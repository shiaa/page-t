马斯克整合 Cursor 首战：SpaceXAI 发布 Grok Bot，云端 AI 队友 7×24 小时端到端干活

AI Agent SpaceXAI Cursor

8 月 11 日，马斯克旗下 SpaceXAI 正式发布 Grok Bot 早期测试版——每个 Bot 拥有独立的云端 Linux 虚拟机，能登录用户各类账号端到端执行任务，合上笔记本也不停机。Bot 支持多实例并行协作与"跟班学习"（操作一遍即可复用优化），并继承 Cursor 生态连接器，可直接调用 Cursor Cloud Agent 写代码。这是马斯克 6 月以 600 亿美元全股票收购 Cursor 后的首个整合成果，直接对标 Anthropic 的 Claude Cowork。Grok Bot 向 SuperGrok Heavy（月 300 美元）、Cursor Ultra（月 200 美元）、Cursor Teams Premium（月 120 美元）订阅用户开放，支持 macOS、Windows、Linux、iOS，企业用户走候补名单。

值得关注的原因：Grok Bot 的原型是 Cursor 内部代号为"Sand"的通用 Agent 产品，被收购后改名换姓迅速落地——这验证了"大模型公司吞并工具厂商以获取用户行为数据和分发渠道"的并购逻辑。从技术层面看，Grok Bot 的核心差异化在于"持久化云端数字同事"：不依赖 API 预接，而用视觉+操作模拟真人使用软件，能跨 Gmail、Salesforce 等应用自主完成多步骤工作流。这标志着 AI Agent 从"对话工具"正式进入"数字员工"赛道，但权限管理、审计合规和资安争议仍是待解难题。对开发者而言，Cursor 的基础设施已被纳入马斯克的"算力—编程—办公代理"垂直栈，后续 Cursor 产品路线图值得密切关注。

AI 编程创企 Lovable 完成 4 亿美元 C 轮，估值 7 个月翻倍至 133 亿美元，腾讯参投

Vibe Coding Lovable 融资

8 月 12 日，瑞典 AI 编程创企 Lovable 宣布完成 4 亿美元 C 轮融资，投后估值达 133 亿美元（约合人民币 897 亿），较去年 12 月的 66 亿美元估值翻倍。本轮融资由 Menlo Ventures 领投，腾讯及 Balderton Capital 等参投。Lovable 成立于 2023 年，脱胎于开源项目 GPT Engineer，通过自然语言交互让非程序员也能构建应用，平台整合了数据库、存储、身份验证、智能体服务等全栈能力。目前用户已创建超 6000 万个项目，月访问量突破 9 亿次，2/3 财富 500 强企业员工在使用其平台，预计本月年化营收将接近 6 亿美元。客户包括英伟达、阿迪达斯、Zendesk 等。

值得关注的原因：Lovable 估值 7 个月翻倍，是"Vibe Coding（氛围编程）"赛道被资本疯狂追捧的缩影。其定位——"帮助 99% 不会编程的人将创意变成现实"——与 Cursor、Replit 等面向开发者的工具形成差异化，瞄准的是企业内部工具构建的增量市场。值得关注的是腾讯连续参投（此前 B 轮已有 CapitalG、Salesforce Ventures），说明中国科技巨头在 AI 编程赛道的海外布局正在加速。Lovable 的商业模式从"工具订阅"向"平台运营"演进（应用直接跑在 Lovable Cloud 上），这意味着 AI Coding 公司正在演变为新一代 PaaS。

DeepSeek V4 Pro 0813 正式版发布：百万上下文+极低成本，编程能力跻身全球第一梯队

AI Coding DeepSeek 开源模型

8 月 13 日，DeepSeek 发布 V4 Pro 0813 正式版。在关键编程基准测试中，该模型已与 Fable 5、Opus-4.8 等旗舰模型差距极小：Terminal Bench 2.1 达 87.9 分（高于 Opus-4.8 的 85.0），DeepSWE 软件工程缺陷修复 62.7 分（预览版仅 12.8），Cybergym 网络安全攻防 83.3 分。核心技术突破包括：1M Token 上下文窗口可一次性处理整个代码仓库，384K Token 最大输出支持生成完整模块代码，稀疏注意力机制（HCA）使百万级上下文的 KV Cache 占用仅约 1.2GB（A100），远低于稠密模型的 110GB。成本方面，输入缓存命中仅 0.025 元/百万 Token，未命中 3 元，推理成本约为 GPT-4o 的 1/8。

值得关注的原因：DeepSeek V4 Pro 0813 从"会考试的学生"进化为"能下场干活的实习生"——真正杀手锏不是单点跑分，而是把百万上下文从概念变为可工程化落地的生产力，并以极低成本支撑高并发长任务。对开发者而言，这意味着：(1) 整仓库级代码理解不再需要分段处理，语义断裂问题被根治；(2) 缓存命中 0.025 元/百万 Token 的定价，让高频调用 Agent 工作流的成本几乎可忽略；(3) 原生兼容 OpenAI 与 Anthropic 接口，现有开发流程无缝接入。在国产模型中，DeepSeek 正在与 Kimi K2.6、GLM 5.1 形成三足鼎立的第一梯队格局。

Blacksmith 获 4500 万美元 B 轮：AI 写代码易、验证难，云端编程代理 codesmith 主攻代码验证

AI Coding Blacksmith CI/CD

8 月 13 日，持续集成服务商 Blacksmith Software 宣布完成 4500 万美元 B 轮融资（估值 5.5 亿美元），由 Peak XV Partners 领投，Y Combinator 和 GV（谷歌风投）参投。该公司将代码开发与云端测试深度结合，近期推出名为 codesmith 的云端编程代理——开发者可将任务委托给它，它不仅构建功能和修复错误，更深入验证环节：诊断集成故障、自动修复问题、修复对代码库的提交。整个团队可同时编写代码并协作提交，Blacksmith 在提交到达时自动测试：通过则合入代码库，失败则拒绝并返回出错原因。自今年初以来，其服务上运行的任务量每周增长 5%-10%。

值得关注的原因："编写代码已经变得极其容易，但验证代码却没有"——这句话精准概括了 AI Coding 的下一阶段瓶颈。当 Claude Code、Codex 等工具能自动生成大量代码后，验证和测试环节的价值急剧上升。Blacksmith 的 codesmith 代表了一个新趋势：AI Agent 从"代码生成者"进化为"代码守门员"，在 CI/CD 流水线中承担构建-测试-审查的自动化闭环。这对 DevOps/SRE 团队尤其重要——当 AI 生成的 PR 量激增时，传统人工 Code Review 根本扛不住，云端 Agent 自动验证将成为刚需基础设施。公司管理着数十万核心并计划扩容一个数量级，说明需求增长远超预期。

蚂蚁集团领投戴盟机器人数亿元轮，全球首个"物理交互脑"Daimon-TWM 将触觉从事后反馈推向事前推演

具身智能 戴盟机器人 触觉感知

8 月 11 日，戴盟机器人宣布完成数亿元战略轮融资，蚂蚁集团领投，老股东超额跟投。同期推出全球首个触觉锚定世界模型"物理交互脑"Daimon-TWM，将触觉从"事后反馈"推进到"事前推演"。该模型采用三层架构：物理认知模块（基于强化学习建立物理常识，理解接触状态、力与形变、材料属性）、推演决策模块（基于世界模型前瞻预判接触状态演化与失败风险）、瞬时操控模块（100Hz 高频伺服实现毫秒级动作纠偏）。参数规模达 10B 级，可在 NVIDIA RTX 5090 平台实时推理，具备跨本体、跨机械臂部署能力。蚂蚁此前已密集投资宇树科技、星海图、灵心巧手等，此次是首次将触角延伸至触觉感知层。

值得关注的原因：这是具身智能赛道的一个重要信号——资本正从"机器人本体"涌向"触觉感知层"。行业研究显示，触觉数据能显著提升机器人接触类任务的成功率与数据效率，走出比纯视觉路线更陡峭的 Scaling 曲线。"莫拉维克悖论"指出机器擅长复杂逻辑推理却难以复现人类本能的感知与操作，而 Daimon-TWM 试图用"触觉世界模型"突破这一悖论：不是给机器人更复杂的手，而是给它一个懂物理交互的"脑"。蚂蚁从本体→大脑→核心零部件→触觉感知的全链路投资版图，说明具身智能的竞争焦点正在从"硬件参数"转向"感知-决策-操控闭环"。对关注供应链入行的从业者，触觉传感器和触觉数据采集是正在打开的新细分赛道。
