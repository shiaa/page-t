OpenAI GPT-5.6 正式发布，Sol/Terra/Luna 三模型重新定义能力层级

AI Coding OpenAI 模型发布

7 月 9 日，OpenAI 结束 12 天受限预览，正式发布 GPT-5.6 系列。三模型家族 Sol（旗舰）、Terra、Luna 引入"持久能力层级"概念——名称标识能力级别而非版本，Sol 未来可升级至 GPT-5.7 同时保持层级身份。Sol 在编程能力上创下新 SOTA：Artificial Analysis Coding Agent Index 得分 80，超越 Claude Fable 5 的 2.8 分。同时 Codex 并入 ChatGPT 桌面端，推出 ChatGPT Work 统一界面，支持聊天、编码和长时 Agent 任务。

值得关注的原因：GPT-5.6 的"能力层级"命名策略是 OpenAI 产品化思路的重要转变——从版本号焦虑转向能力承诺，企业客户可以按层级采购而非追版本。Sol 的编程指数 80 意味着 AI Coding Agent 的能力边界又向外扩了一圈，配合 Ultra 模式下默认 4 个并行 Agent（可扩至 16 个），复杂软件工程的自动化拆解和并行执行已成为现实。对 SRE/DevOps 场景来说，多 Agent 并行意味着故障排查、代码重构、配置迁移等任务可以"分工+同步"完成，效率提升是数量级的。

阿里巴巴全面禁用 Anthropic 旗下 AI 工具，全员切换自研智能体编程平台 Qoder

AI Coding 阿里巴巴 国产替代

2026 年 7 月初，阿里巴巴发布内部紧急通知，要求全体员工在 7 月 10 日前卸载美国 Anthropic 旗下 Claude Code 及 Sonnet、Opus、Fable 等全系产品，统一替换为自研智能体编程平台 Qoder。数月前阿里还在开放该类工具的大额报销通道，此次转向反映国内头部科技企业核心研发领域对海外闭源 AI 工具态度发生根本转变。Qoder 定位为 Agentic 编程平台，支持多智能体协作、代码生成、自动化测试和部署。

值得关注的原因：这是国内大厂"AI 工具去美化"最明确的信号之一——从"报销使用海外工具"到"全员禁用+强制切换自研"，中间只隔了几个月。阿里不是第一家（字节、百度早有动作），但阿里在研发人员规模和代码库复杂度上的体量，让这次切换具有行业示范效应。Qoder 的实战表现将成为国内自研 AI 编程工具能力的试金石；如果能在阿里内部跑通，意味着国产 Agentic Coding 平台已具备替代海外产品的工程成熟度。对国内开发者而言，Qoder 的开放进度和 API 生态值得持续关注。

Meta Muse Spark 1.1 发布，Zuckerberg 三年首返 X 称其为"极具能力的 Agent 模型"

AI Coding Meta Agent

7 月 9 日，Meta 正式发布 Muse Spark 1.1，专为 Agentic 任务设计——规划、工具调用、子 Agent 委派、计算机操作。在 Agent 基准测试中，JobBench 54.7%（超越 Claude Opus 4.8 的 48.4%），MCP Atlas 88.1（领先 Opus 4.8 的 82.2）。支持 100 万 token 上下文窗口和上下文压缩机制，可在长会话中保持状态。编码方面，Vibe Code Bench 从 19.7% 跃升至 72.2%，但 SWE-Bench Pro 61.5% 仍落后 Claude Opus 4.8 的 69.2%。Meta 将其定位为 Agent 编排器而非纯编码领导者。

值得关注的原因：Zuckerberg 三年没发 X，Muse Spark 1.1 让他破功——这个信号本身就很说明问题。Meta 的战略定位很聪明：不跟 Claude 拼纯编码能力，而是做"Agent 编排器"——主 Agent 收集信息、制定计划，拆分任务给子 Agent 并行执行。这意味着 Muse Spark 1.1 的核心价值不在"写代码"，而在"管理写代码的过程"。对于复杂软件项目（如微服务重构、跨模块 Bug 修复），编排能力比单文件编码能力更重要。100 万 token 上下文+压缩机制，也意味着它可以一次性吞下整个代码库并保持长期记忆——这是大型工程自动化的关键前提。

蚂蚁灵波发布 6 款具身原生机器人动作模型，从数字世界转向物理世界原生设计

具身智能 蚂蚁灵波 动作模型

7 月 12 日，蚂蚁灵波发布 LingBot-VA 2.0 等 6 款具身原生机器人动作模型，采用自回归架构从零预训练，聚焦动态建模、因果预测等物理世界交互核心需求。技术路线从数字世界模型构建转向物理世界原生设计，这是国内首次有科技巨头以"具身原生"思路发布系列动作模型。相关数据显示，具身智能 AI 模型平均每 48 小时就有一个全新模型诞生，迭代速度显著加快，从智源"世界模型"到阿里"通义千问机器人"等成果不断问世。

值得关注的原因："具身原生"是这次发布的关键词——不是拿数字世界的模型微调后套到机器人上，而是从零开始为物理世界交互设计架构。自回归架构+动态建模+因果预测，这套组合拳意味着模型不是在"记住动作"，而是在"理解物理规律"。这对机器人泛化能力至关重要：遇到没训练过的障碍物、地形、物体形态时，能基于物理因果推断合理动作，而非死板复现训练数据。蚂蚁灵波背靠阿里生态，在物流、仓储、服务机器人场景有天然落地通道。6 款模型矩阵覆盖不同能力维度，说明团队已经体系化思考具身智能的产品化路径。

NVIDIA 与 Hugging Face 扩展开源机器人合作，GR00T 1.7 入驻 LeRobot 生态

具身智能 NVIDIA 开源

7 月 7 日，NVIDIA 与 Hugging Face 宣布重大扩展合作，将 NVIDIA Isaac GR00T 1.7 视觉-语言-动作模型和 Isaac Teleop 数据捕获框架集成进 Hugging Face 开源 LeRobot 库。GR00T 1.7 是首个开放的、商业可行的人形机器人基础模型，开发者可通过标准 LeRobot 流程进行后训练与部署，无需专有工具链。Isaac Teleop 支持高质量人类示范数据捕获，直接输入 LeRobot 数据集。路线图还包括 Cosmos 3 前沿世界基础模型，用于生成合成机器人数据。

值得关注的原因：这次合作把 NVIDIA 的 300 万机器人开发者与 Hugging Face 的 1600 万 AI 构建者连接在一起，形成统一 pipeline：遥操作 → 在 GR00T 上训练 → 用 Cosmos 模拟 → 通过 LeRobot 部署。"开放+商业可行"是 GR00T 1.7 的关键定语——之前的人形机器人模型要么封闭（如 Tesla Optimus 的模型），要么仅供研究，GR00T 1.7 是第一个允许企业直接拿来产品化的开放模型。Cosmos 3 世界模型生成合成数据的能力，解决了机器人训练最大的瓶颈：真实数据昂贵且危险。对具身智能创业者来说，这意味着"有模型可用、有数据可生成、有工具可部署"的闭环正在形成，创业门槛显著降低。
