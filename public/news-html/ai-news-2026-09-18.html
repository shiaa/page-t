OpenAI 推出托管版智能体 API，一次调用即可构建定制化 Agent

智能体基础设施 OpenAI Agents API

9 月 18 日，OpenAI 推出公开测试阶段的托管版智能体 API，将支撑 Codex 运行的智能体框架与底层基础设施能力开放给开发者。开发者在指定任务、模型、工具与运行环境后，通过一次 API 调用即可完成定制化智能体设计。执行环境可选 OpenAI 托管沙盒、自有基础设施，或第三方沙盒（Cloudflare、Daytona、E2B、Modal、Vercel、甲骨文、DigitalOcean 等）。其本质是把"任务队列、状态库、沙盒集群、压缩例程、重试策略"等脏活交给 OpenAI 托管。

值得关注的原因：这标志着智能体基础设施从"手搓"走向"云托管"的拐点——企业搭建一个可无人值守运行数小时的 Agent，工程量被大幅压缩，CIO 将智能体投产与扩缩容的时间显著缩短。但硬币的另一面是"锁定效应"：OpenAI 同时掌握模型、上下文管理、工具、编排与执行环境，迁移成本陡增、议价能力削弱，且不承诺零数据保留，在金融、医疗等强监管行业受限。直接竞品已就位：Anthropic Claude 托管智能体（4 月公测）、AWS Bedrock AgentCore（6 月 GA）、微软 Foundry Agent Service、LangGraph。对 AI Coding 开发者，这意味着"在哪跑 Agent、活在谁的工作流里"正取代"模型谁更强"成为新战场。

Claude 已主导 Anthropic 26% 的 AI 研发，约 3 万 Agent 同时上岗

AI 研发自动化 Anthropic 指标披露

9 月 18 日，Anthropic 披露一组用于追踪前沿 AI 实验室研发进展的新指标：截至今年 8 月，Claude 已"主导"（AI leads）约 26% 的 AI 研发工作——这一比例 2 月时尚不足 1%；超 90% 的相关任务已达到"AI 协作"或更高自动化水平。另有约 3 万个 AI Agent 同时在公司内部执行研究与工程任务，单月分析超 10 亿次 Agent 决策，监控系统拦截率约 0.002%（每 4.7 万次约 1 次）。不过 Claude 仍未在任何被测任务上达到完全自主运行水平。

值得关注的原因：这是头部实验室首次量化"AI 在多大程度上参与开发下一代 AI"，揭示研发正从"AI 辅助"走向"AI 驱动"。但比例越高，安全隐忧越重——7 月 13-20 日一周约 6% 的 AI 研发算力用于安全工作，纯 AI 驱动的研发中该比例升至 12%。Anthropic 还计划开放独立第三方评估访问内部流程，以弥合实验室内部进展与公众认知的差距。对开发者而言，"用 AI 造 AI"已从口号变为日常，如何衡量研发自动化程度、监督 Agent 行为、让安全投入跟上自动化速度，将成为前沿团队的硬课题。

Zed 发布 Delta 公开测试版：用「共享线程」替代 Pull Request

AI Coding Zed 协作范式

由 GitHub Atom 团队创业打造的 Zed 推出 Delta 公开测试版，主张 agents 生成代码的节奏已超出 GitHub PR 模型的承载能力。Delta 以"线程"为核心——开发者把任务交给 agent，对话与变更文件始终连接，可分享完整上下文供他人审阅、追问与改稿；底层 DeltaDB 以"deltas"记录编辑级事件而非 commit。创始人 Nathan Sobo 直言"所有人都在赛跑取代 GitHub"。背景：GitHub 月提交量已从 2025 全年约 10 亿飙至 2026 年 8 月的 29 亿/月，8 月还曾出现近 8 小时大中断。

值得关注的原因：这是"Agent 原生协作范式"对统治 15 年的 PR 工作流的第一次正面挑战。它暴露一个结构性矛盾——当推理发生在对话里、diff 只是结果，传统 review 模型天然丢失上下文。对 coding 工具链、代码托管平台乃至企业内部研发流程，这都是范式级变量：代码托管可能从"以 commit 为中心"转向"以对话线程为中心"，审阅者看到的是完整推理链路而非孤立补丁。

Qwen3.8-27B 登顶 HuggingFace「史上最受欢迎」，本地跑 27B 成编程新标杆

开源模型 阿里千问 本地部署

9 月 16 日，阿里千问 Qwen3.8-27B 在 HuggingFace 登顶"史上最受欢迎"榜单（15.3k 赞，超过 FLUX.1、DeepSeek-R1、Kimi-K3、Meta-Llama-3 等老牌网红）。270 亿参数的稠密模型，被海外社区称为"本地 Opus 4.6"，在 CodeArena 同尺寸模型性能上拿下 SOTA，官方定位"A New Bar for Coding and Cowork"。其 4-bit 量化版仅需 17-19GB 总内存即可启动（RTX4090/5080 或 24GB 统一内存 Mac 均可）。开源不到一个月，Perplexity 已将其选为本地 Agent 业务首选模型；阿里累计开源 460+ 款 Qwen 模型，全球下载总量突破 30 亿次。

值得关注的原因：旗舰级模型能力正在下沉到本地终端，意味着"云端租算力 vs 本地买断自由"的拐点已至。对高频写代码、隐私敏感（合同/财务/内部文档）、批量任务三类场景，本地 27B 是 2026 年性价比最高的选择之一——零延迟、零 API 费用、数据不出本机。这也折射出开源阵营以"可用 + 可控 + 低成本"对闭源 API 形成的真实威胁：当 27B 跑进普通人的电脑，模型私有化不再只是极客玩具。

优必选柳州万台级工厂投产，「机器人造机器人」每 10 分钟下线一台

具身智能 优必选 规模制造

9 月 14 日（报道于 9 月 18 日），优必选万台级工业人形机器人超级智慧工厂在广西柳州正式投产。按生产设计节拍，每 10 分钟下线一台工业人形机器人，年规划产能超万台。走进 1.4 万平方米的厂房，生产一线忙碌的是 Cruzr Y1、Cruzr S2 等具身智能工业人形机器人——它们参与拆垛、码垛、上料、搬运，亲手制造自己的"同类"，还没出厂就先在产线上"上岗"。优必选联合西门子围绕数字孪生、智能调度、全链路品控打造专属数字化制造底座。对比：乐聚/东方精工佛山产线 3 月投产时节拍为每 30 分钟一台，柳州把它压到了 10 分钟。

值得关注的原因："机器人造机器人"从概念秀走向规模制造的现实样板，标志行业正逼近第三层"全流程自主闭环"（感知-决策-执行由智能系统调度）。TrendForce 预估 2026 全球人形机器人出货突破 5 万台、年增逾 700%，中国上半年出货已超 4 万台、全球占比 97%。当行业产量以每年数倍膨胀，制造方式本身成为核心竞争力——谁能用更低成本、更高良率、更快节拍把机器人造出来，谁就能在价格战中活下来。这对关注供应链（关节电机、谐波减速器、六维力传感器、端侧 AI 芯片）与商业化落地节奏的人，是关键的产能信号。
