2026 WAIC 闭幕：AI 从数字智能迈向"物理智能交付元年"，具身智能全面冲刺落地

WAIC 2026 具身智能 物理智能

7 月 17-20 日，2026 世界人工智能大会在上海举办。本届最大变革：AI 不再局限于屏幕里的文字生成，大批国产人形机器人、具身智能硬件集中亮相，厂商纷纷搭建实景作业区展示"真干活"能力。乐聚机器人直接打造工业实景作业区（纸箱拆垛、小件上料），傅利梁首发高负载轮式双臂机器人 GRW 及"具身之家"居家陪伴方案，新智具身展示汽车车灯精密装配，飒智智能发布面向工业场景的"玄枢·WASM 世界模型"。国家地方共建人形机器人创新中心与华为联手打造全国首个具身智能实训场样板点，将训练从"固态"推向"动态"。

值得关注的原因：今年 WAIC 的展陈变化是具身智能赛道最直观的信号灯——从去年"百台机器人秀场"到今年"实景作业无滤镜演示"，行业已正式从概念验证进入商业落地攻坚期。华为与人形机器人创新中心共建实训场，意味着国产算力底座与机器人本体开始深度耦合，"一脑多机"的通用具身智能平台不再只是愿景。对关注转岗 SRE/DevOps 的人而言，机器人在工业产线中的巡检、运维场景正快速成型，未来的"运维岗"可能同时管机器和管机器人。

Kimi K3 发布引爆全球 AI 竞速，马斯克宣称 2 万亿参数模型下周完成训练、目标赶超

大模型 Kimi K3 马斯克

7 月 17 日，月之暗面发布新一代开源大模型 Kimi K3，参数规模达 2.8 万亿（当前全球最大开源模型），原生支持图像输入与 100 万 Token 上下文，采用 KDA 注意力机制与 896 专家稀疏 MoE 架构（每 Token 仅激活 16 个专家），扩展效率较 K2 提升约 2.5 倍。Arena AI 前端编程排行榜以 1679 分登顶全球第一，超越 Claude Fable 5 和 GPT-5.6 Sol。发布当日纳斯达克 100 期货一度跌超 1.8%，英伟达等 AI 龙头走低。马斯克先留言"令人印象深刻"，次日透露其 2 万亿参数模型下周完成初始训练，可能超越 Kimi。Kimi 回应："欢迎加入'2 万亿+'俱乐部。"权重将于 7 月 27 日前公开。

值得关注的原因：Kimi K3 的发布再次复现了"DeepSeek 时刻"——中国开源模型在核心基准上超越美国顶尖闭源模型，直接冲击美股 AI 板块估值。更值得关注的是竞争格局的变化：模型参数规模的军备竞赛已从"谁的模型更强"转向"谁的开源生态更密"——K3 以 2.8T 开源权重 + OpenAI 兼容 API 的组合，把 Opus 级能力放进任何人可自持的范围。对开发者而言，这意味着推理成本下行和本地部署可行性双双提升，AI Coding 工具的模型选择空间大幅拓宽。

💻 AI Coding 方向

AI Coding 价值重心转移：从"谁的模型更强"到"谁的工具链更密"，编程 Agent 安全护栏一周内集体升级

AI Coding 工具链 安全护栏

AI Coding 的竞争正在发生结构性转向——OpenAI 3 月主动为竞争对手 Claude Code 发布官方插件，让 Codex 写代码、Fable 5 管流程和审核，形成"双模型协同工作流"。这一架构的本质是：Claude Code 已成为大量开发者的默认编程环境，不是因为代码生成更强，而是因为工程管理能力（理解项目结构、拆分任务、调用工具、管理版本）更靠近日常工作流。同期，三家头部编程 Agent 在同一周集体加码安全护栏：GitHub Copilot CLI 硬阻断计划模式下的文件编辑，Claude Code 修复双向字符和零宽字符伪造审批提示的漏洞，OpenAI Codex 改进危险命令检测。这背后是 AsyncAPI 四个核心仓库遭供应链攻击、五个木马包被推上 npm 的现实威胁——Agent 自动安装依赖的权限正是此类攻击的爆炸半径。

值得关注的原因：两条趋势线正在交叉：一条是工具链密度决定胜局（Claude Code 管全局、Codex 写细节的分工模式可能成为行业标准），另一条是 Agent 自主权越大、安全边界越必须硬编码而非靠提示词约束。对一线开发者而言，"选哪个模型"的决策正在让位于"选哪个工作流"——模型可以换，但项目结构理解、任务拆分逻辑、变更审核流程这些"管理能力"才是真正锁住用户的粘性。而供应链攻击事件提醒我们：AI Coding Agent 的"超级权限"必须配以"超级护栏"。

工信部发布 Claude Code 严重后门隐患预警：内置监控机制可静默回传敏感数据，阿里巴巴全面禁用

安全预警 Claude Code 工信部

7 月 8 日，工信部网络安全威胁和漏洞信息共享平台（NVDB）发布风险提示：美国 Anthropic 公司 AI 编程工具 Claude Code（2.1.91 至 2.1.196 版本）存在安全后门隐患，危害等级为"严重"。该工具内置隐蔽监控机制，未经用户同意即可向远程服务器回传用户地域信息、设备标识乃至研发代码等核心敏感数据，且会读取系统时区精准识别并标记中国用户。《华盛顿邮报》7 月 6 日报道证实，Anthropic 今年 3 月悄悄部署了针对中国客户的监视软件。阿里巴巴已于 7 月初内部通告：自 7 月 10 日起全体员工办公场景全面禁用 Claude Code，纳入高风险软件清单。Anthropic 称该机制为"实验性反滥用功能"，已于 7 月 2 日推送新版本移除后门代码。

值得关注的原因：这不仅是产品安全事件，更是 AI 时代数据主权与工具信任的标志性拐点。AI Coding Agent 拥有读取代码库、编辑文件、运行命令的"超级权限"——当这个权限可以被暗中利用回传数据，风险不亚于芯片硬件漏洞。从企业角度看，核心研发流程绑定海外模型工具链本身就是系统性风险：涨价、断供、政策变化、后门代码，任何一环都可能让企业陷入被动。事件也加速了国产 AI 编程基础设施的替代需求——"全自主、高安全、自进化"的本土平台不再是备选项，而是安全合规前提下实现 AI 生产力的必由路径。

具身智能产业销售收入同比增长 22.4%，机器人整机制造增长 30.1%，近九成企业集聚粤京沪浙苏

产业数据 具身智能 增长态势

国家税务总局最新数据显示，2026 年 1-5 月我国具身智能产业企业销售收入同比增长 22.4%，其中机器人整机制造增长 30.1%。近九成企业集中在广东、北京、上海、浙江、江苏五省市，产业集聚效应显著。同期在 WAIC 上，复旦大学可信具身智能研究院展示车灯精密装配系统（集成自研视触觉传感器实现"触觉认知"），本自具智发布面向护理康养场景的智慧介护系统（人-机-物三元协同具身大模型），它石智航线束智能机器人方案已落地国内汽车线束龙头企业产线。

值得关注的原因：22.4% 的行业收入增速和 30.1% 的整机制造增速，是具身智能从"实验室原型"走向"产线交付"最硬的经济证据。五省市近九成集聚意味着产业链正在快速形成区域集群效应——和芯片产业当年在深圳、上海的集聚路径相似。对运维工程师而言，机器人巡检、电控柜操作、设备维护这些场景正是传统运维的物理延伸，SRE/DevOps 转型路径中"管理机器人运维工作流"可能成为新的差异化技能。
