IPO AI 史上最大

Anthropic 秘密提交 S-1 招股书：估值近万亿，AI 行业资本化进入超级周期

核心内容：Anthropic 于当地时间 6 月 1 日正式向美国 SEC 秘密递交 S-1 注册声明，计划推动公开上市。高盛与摩根大通担任主承销商，预计最早 2026 年秋季正式挂牌，上市规模将创 AI 领域历史纪录。

估值与营收：5 月 29 日刚完成 Series H 融资 650 亿美元，投后估值达 965 亿美元（约合人民币 6500 亿元）。年化收入已达 470 亿美元，在 Claude 系列模型强劲商业化驱动下，Anthropic 估值已反超 OpenAI。

行业背景：SpaceX、OpenAI 也计划今年 IPO，三家万亿级估值公司或将同年在美上市，全球资本市场 AI 定价逻辑面临大考。
Anthropic 抢在 OpenAI 之前递交招股书，标志着 Claude 系列在 Coding Agent 领域的技术优势已转化为商业胜利。470 亿美元年化收入意味着 AI Coding 已是百亿级市场。作为 Claude Code 背后的公司，其上市将为整个 AI Coding 赛道确立估值标杆。

AI Coding 方向

AI 编程融资 500 亿美元估值

Cursor 以 500 亿美元估值融资逾 20 亿美元，AI 编程赛道最大单笔融资即将诞生

核心内容：AI 编程工具 Cursor 母公司 Anysphere 正在推进新一轮融资，估值 500 亿美元，计划融资规模 超过 20 亿美元。潜在投资方包括 Andreessen Horowitz（a16z）和 Thrive Capital，目前处于谈判阶段。

增长驱动：此轮融资的核心驱动力是 Cursor 企业业务加速增长。从去年中期的估值约 25 亿美元到如今的 500 亿美元，Cursor 在不到一年内估值翻 20 倍，反映了企业级 AI 编程需求的爆发式增长。

行业对比：相比之下，Devin 母公司 Cognition AI 上轮融资估值约 260 亿美元。Cursor 此轮若成功落地，将成为 AI 编程赛道估值最高的公司。
Cursor 500 亿美元估值意味着资本市场已将 AI 编程工具视为"下一代 IDE"级别的核心基础设施。企业业务增长是估值锚点——说明 AI Coding 不再只是开发者个人工具，而是企业研发效能的刚需。这也预示着 AI Coding 赛道将进入更激烈的竞争和整合阶段。
计费变革

GitHub Copilot 正式切换 AI Credits 按量计费：AI 编程工具免费红利时代结束

核心内容：GitHub 于 6 月 1 日起全面上线 AI Credits 按量计费体系，取代原有的 Premium Request Units 固定额度模式。套餐价格不变，但计费逻辑彻底改变——代码生成按模型和 Token 消耗扣减 AI 点数。

新定价体系：
Pro（$10/月）：1,500 AI 点数
Pro+（$39/月）：7,000 AI 点数
Copilot Max（$100/月）：20,000 AI 点数

实际影响：重度使用 Copilot 的开发者可能面临用量不够用的问题，按 Token 计费意味着 AI 编程成本与代码复杂度直接挂钩。企业需要重新评估团队 Copilot 预算。配套上线了用户级预算控制功能。
AI 编程工具的计费模式正从"无限量包月"转向"按量付费"，这是行业走向成熟的标志。对开发者而言，需要更加审慎地选择何时调用 AI——简单补全和复杂重构的成本差异将被放大。这也为 Cursor、Claude Code 等竞品提供了差异化定价机会。
新模型发布

MiniMax 发布 M3 模型 + MiniMax Code：编程能力达 Claude Sonnet 4.6 水平，模型权重将开源

核心内容：MiniMax 于 6 月 1 日发布新一代旗舰模型 M3，宣称是国内首个齐备三大前沿能力的模型：1M 上下文窗口、前沿编程能力、原生多模态。编程性能对标 Claude Sonnet 4.6，模型权重将在发布后十天内开源。

MiniMax Code：同期推出配套 AI 编程产品 MiniMax Code，正式加入 AI Coding 赛道竞争。该公司此前已启动 A 股上市辅导，估值持续攀升。

行业格局变化：国内 AI 编程赛道从"三家"（阿里通义、字节豆包、智谱）扩展至"四家"，MiniMax 凭借开源策略 + Coding 定位切入，可能搅动现有格局。
MiniMax M3 开源 + MiniMax Code 的组合拳值得关注——开源模型降低了本地部署 AI Coding 能力的门槛，国内开发者可基于 M3 构建私有化编码助手。随着 Claude Code 付费化趋势加剧，开源替代方案的重要性日益凸显。

具身智能方向

世界动作模型

越疆发布"空弈"世界动作模型：LIBERO 标准任务成功率超 99%，国产具身智能新突破

核心内容：机器人企业越疆（Dobot）发布自研世界动作模型 "空弈 DobotWAM"，在具身智能标准评测基准 LIBERO 上通过深度测试，顺利通过 LIBERO-Spatial、LIBERO-Object 等全部评估子项，标准任务成功率 超过 99%。

技术路线："空弈"采用世界动作模型（World Action Model）架构，不同于传统的视觉-语言-动作（VLA）范式，强调对物理世界动作空间的建模，在复杂现实任务理解与执行上取得关键突破。

产业价值：越疆作为国内机械臂龙头企业，将世界动作模型与自有硬件结合，意味着从"模型公司"向"产品公司"的路径更短，商业化落地速度可能更快。
LIBERO 99%+ 成功率是一个令人印象的数字——此前卧安 OneModel 1.7 也曾达到 99% 的 LIBERO 成功率。国产世界动作模型密集突破，说明中国在具身智能核心算法层面已进入全球第一梯队。越疆的硬件+模型整合模式值得关注，可能代表具身智能商业化的最优路径。
