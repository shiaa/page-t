OpenAI 收入口径下修至约 500 亿美元，寻求 300 亿新融资、估值 1.4 万亿，算力股应声下挫

融资 OpenAI 资本重估

10 月 10 日多方报道，OpenAI 将此前按不同会计准则披露的约 700 亿美元年化收入下修至约 500 亿美元，同时寻求至少 300 亿美元的新融资，对应估值约 1.4 万亿美元。收入口径的修正引发市场对 AI 巨头「规模叙事」的重新审视，当日算力与芯片相关股票随之下跌。

值得关注的原因：头部玩家首次从「规模增长」转向「收入质量」被公开审视，直接影响三件事：AI 基础设施的投资节奏、算力/芯片需求的预期，以及整个行业的融资环境。对 AI Coding 与具身智能开发者而言，资本从「烧钱换增长」转向「收入成色」意味着下游工具与硬件的采购窗口与成本曲线可能收紧，选型时需更看重真实可落地的 ROI。

💻 AI Coding 方向

Harness 收购 Augment Code 编码智能体资产，AI 编码赛道整合加速

AI Coding Harness 并购

10 月 8 日，软件交付公司 Harness 宣布收购 Augment Code 的部分资产，包括 Cosmos 与 Auggie CLI 产品、Code Context Engine 及相关技术，原团队将并入 Harness。Cosmos 将改造为「Harness Cosmos Software Factory Agent」——一支由多个智能体组成的「机群」可在各自隔离的 VM 中规划改动、写代码与测试并自动开 PR，工程师仅保留设计与最终合并决策权。

值得关注的原因：这是 AI 编码创业公司被「传统软件交付平台」收编的明确信号：单点编码助手难以独立盈利，价值正向上游「软件交付编排」聚拢。Harness 计划把 Augment 的 Code Context Engine 接到其「软件交付知识图谱」，让智能体调用历史测试失败、安全发现与事故数据——「上下文 + 治理」正成为编码 Agent 的平台级护城河，而非单纯模型能力。

编码智能体「长会话可靠性」竞赛白热化：Claude Code 默认 Haiku 5.5（1M 上下文），Codex CLI 0.162、Copilot CLI 1.0.94 密集更新

AI Coding Claude Code 长会话

本周编码智能体密集迭代：Claude Code 2.1.293（10/7）将默认模型切到更快更便宜的 Haiku 5.5（1M 上下文、$0.10/$0.50 每 Mtok），并修复压缩丢工作等隐患；OpenAI Codex CLI rust-v0.162.0（10/8）新增全局可点链接、可钉住任务与 Git worktree 组织；GitHub Copilot CLI 1.0.94（10/8）加入实时沙箱与更稳的会话切换。三家 changelog 高度一致地指向「长周期自治任务的工程磨损点」而非新能力。

值得关注的原因：终端编码智能体的竞争维度已从「谁的模型更强」切换到「谁在 8 小时长会话里不丢东西」——自动压缩失效、resume 丢上下文、断线重连重复发消息，这些问题最难复现也最伤信任，却无法从榜单分数读出，只能从 changelog 里读。对选型方（尤其 DevOps/SRE 远程排障、长任务委托场景）而言，长会话可靠性才是能否真正托付生产任务的分水岭。

🤖 具身智能方向

星源智 Thor 人形机器人创吉尼斯纪录：37.15kg 自重牵引 1434kg 汽车（约 38.6 倍自重）

具身智能 全身控制 强交互

10 月 9 日，星源智与智源研究院联合研发的 Thor 全身控制模型赋能人形机器人，在北京亦庄创下「人形机器人拉动最重的汽车（40kg 以下）」吉尼斯世界纪录：以 37.15kg 自重拉动 1434kg 汽车，持续双足行进 9.92 米，牵引重量约为自身 38.6 倍。挑战中机器人需主动调整躯干倾角、转移重心、协调上下肢与步态，将外部反作用力纳入全身控制闭环。

值得关注的原因：这是人形机器人在「强交互」场景（推、拉、拖、开门等承受外部反作用力的任务）下全身控制能力的一次极限验证。自由空间里的「把动作做出来」与承受外力下「把任务做完」是两类控制问题，而后者才是搬运、装配、救援等真实作业的核心瓶颈。极限负载下的稳定控制突破，意味着人形正从「会动」走向「能干重活」。

中国具身智能产业化拐点：70+ 训练场投用、零售文旅批量落地，瓶颈从硬件转向场景与软件

具身智能 产业化 商业化

据央视报道，全国已建成启用 70 多家具身智能训练场，在建/规划 40 余家，形成长三角、京津冀、珠三角三大集群，已交付 150 万小时人类视频数据（全球领先）。应用端同步放量：100 台灵犀 X2 落地爱仕达全国门店担任导购，清宝机器人批量进入景区做导览伴游；IDC 数据显示 2026 上半年全球人形出货近 2.5 万台（同比 +432%），中国占 77.9%。行业共识是瓶颈已从「硬件本体制造」转向「场景适配与具身智能软件能力」。

值得关注的原因：具身智能正从「单点技术展示」跨入「系统化落地」——数据飞轮（训练场→真机数据→模型迭代）与商业场景（零售、文旅、工业）同时跑通，但纯商业化付费订单占比仍待提升，高出货不等于盈利。对关注供应链与投资机会的人，力控执行器、灵巧手、力矩传感器、端侧 AI 芯片四大子赛道，以及「量产 + 场景运营」双能力企业，是下一阶段确定性更高的观察锚点。
