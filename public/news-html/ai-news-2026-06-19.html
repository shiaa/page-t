行业头条

史诗级人事 格局重塑

1Transformer 核心作者 Noam Shazeer 正式加盟 OpenAI——让发明 Transformer 的人去发明下一个

6 月 18 日，Google DeepMind 工程副总裁、Gemini 模型联合负责人 Noam Shazeer 亲自官宣：他将离开 Google，加入 OpenAI 担任「架构研究负责人」。Shazeer 是 2017 年《Attention Is All You Need》八位作者之一，亲手设计了多头注意力机制与残差结构，第一个跑赢 SOTA 的 Transformer 实现由他一行一行敲出来。此外，他还是 MoE（稀疏门控混合专家）、Mesh-TensorFlow、T5 等底层技术的核心贡献者——现代大模型赖以生存的几大基础架构几乎全在他的名下。

谷歌曾在 2024 年 8 月以 27 亿美元技术许可协议将 Shazeer 请回（他个人从中获利约 7.5~10 亿美元），他回归后主导 Gemini 3 训练优化，据传揪出一个深藏 bug 让训练效率暴涨。如今不到两年再度出走，对谷歌 Gemini 团队军心冲击不可小觑。

Shazeer 技术遗产
  • 多头注意力机制：Transformer 核心
  • MoE 稀疏门控：现代 LLM 省算力命门
  • Mesh-TensorFlow：超算训练巨型模型
  • T5 / LaMDA：谷歌对话系统基石
  • 1994 年国际数学奥赛 金牌满分
OpenAI 阵容升级
  • 职位：架构研究负责人
  • 使命：Transformer 之后是什么？
  • 集齐 两位 Transformer 原作者（+ Lukasz Kaiser）
  • 同日招募前 AI 政策官员 Dean Ball
  • IPO 前技术与监管双线储备

"他公开谈论'百万个自动化研究员在数据中心日夜运转'，谈论'世界 GDP 暴涨 100 倍'。当被问到大模型为什么能 work，他给出的回答堪称玄学——'我最好的猜测，是神的恩典。'"

💡 为什么重要

三个维度叠加影响深远。第一，「让发明者发明下一代」——OpenAI 找 Shazeer 不是优化产品，而是去搭 Transformer 之后的架构骨架。集齐两位原作者（Shazeer + Kaiser），这种阵容放眼全行业独此一家。第二，谷歌 Gemini 3 的翻盘功臣出走——Shazeer 回归后推动 Gemini 3 登顶多个榜单，逼得奥特曼拉响「红色警报」；他离开意味着谷歌最核心的架构大脑出走，军心与技术路线双重动摇。第三，27 亿买回一个人却买不回他的未来赌注——Shazeer 的选择说明他相信 OpenAI 的 AGI 路径，这对整个行业的人才流向与阵营格局将产生连锁反应。

AI Coding 方向

开源旗舰 Coding 全球第一

2智谱 GLM-5.2 正式开源上线——1M 真正可用上下文，Code Arena 前端开发盲测全球可用模型第一

6 月 17 日，智谱 AI 正式上线并开源新一代旗舰模型 GLM-5.2。该模型专为 Coding 与长程任务能力打造，在全球百万用户参与盲测的前端开发评估系统 Code Arena 上取得全球可用模型第一的表现。核心特色包括 1M 无损上下文（非 PPT 指标）、强化 Coding 能力、Day 0 适配国产算力平台，并采用 MIT 开源协议——可商用、可微调、可私有化部署。

GLM-5.2 同时兼容 Claude Code / OpenCode / Cline 等主流 Coding Agent 工具，面向 Agentic Engineering 优化。此前智谱已投入大半年攻关 Coding 领域，先后推出 GLM-4.5 代码基座与 GLM-4.7 国产最优 Coding 模型。

GLM-5.2 核心能力
  • 1M 真正可用上下文（非宣传指标）
  • Code Arena 前端开发盲测全球第一
  • 面向 Agentic Engineering 优化
  • Day 0 适配国产算力平台
  • MIT 协议：商用/微调/私有部署全开放
国产 Coding 四强格局
  • GLM-5.2：自研 Agent + MIT 开源
  • Kimi K2.7 Code：开源兼容多模型
  • Qwen 3.7 Max：通用兼顾 Coding
  • MiniMax M3：长上下文特化
  • 6 月进入「淘汰赛」阶段
💡 为什么重要

第一，「模型随时可能被收回」的焦虑有了国产答案——上周 Anthropic 被曝切断高端模型访问，GLM-5.2 此时选择 MIT 开源（可商用、可私有化部署），直接对标「自主可控」叙事，企业客户不再担心模型断供。第二，开源路线正在证明 Coding 实力——GLM-5.2 在 Code Arena 盲测击败 Claude Code、GPT-5.5 等闭源模型成为全球可用模型第一，说明开源 Coding 模型已具备与顶级闭源模型抗衡的能力。第三，国产编程模型分化加速——GLM-5.2（自研 Agent）、Kimi（开源兼容）、Qwen（通用兼顾）、MiniMax（长上下文）形成清晰差异化，6 月进入淘汰赛阶段。

Agent 入主 工作流编排

3Adobe Creative Agent 全面嵌入 Creative Cloud——AI Agent 从「对话式工具」升级为「多步骤工作流编排器」

6 月 18 日，Adobe 宣布将旗下 Creative Agent 全面嵌入 Creative Cloud 核心产品——Photoshop、Premiere、Illustrator、InDesign 和 Frame.io 同日上线公测版 AI Assistant。这是 AI Agent 从「单步对话式工具」升级为「多步骤工作流编排器」的关键标志：用户只需描述期望结果，Agent 自动编排跨步骤、跨工具的复杂流程并执行。

与此同时，Adobe Firefly 升级为全流程创意 AI Studio，新增品牌套件生成、短视频创作、分镜生成等功能；Adobe 还将创意工具接入 ChatGPT、Claude、Copilot、Gemini 和 Slack 等主流 AI 平台，覆盖数亿用户。

各产品 AI Assistant 能力
  • Premiere：自动分类素材、批量命名、识别访谈问题、组装初始剪辑
  • Photoshop：描述结果即执行——换背景、跨平台尺寸适配、图层编排
  • Illustrator：从表格批量生成 50 个版本文件、预检颜色模式/字体
  • InDesign：导入品牌 PDF 自动更新所有版面排版
  • Frame.io：整理拍摄素材、跨版本反馈、生成 B-roll
战略意义
  • 从「生成式工具」进化为「工作流编排 Agent」
  • 创意决策始终由人掌控，Agent 执行编排
  • 接入 5 大 AI 平台：ChatGPT / Claude / Copilot / Gemini / Slack
  • 覆盖 数亿 用户的工作场景
  • 75% 创作者视 AI 为必需品，但 85% 要求决策权归人
💡 为什么重要

这是 AI Agent 从「辅助工具」迈向「工作流引擎」的分水岭事件。第一，Agent 能力范式升级——此前 AI 工具多是「你问一步它答一步」的对话式交互，Adobe Creative Agent 做的是「你说结果，它编排全流程」的多步骤自主执行——这与 AI Coding Agent 在软件开发中的演进方向完全一致。第二，「创意主权」叙事——Adobe 调查显示 85% 创作者要求「最终决策归人」，这与 Anthropic 的「安全优先」路线形成呼应：Agent 做执行，人做判断。第三，跨平台覆盖——将创意工具接入 ChatGPT、Claude、Copilot 等五大平台，意味着「AI Agent 生态互联」时代正式开启。

具身智能方向

460 亿 马太效应

42026 上半年 460 亿砸向具身智能——288 起融资但资金极度集中于头部 20 家，产业化与淘汰赛同步启动

据 IT 桔子数据，2026 年上半年国内具身智能及机器人领域共发生 288 赞融资事件，涉及 226 家企业和 274 家投资机构，披露融资总额超 460 亿元。但资金分配极度失衡——头部约 20 家企业吸纳了绝大部分资金，多数中小玩家仍在「玩不起」的境地。一位美元基金合伙人转发千寻智能 A+ 轮 15 亿融资后配文「玩不起」，随后删除。

与此同时，工信部与国务院国资委联合启动 2026 年度人形机器人与具身智能实景实训专项行动，聚焦工业、服务、特种等领域重点场景，强调以真实场景应用牵引产业发展。宇树科技（年出货 5500 台）科创板 IPO 过会、智元（下线 5000 台）量产交付，人形机器人正从实验室走向工厂车间。

投融资全景
  • 融资事件：288 起
  • 涉及企业：226 家
  • 投资机构：274 家
  • 披露总额：460+ 亿元
  • 资金分配：头部 20 家占绝大部分
产业落地关键节点
  • 工信部+国资委：实景实训专项行动启动
  • 宇树科技：科创板 IPO 过会，营收 16.99 亿
  • 智元机器人：量产下线 5000 台
  • 国内首份具身智能行业标准 YD/T 6770 已实施
  • 智源大会：具身原生基础模型有望涌现
💡 为什么重要

两条并行线索揭示具身智能赛道的真实生态。第一，「460 亿但玩不起」——资本的马太效应：资金高度集中于千寻智能、宇树科技等头部玩家，中小企业融资难度加剧。这意味着赛道已进入淘汰赛阶段，「量产交付」成为硬门槛——能出货的吸金，不能出货的出局。第二，政策与标准双轮驱动：工信部实景实训专项行动要求「以真实场景牵引」，具身智能行业标准落地提供统一技术框架——政策正在从「鼓励创新」转向「强制筛选」，加速优胜劣汰。第三，从概念爆发到量产交付：如果说 2024 年是「概念爆发年」，2025-2026 年则是「量产交付年」——宇树 5500 台、智元 5000 台的数据说明人形机器人已走出实验室。

安全框架 IPO 竞速

5Anthropic 与白宫合作 AI 安全漏洞框架 + OpenAI 双线冲刺 IPO——安全合规与资本竞速进入关键窗口

6 月 18 日多方消息：Anthropic 正与美国白宫合作开发一套标准化 AI 安全漏洞评估框架，旨在为 AI 安全漏洞的严重程度建立统一评估指标——这是美国政府在 AI 安全协议标准化方面迈出的具体一步。但与此同时，Anthropic 因与特朗普政府在出口管制上的冲突，无法发布 Claude Mythos 5 模型，合规标准不明确为 AI 公司带来严重运营不确定性。

OpenAI 同日两步棋并行：招募 Transformer 核心作者 Noam Shazeer（技术储备）+ 前政策官员 Dean Ball（监管合规），IPO 竞速进入关键窗口。奥特曼此前预计 OpenAI 将在未来一年内上市，GPT-5.6 或将于本月发布。

Anthropic 困境
  • 与白宫合作：AI 安全漏洞评估框架
  • 出口管制冲突：无法发布 Mythos 5
  • Fable 5 发布后「降智」「数据政策」争议
  • 估值约 9650 亿美元（超越 OpenAI）
  • 已秘密提交 S-1 草案
OpenAI 冲刺
  • Shazeer 加入：架构研究负责人
  • Dean Ball 加入：AI 政策合规储备
  • 估值约 8520 亿美元
  • GPT-5.6 或本月发布（内部代号 iris-alpha）
  • 奥特曼预计一年内 IPO
💡 为什么重要

这一天的动态勾勒出 AI 行业两条并行且相互缠绕的线。第一，AI 安全正从「自愿自律」升级为「强制合规」——白宫与 Anthropic 合作建立评估框架，意味着 AI 安全漏洞将像网络安全漏洞一样被标准化分级和强制披露；但 Mythos 5 被禁发布的事件说明，合规标准本身仍处于「实时制定」阶段，规则不清反而是最大的不确定性。第二，IPO 竞速倒逼技术与合规双线储备——OpenAI 同时招揽技术天才（Shazeer）与政策专家（Dean Ball），说明上市不只是资本事件，更是技术实力与合规能力的双重考验。第三，Anthropic 估值 9650 亿超越 OpenAI 的 8520 亿——资本市场正在用金钱投票：安全优先 vs 普惠化路线，谁的故事更值钱？
