腾讯混元 Hy3 正式发布：Agent 能力与产品体验跃升，WorkBuddy/CodeBuddy 已接入

大模型 Agent 腾讯

7 月 6 日，腾讯混元 Hy3 正式发布。该模型采用 MoE 架构，总参数 295B、激活参数 21B，支持 256K 上下文，在软件开发、办公生产、前端设计、CI/CD 等生产力任务上显著进步。Hy3 已接入 WorkBuddy/CodeBuddy、元宝、Marvis、ima 等多个业务；API 同步上线腾讯云 TokenHub，并采用 Apache 2.0 开源协议。

在 WorkBuddy 办公场景内部测评中，Hy3 任务成功率从 72% 升至 90%，平均耗时缩短 34%；在 Marvis Agent 多步骤协作评测中任务派发正确率达 92%。定价为输入 1 元/百万 tokens、输出 4 元/百万 tokens，输入缓存命中仅 0.25 元/百万 tokens。

值得关注的原因：Hy3 是腾讯混元重建底层后首个正式版，其「高性价比+强 Agent 能力」定位直接切中企业级应用。对日常用 WorkBuddy/CodeBuddy 的用户来说，这是能感知到的体验升级；对行业而言，它意味着国产 MoE 模型在办公 Agent、代码辅助、工具编排等真实业务链路上已能对标 2-5 倍参数的旗舰模型。

DeepSeek 生态补上编程 Agent：Deep Code 开源终端助手适配 DeepSeek-V4

AI Coding 开源 DeepSeek

一款名为 Deep Code 的第三方开源 AI 编程助手近日被收录进 DeepSeek Agent 工具，深度适配 DeepSeek-V4 系列模型（推荐 deepseek-v4-pro / deepseek-v4-flash）。该工具支持深度思考、推理强度控制、Agent Skills、MCP 集成以及细粒度权限控制，可通过 npm 安装并以 CLI 或 VS Code 插件形式使用。

Deep Code 覆盖读取/修改项目文件、执行 Shell 命令、恢复历史对话、调用 MCP 服务等常见 Agent 能力，并支持从 ./.deepcode/skills/、~/.agents/skills/ 等路径扫描自定义 Skills，方便团队封装内部流程与项目规范。GitHub 仓库已收获超 1500 star、127 fork。

值得关注的原因：Deep Code 的意义在于给 DeepSeek 生态补齐了一个「开箱即用的编程 Agent」入口。对国内开发者而言，DeepSeek-V4 系列模型性价比高、中文理解强，但此前缺少类似 Claude Code/Cursor 的终端原生体验；Deep Code 的出现降低了国产模型在真实工程链路中的使用门槛，也让「DeepSeek + MCP + 自定义 Skills」的组合成为可能。

美团 LongCat-2.0 正式开源：1.6 万亿参数 MoE，华为昇腾/摩尔线程/沐曦股份 Day-0 适配

AI Coding 国产算力 开源

7 月 6 日，美团宣布正式开源新一代基础大模型 LongCat-2.0 的全部模型权重、推理引擎与核心技术文档。该模型采用 MoE 架构，总参数规模 1.6 万亿，每个 Token 平均激活约 480 亿参数，原生支持 1M 超长上下文；预训练数据规模超 30 万亿 Tokens，训练峰值规模超 5 万张国产算力卡。

同日，华为昇腾、摩尔线程、沐曦股份等国产芯片厂商集体宣布完成 LongCat-2.0 的推理适配。美团称其为业界首个完全依靠国产算力完成训练和推理全流程的万亿参数大模型。王兴此前公开表示 AI 是美团的「必答题」。

值得关注的原因：LongCat-2.0 的核心价值不仅是参数规模，而是「国产算力训练 + 国产芯片推理」的全链路闭环。它验证了在受限环境下，用国产算力集群训练万亿参数 MoE 模型并开放权重是可行的。对 AI Coding 从业者而言，后续基于 LongCat-2.0 的长上下文代码理解、复杂任务执行等二次开发值得期待。

李飞飞团队发布 SimFoundry：一段真实视频即可生成无限机器人训练场

具身智能 Real2Sim 世界模型

李飞飞团队联合英伟达 GEAR 实验室、佐治亚理工大学等机构发布 SimFoundry 系统，提出 Real2Sim 新路径：仅需一段真实世界视频，即可自动生成可交互、可训练、可评测的机器人仿真环境。系统通过解析视频中的物体几何、物理属性与交互功能，先构建高精度「数字孪生」，再自动调整外观、形态、布局生成海量「数字表亲」，实现近乎无限的训练数据扩展。

实验显示，SimFoundry 在仿真中评测的机器人表现与真实世界结果高度一致；基于生成数据训练的策略可实现零样本迁移，在多步操作、双臂协作等复杂任务中表现优异。论文已公开于 arXiv。

值得关注的原因：SimFoundry 直击具身智能最昂贵的瓶颈——数据采集与仿真环境搭建。传统 Sim2Real 需要大量人工建模和真实采集，而 Real2Sim 让「一段视频 → 无限场景」成为可能，可能大幅降低机器人训练成本并加速从实验室到真实世界的迁移。对 VLA/世界模型赛道而言，这是数据生成范式的关键补充。

星动纪元完成新一轮 10 亿元融资：国资组团入场，物流场景已常态化 7×24 小时运营

具身智能 融资 落地

7 月 6 日，具身智能公司星动纪元宣布完成新一轮 10 亿元融资，由国务院国资委诚通基金领投，江西国控、国元股权、渝富中新基金、杭州资本等多家大型国资参与，中金雷诺、九坤创投、弘毅投资等跟投，老股东持续追加。至此，星动纪元在两个月内密集融资 25 亿元，年内累计融资超 35 亿元。

星动纪元是清华大学唯一直接持股的具身智能企业，已构建「数据-大脑-运控-灵巧手-本体」全栈自研体系，拥有全尺寸双足人形机器人星动 L7、轮式服务机器人星动 Q5 及全直驱五指灵巧手 XHAND 系列。其自研灵巧手已供货 OpenAI、波士顿动力、英伟达、苹果、字节跳动等全球头部客户；在物流场景，星动机器人已进驻顺丰、中国邮政等 10 余个物流中心，部分实现 7×24 小时运营，分拣效率达每小时 1200 余件。

值得关注的原因：国家级国资领投 + 头部产业客户落地，标志着具身智能赛道从「融资故事」进入「订单验证」阶段。星动纪元以灵巧手作为数据入口、以世界模型/VLA 作为大脑的路径，代表了当前具身智能「以数据闭环构建壁垒」的主流方向。其物流场景 7×24 小时运营是行业少有的真实商业化证据。
