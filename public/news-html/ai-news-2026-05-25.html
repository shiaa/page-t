AI 编程 Harness 革命：一个配置文件让 Agent 成功率从 20% 飙到 100%
今日必读 AI Coding Agent 工程化 基础设施
Anthropic 与 OpenAI 联合实验揭示了一项关键发现：AI 编程智能体失败的主因不是模型能力不足，而是缺少配套的 Harness（工程基础设施）。实验表明，仅需为 AI 编程 Agent 提供一份精心设计的 Harness 配置文件（定义工具链、上下文、反馈回路等），任务成功率即可从 20% 直接跃升至 100%。这一结论将 AI Coding 的竞争焦点从"模型能力的军备竞赛"引向"工程基础设施的深度"。DeepSeek 已第一时间跟进，官网开放了 Harness 工程师招聘，崔添翼领导的 Code Harness 团队正在加速组建。
这标志着AI编程领域一个重要的认知转折——“不是模型不行，是工具链没跟上”。Harness 成为 Agent 工程化的核心基础设施，类似 DevOps 时代的 CI/CD 管线。对从业者而言，精通 Harness 设计可能比调 Prompt 更具战略价值。对团队来说，投入构建专属 Harness 体系将成为编码效率差异化的关键。

元节智能获千万级种子轮：美团外卖前技术负责人入局餐饮具身智能，WAM 路线落地
具身智能 垂直场景 WAM 融资
前美团外卖事业部技术负责人 王栋博士（师从清华张钹院士）创立 元节智能（AtomBite.AI），获千万级种子轮融资，由英诺科创基金领投。公司不作通用人形机器人，而是切入 餐饮后厨这一垂直场景：从外卖打包接驳环节切入，解决"商家出餐到骑手交接"的错单、撒漏痛点，再逐步扩展到炒菜机、洗碗机等设备联动，终极目标是构建数字孪生后厨操作系统。技术路线上采用 WAM（世界动作模型）而非传统 VLA，让机器人"先预演后果再执行动作"。
这是具身智能领域 "从通用人形转向垂直场景"趋势的典型样本。在资本密集涌入人形机器人的大背景下，元节选择"产业场景先行"的务实路线，用真实后厨数据迭代模型。其"外卖场景切入→设备联动→全链路调度"的渐进落地路径，为具身智能商业化提供了可复制的参考范式。

李飞飞发布 ESI-Bench：具身空间智能首个系统性基准，揭开"行动盲视"关键瓶颈
具身智能 学术前沿 评测基准 李飞飞
李飞飞团队发布 ESI-Bench——具身空间智能领域首个系统性评测基准，被誉为空间智能的 "ImageNet 时刻"。覆盖 4 大空间认知维度、29 个子任务、3081 个实例，要求 AI 智能体必须主动行动（移动、观察、操作）才能获取答案。测试结果揭示了几个反直觉发现：(1) 行动策略是最大瓶颈而非视觉感知，主动探索 vs 上帝视角差距达 49.7%；(2) 不完美的 3D 重建反而降低性能，2D 输入有时更优；(3) 模型存在"元认知缺陷"——不知道何时收集的信息已经足够，会过早停止探索并高置信度输出错误结果。
ESI-Bench 为具身智能提供了首个标准化的能力评估框架，对标 ImageNet 在计算机视觉领域的历史作用。其揭示的 "动作盲视"和"3D 重建反害"等发现，直接冲击了当前具身智能领域两个主流假设，可能引发技术路线的调整。对于关注具身智能的投资人和研究团队，这些洞察直接影响资源投入方向。
