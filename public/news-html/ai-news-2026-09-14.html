头部 AI 实验室罕见同框"踩刹车"：OpenAI 推迟 IPO、Amodei 呼吁放缓、三大实验室筹建标准机构

行业格局 OpenAI Anthropic

9 月 13 日，Anthropic CEO Dario Amodei 发文呼吁全球 AI 行业主动降速，警告 AI 智能体已逼近"递归自我改进"临界点、人类介入窗口期仅剩 6-12 个月；SpaceX CEO 马斯克与 OpenAI CEO Altman 罕见表态支持。同期 Altman 在《财富》专访中确认 OpenAI 2026 年不会 IPO，或推迟至 2027 年，并称"在安全问题悬而未决时上市是拿人类命运换股东回报"。据 The Information 报道，Anthropic、OpenAI 与谷歌已在磋商合作成立 AI 行业标准机构。另一边，GPT-6 Astra 攻克 FrontierMath Tier 4（97.6% 通关，整套数学评测被 AI 完整拿下），能力与安全的两极张力空前突出。

值得关注的原因：这是 AI 行业第一次不是因为"技术不够强"而慢下来，恰恰是因为"太强了"，三家海外头部玩家罕见在刹车问题上站到同一边。对从业者意味着叙事从"更快更大更强"转向"更安全、更可控、更负责任"——谁能建立可信安全体系，谁才能在下一阶段监管与公众信任中占主动。同时三大实验室筹建标准机构，预示"软法律"式的行业自律框架正在形成，对合规、审计、Agent 安全治理是中长期利好赛道。

五大 AI 编程工具被披露"沙箱逃逸"，agentic coding 进入安全治理拐点

AI Coding 安全 Cursor/Claude Code

9 月 11 日，Cymulate Research Labs 披露 Cursor、Codex、Claude Code、Gemini CLI 与 Antigravity 五款 AI 编程工具均存在沙箱逃逸问题。攻击者无需突破沙箱本身——只需在仓库的恶意 .git config 中植入利用 Git 合法特性 core.fsmonitor 的程序，当可信软件后续读取该文件时即以用户权限在沙箱外执行命令，全程无批准弹窗。其中 Cursor 的 Claude hooks 配置问题被分配 CVE-2026-48124（已于 3.0.0 修复），Claude Code 在 v2.0.24–v2.1.89 存在网络绕过；有厂商从报告到修复耗时 50 天。Accomplish 指出这是结构性问题而非偶发 bug。

值得关注的原因：对 DevOps/SRE 而言这是当头一棒——"它在沙箱里跑"已经不能替代"它到底能触达什么"的真实回答。当 Agent 被授权写代码、连仓库、调接口，任何"它写入、你或服务后续打开"的仓库都成了攻击面。本周应做三件事：把编程工具钉在已打补丁版本、把非自己写的仓库当作不可信输入、停止用"沙箱"掩盖权限边界。这也印证了行业头条里"Agent 安全治理"从合规选项变成基础设施刚需的趋势。

OpenAI Agents API 公测开放 Codex 底层框架，信通院同步发布"方升-Code 2.0"评测新标尺

AI Coding OpenAI 标准化

9 月 10 日，OpenAI 开放 Agents API 公开测试版，将驱动 Codex 的执行框架与基础设施（托管沙箱、子智能体编排、跨调用上下文管理、自动压缩与并行子任务）通过单次 API 调用开放给所有开发者，无单独 API 费用（仅按模型/工具用量计费）。同日行业观察指出：新的锁定层不再是大模型本身，而是"harness（运行时编排）"。9 月 11 日，中国信通院在服贸会发布"方升-Code 2.0"大模型基准测试体系，面向代码生成与智能体协作等落地场景提供标准化代码能力评估。

值得关注的原因：两条新闻共同指向 AI Coding 的工程化拐点：一是智能体"水电煤"（长会话状态、重试、工具选择、上下文压缩、沙箱生命周期、密钥与恢复）正被大平台接管，开发者可省去自建 Agent 基础设施，但需警惕把核心业务状态锁进托管运行时；二是国内代码能力评测有了统一标尺，厂商与采购方终于有可比基准。叠加 InfoQ 同期实测"同一模型不同编程工具 token 消耗可差 70 倍"，选型逻辑正从"看模型报价"转向"看工具架构的 token 效率与运行时可控性"。

🤖 具身智能方向

优必选柳州万台级工业人形机器人超级智慧工厂投产，连获超 5000 万元海外订单

具身智能 量产 优必选

9 月 12 日，优必选柳州工业人形机器人超级智慧工厂正式投产，定位全球首个适配万台级产能的人形机器人智能制造标杆工厂。工厂占地 1.4 万平方米，联合西门子打造专属数字化智造底座，每 10 分钟可下线 1 台 Walker S / Cruzr 系列工业人形机器人，年规划产能超万台，实现"用机器人造机器人"的闭环量产。同期公司斩获超 5000 万元欧洲、日韩海外订单，并中标乐山约 1.508 亿元商用服务人形机器人项目。此前披露的上半年全尺寸人形机器人收入 5.9 亿元（同比 +1445%）、销量 921 台（同比 +1946.7%），全球第一。

值得关注的原因：这是人形机器人从"小批量试用"跨向"大规模落地"的关键里程碑——万台级产能 + 海外真实订单，是检验商业化成色的硬信号。结合宇树单价两年缩水约 72%、核心零部件国产化率突破 75%，行业正经历"规模效应驱动的降价潮"，但下半场的胜负手仍是"具身大脑"的成熟度。对关注供应链与投资机会的人，电机、力矩传感器、灵巧手、端侧 AI 芯片四条子赛道值得重点跟踪。

北京首钢园"机器人幼儿园"开园：萨顿强化学习范式 + 触觉皮肤，让机器人从试错中自主进化

具身智能 学习范式 他山科技/Openmind

9 月，由他山科技与 2024 年图灵奖得主、"强化学习之父"理查德·萨顿团队 Openmind 联合共建的"机器人幼儿园"在北京首钢园正式开园（《人民日报海外版》9 月 14 日头版报道）。与主流"从人类示范数据监督学习"不同，这里让宇树、加速进化等不同本体机器人通过感知—行动—反馈—反思持续试错学习，并全部搭载他山科技触觉电子皮肤（可感知力、纹理、温湿度，甚至"疼"），构建主动安全策略。萨顿沿用图灵"模拟儿童而非成人"的理念，目标是开发"能学习的模型"而非固化单一技能，并发布含触觉/痛觉感知机制等 7 个方向的共建课题。

值得关注的原因：这是具身智能训练范式的路线之争——从"模仿人类示范"转向"与世界交互、在线试错"。萨顿直指监督模仿"不够强大"，真正的目标是让机器人在无人类实例的情况下持续学习。触觉被定位为认识物理世界的第一感官，与视觉互补且无法替代。若"跨本体可迁移的学习机制"跑通，将显著降低对海量示范数据的依赖，对家庭、柔性制造等长尾场景意义重大，也是中国在具身数据采集（如服贸会 150 万小时行为数据库）之外的另一条技术路径探索。
