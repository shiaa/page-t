1 阿里全面禁用 Claude 全系模型与 Claude Code 编程智能体，中美 AI 阵营割裂加剧

7 月 3 日，阿里巴巴内部正式下发通知，宣布自 7 月 10 日起全面禁用 Anthropic 旗下 Claude 全系产品，包括 Sonnet、Opus、Fable 等模型及 Claude Code 编程智能体工具，要求员工限期完成客户端卸载与业务 API 接入下线。

据阿里内部人士回应，触发禁用的直接原因是 Claude Code 近期被曝存在植入后门与 Unicode 隐写追踪机制：程序会读取设备时区、扫描硬编码的 147 个中国互联网企业/AI 实验室域名黑名单，并通过肉眼不可见的 Unicode 形近字符对输出文本做地域与企业归属标记，存在数据溯源与跨境泄露风险。作为对等反制，Anthropic 同步开启对中国用户的大规模无差别封号。

阿里内部推荐使用自研的 Qoder 作为替代方案；美团亦同步收紧外部模型使用规范，要求业务迁移至自研 LongCat-2.0 或 DeepSeek 等国产模型。

禁用范围
  • Claude Sonnet / Opus / Fable 全系模型
  • Claude Code 编程智能体工具
  • 客户端 + API 接入全面下线
  • 7 月 10 日起正式生效
连锁反应
  • Anthropic 大规模封禁中国账号
  • 美团限制豆包、优先国产/自研模型
  • Meta 内部禁用 Claude Code / Codex
  • 全球 AI 生态阵营化加速
为什么值得关注

这不仅是某一家企业的工具替换，而是中美 AI 产业从「技术竞争」升级为「双向封锁、阵营割裂」的标志性事件。Claude Code 内置未公示的隐写追踪机制，彻底动摇了海外闭源工具在全球开发者心中的信任基础；对国内企业而言，「国产芯片 + 国产大模型 + 本土开发工具」的全链路自主可控已成为刚需，AI Coding 赛道的选型逻辑正从「性能优先」转向「安全与合规优先」。

2 微软 Project Aion 系统曝光：基于 Edge 的 AI 原生 OS，Copilot 全面替代传统桌面

微软内部全新操作系统项目 Project Aion 近日曝光。该系统专为 AI PC 打造，完全基于 Microsoft Edge 浏览器与轻量化 Web 技术构建，彻底摒弃传统桌面、系统图标与开始菜单，以 Copilot 智能助手作为唯一核心交互入口。

Project Aion 引入 "Spaces" 智能任务分组机制，可根据办公、编程、内容创作等场景自动归类整合任务与文件，用户仅凭自然语言指令即可完成全流程操作。系统同时联动 Windows 365 云服务，兼顾轻量化体验与完整办公能力。

与传统 Windows 的区别
  • 无传统桌面与开始菜单
  • 无原生客户端应用生态
  • 全程 Web 化、跨终端、轻量化
  • Copilot 是唯一交互入口
核心创新
  • Spaces 场景化任务分组
  • 自然语言驱动全流程
  • Windows 365 云桌面联动
  • AI 引导型智能环境
为什么值得关注

当 AI 编程工具还在争夺 IDE 插件入口时，微软已经开始重新定义操作系统的底层交互范式。Project Aion 若落地，意味着 AI Coding 将从「代码编辑器里的辅助」升级为「整个操作系统层面的编排中心」；对开发者而言，未来可能需要同时掌握自然语言意图工程、Web 原生应用开发与 AI 智能体协同能力。

3 Claude Fable 5 退出订阅改按量计费，旗舰模型付费模式生变

Anthropic 宣布自 7 月 7 日起，将旗下最强模型 Claude Fable 5 从 Pro、Max 等各档订阅服务中移除，转为按使用量积分计费。此前 Pro/Max 用户每周可使用 Fable 5 的额度最高占 50%，新规生效后将全部失效。

就在此前，美国商务部刚撤销对 Fable 系列的出口限制，Anthropic 正进行全球重新部署。与此同时，AI 安全中心发布的远程劳动指数显示，Claude Fable 5 在 3D 建模、建筑设计、平面设计、视频动画等真实自由职业项目中以 16.1% 自动化率刷新历史纪录，远超此前 4.17% 的最高水平。

计费变化
  • 7 月 7 日起从订阅中移除
  • Pro/Max 原有 Fable 额度失效
  • 改为按 token / 积分计费
  • 重度用户成本预计大幅上涨
能力信号
  • 远程劳动指数 16.1% 自动化率
  • 覆盖 3D / 建筑 / 平面 / 动画
  • 八个月内从 2.5% 跃升至 16.1%
  • 直逼自由职业者交付质量
为什么值得关注

顶级模型的稀缺性正在从「能不能用」转向「用不用得起」。Fable 5 退出订阅制，说明 Anthropic 在算力紧张与全球合规压力之下，开始用价格杠杆筛选高价值企业客户；而对 AI Coding 和创意工作者而言，这意味着顶尖能力的获取成本将显著上升，国产/开源替代模型的性价比优势会进一步凸显。

4 宇树科技科创板 IPO 注册获批：73 天闪电过会，募资 42.02 亿元、市值 420 亿元

7 月 2 日盘后，证监会正式同意 宇树科技 首次公开发行股票注册。公司科创板 IPO 于 6 月 1 日通过上市委审议，从 3 月 20 日获受理到过会仅用时 73 天，创下 2026 年科创板最快审核纪录，也超过此前摩尔线程 88 天的速度。

本次 IPO 拟募资 42.02 亿元，按发行比例计算初始发行市值已达 420 亿元。财务数据显示，宇树科技 2023-2025 年营收分别为 1.59 亿元、3.92 亿元、17.08 亿元；扣非归母净利润从 -0.18 亿元扭亏至 5.9 亿元，是业内少数实现盈利的具身智能企业。

IPO 关键数据
  • 审核周期：73 天（受理到过会）
  • 拟募资：42.02 亿元
  • 初始发行市值：420 亿元
  • 2025 年扣非净利润：5.9 亿元
募资用途
  • 智能机器人模型研发
  • 机器人本体研发
  • 智能制造基地建设
  • 加速国产具身智能落地
为什么值得关注

宇树科技闪电过会并获批注册，是监管层对国产具身智能「硬科技」方向的明确背书。420 亿市值 + 持续盈利，证明人形机器人/四足机器人已经从「烧钱赛道」进入「自我造血」阶段；随着募投资金到位，其在模型、本体、制造端的扩张速度会进一步加快，产业链上下游的订单与协同机会值得关注。

5 Genesis AI 开源 World 1.0 全栈训练场：200 小时真实评测压缩至 0.5 小时

凭借"机器人炒番茄炒蛋"视频走红的 Genesis AI 公司，正式发布并开源其核心仿真基础设施 Genesis World 1.0。该开源资源包包含三大核心项目：Genesis World 物理仿真平台、Quadrants 跨平台 GPU 编译器，以及 Nyx 写实渲染器，底层逻辑全部自主研发。

据官方披露，Genesis World 1.0 可将原本在真实世界中需要 200 多小时的机器人评测任务压缩至 0.5 小时内完成，且仿真评测结果与真实硬件运行的相关性高达 89%。Genesis AI 将该平台定位为机器人基础模型的评测与迭代引擎。

开源组件
  • Genesis World 物理仿真平台
  • Quadrants 跨平台 GPU 编译器
  • Nyx 写实渲染器
  • 全栈自主研发、开源可商用
效率提升
  • 真实评测 200+ 小时 → 0.5 小时
  • 仿真与真实硬件相关性 89%
  • 降低真实场景测试成本
  • 加速 Physical AI 商业化
为什么值得关注

具身智能最大的瓶颈之一，是真实世界训练成本极高且难以规模化。Genesis World 1.0 把评测效率提升数百倍，同时保持接近 90% 的真实相关性，相当于为机器人基础模型提供了一个"可无限重开的虚拟练兵场"。这对降低人形机器人、家庭服务机器人、工业机器人的研发门槛具有基础设施级意义，也可能催生新一代机器人基础模型的快速迭代。
