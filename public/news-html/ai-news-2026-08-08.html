Meta 发布首款 AI 编程智能体 Muse Code，以极致低价和崩溃恢复能力正面叫板 Claude Code 与 Codex

AI Coding Meta Muse Code

8 月 6 日，扎克伯格正式宣布 Meta 推出首款 AI 编程智能体 Muse Code 测试版，由最新基础模型 Muse Spark 1.2 驱动。产品定位为终端编程 Agent，支持一条命令安装，可自主分析项目结构、规划修改、编写代码、运行工具并验证结果，专为大型代码库的复杂软件工程任务设计。在 Terminal-Bench 2.1 基准测试中得分 82.9%，超过 OpenAI Codex（81.8%），但仍落后 Claude Code + Opus 5（86.7%）。核心差异化在于两点：一是本地事件日志机制实现崩溃后可从中断位置恢复，支持连续运行 24 小时的长周期任务；二是异步后台智能体架构在整个会话期间持续存活，减少重复信息收集。定价方面，按量付费每百万输入 token 1.25 美元 / 输出 token 4.25 美元，"贡献者版本"价格低至常规档的十分之一（需同意数据用于模型改进）。

值得关注的原因：这是 AI 编程 Agent 赛道竞争格局的一次重大变量——Meta 凭借全球最大单体代码仓库之一（Instagram、WhatsApp 后端）的训练数据和极致低价策略杀入战场。Muse Code 的工程可靠性设计（崩溃恢复 + 事件日志）直击当前 Coding Agent 的最大痛点：长时间任务中途崩溃导致全流程作废。对开发者而言，"贡献者版本"的低门槛定价可能成为个人开发者和小团队的首选，但数据隐私条款需要仔细评估。扎克伯格暗示开源方向正在讨论中——若 Muse Code 最终开源，将对 Claude Code 和 Codex 的商业模式构成降维打击。

Cursor 公布内部云环境架构：AI 编码智能体已写入超 50% 交付代码，但"原型廉价≠生产简单"

AI Coding Cursor 工程实践

8 月初，Cursor 详细披露了其内部为 AI 编码智能体构建的云端安全运行环境，该环境使 Agent 能够在 Cursor 自有代码库中安全运行和验证工作。Cursor 表示，目前这些编码智能体已经写入公司超过 50% 的交付代码。与此同时，一篇在开发者社区广泛传播的文章提出冷静观点：AI 让原型变得廉价，但并没有让生产系统变简单——生成代码是一回事，构建安全、可扩展、可观测、可维护的系统则是另一回事，工程判断力仍然是核心竞争力。

值得关注的原因：50% 的代码由 AI 生成是一个标志性数字，但更值得深思的是配套的冷静反思。Cursor 的实践揭示了一条关键规律：AI Coding 的真正价值不在于"写代码更快"，而在于"把编码智能体嵌入完整的工程工作流"——测试、审查、验证、部署环节才是决定 Agent 输出能否上线的分水岭。对 SRE/DevOps 从业者而言，这意味着未来的核心竞争力正从"会写代码"转向"会设计安全沙箱、自动化测试管线和代码审查流程"——这些恰恰是运维工程师的优势领域。

小米正式开源具身基座模型 Xiaomi-Robotics-1，基于 10 万小时真实操作数据预训练

具身智能 小米 开源模型

8 月 5 日，小米技术官方宣布具身基座模型 Xiaomi-Robotics-1 正式开源，代码已在 GitHub 和 Hugging Face 同步上线。该模型采用预训练+后训练两阶段范式：预训练阶段基于超过 10 万小时 UMI（Universal Manipulation Interface）数据学习通用动作生成能力，后训练阶段使用超过 1 万小时跨本体数据进行适配，实现对不同机器人硬件的泛化。模型输入为当前视觉观察和语言描述，输出为使场景从当前状态向目标状态变化的动作序列。本次开源覆盖从真机后训练到模型部署的完整流程，同时提供相关 Benchmark 的评测代码。

值得关注的原因：这是国内大厂首次以"10 万小时真实世界数据 + 完整部署流程"的规格开源具身基座模型，与 Google Gemini Robotics 2 的闭源 API 路线形成鲜明对比。10 万小时 UMI 数据的规模在国内具身领域属于第一梯队，跨本体后训练的设计思路意味着开发者不需要从零训练即可适配自己的机器人硬件。对中小型机器人团队和高校实验室，这大幅降低了进入具身智能研发的门槛——模型+评测+部署一条龙开源，相当于"具身智能的 Llama 时刻"。

越疆发布全球首款"具身全栖"人形机器人 DOBOT LUMO，瞄准千亿智能陪伴市场

具身智能 越疆科技 消费级

8 月 5 日，越疆科技正式发布全球首款"具身全栖"人形机器人越疆鹿萌（DOBOT LUMO）。该产品身高近 1.3 米，搭载全栈自研空弈具身大模型，实现多模态情绪感知、三维空间理解与主动行动、自主学习与长期进化三大突破。官宣视频全程实拍无特效，展示其在草坪、沙地、鹅卵石等复杂地形上的流畅步态，以及从户外运动陪练（出拳、闪躲、后空翻）到居家情感陪伴（情绪识别、音乐卡点舞蹈、夜间自动关灯）的场景切换。"具身全栖"理念涵盖空间全栖、角色全栖、能力全栖和周期全栖四个维度。越疆空弈大模型在具身智能国际权威基准 LIBERO 评测中以平均成功率全球第一登顶。

值得关注的原因：不同于多数人形机器人厂商聚焦工业场景，越疆选择直接切入消费级智能陪伴赛道，这是一个被严重低估的千亿级市场。全程实拍无特效的视频策略在"演示与量产之间存在鸿沟"的行业共识下尤其有说服力。结合近期供应链成本大幅下探（关键模组从百元级降至几百元级），"万元级机器人走进家庭"正在从概念变为可能。但消费场景的工程可靠性和安全标准比工业车间更严苛，产品能否真正交付并持续运营仍是待验证的命题。

Figure 03 自主攀爬工业梯子，移动操作耦合（loco-manipulation）首次以完整形态呈现

具身智能 Figure AI 技术突破

近期，Figure AI 创始人 Brett Adcock 在 X 上发布视频，展示 Figure 03 在实验室环境中自主攀爬工业梯子——无遥控、无人工协助、无预设动作序列。这在具身智能圈引发"历史性突破"的讨论。爬梯子之所以被视为标志性事件，并非因为"更高更快"，而是因为它首次将三种能力耦合进同一动态任务：实时视觉伺服（眼睛）、抓握扶手（手）和动态平衡攀爬（腿）必须同时工作，任何一环出错都会摔倒。此前的人形机器人演示大多是单能力展示（走路的归走路、抓取的归抓取），而爬梯子意味着移动操作耦合（loco-manipulation）第一次以完整形态出现。据 Figure 4 月发布的生产公告，Figure 03 产量已从每天 1 台提升至每小时 1 台，累计交付超 350 台，C 轮私募投后估值约 390 亿美元。

值得关注的原因：爬梯子的意义在于：在人类建造的环境中，梯子是最常见的垂直通道之一，机器人能自主攀爬意味着"没有机器人进不去的区域"。但需注意三个限定——视频未经独立验证、实验室能力不等于工厂能力、演示与时产体系必须合看。Figure 三层架构（System 2 语义理解 + 运动控制 + 视觉伺服）的工程化路径值得关注，它为整个行业提供了一个可参考的移动操作耦合技术范式。对供应链和投资视角而言，时产 1 台的量产能力比爬梯子视频更具信号价值。
