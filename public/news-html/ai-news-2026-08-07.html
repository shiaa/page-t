谷歌 AI 人事巨震：Hassabis 卸任 DeepMind CEO 转任董事长，Jeff Dean 效力 27 年后离职创业

人事巨震 Google DeepMind

8 月 5 日，谷歌母公司 Alphabet 官宣重磅人事调整：Google DeepMind 创始人兼 CEO Demis Hassabis 卸下日常管理职权，转任 DeepMind 董事长及 Alphabet 集团首席科学家，聚焦 AGI 长期战略。同时，效力谷歌 27 年的首席科学家 Jeff Dean 正式离职，将与 Sanjay Ghemawat、Oriol Vinyals、Quoc Le 三位核心技术大牛联合创办公益企业 Discovery Loop，致力于利用 AI 推动机器学习、科学和工程研究自动化。DeepMind CTO Koray Kavukcuoglu 接管实验室运营，晋升 SVP 直接向皮查伊汇报，负责 Gemini 4 研发。消息公布后 Alphabet 股价盘中暴跌超 5%，收盘跌 4.03%，单日市值蒸发超千亿美元。

值得关注的原因：Hassabis 和 Jeff Dean 是谷歌 AI 体系的两根"顶梁柱"，同时变动标志着谷歌 AI 从科研驱动进一步转向产品落地导向。Jeff Dean 带走的三人团队横跨谷歌底层分布式系统（MapReduce/BigTable）到大模型核心（Gemini/TensorFlow），堪称谷歌 AI 基础架构的集体流失。Discovery Loop 的愿景——用 AI 自动化"提出假设→实验→评估"的科研闭环，一旦打通递归自我改进（RSI），将从根本上改变 AI 自我进化的速度。对 AI Coding 领域而言，谷歌 Gemini 系列在编程能力上已被 Anthropic 和 OpenAI 拉开差距，领导层动荡可能进一步影响 Gemini 4 的编程能力迭代节奏。

Meta 发布首款 AI 编程智能体 Muse Code，以十分之一定价正面挑战 Claude Code 与 Codex

AI Coding Meta 编程智能体

8 月 5 日，Meta 正式发布旗下首款 AI 编程智能体 Muse Code 测试版，由 Meta 超级智能实验室 AI 负责人 Alexandr Wang 领衔推出。Muse Code 是一款终端编程智能体，搭载专为代码场景打造的 Muse Spark 1.2 大模型，可完成从大型代码仓库变更规划、代码撰写到运行结果验证的全流程工作，支持同时调度多款 AI 智能体协作开发。跑分方面，TerminalBench 2.1 实战开发测试拿到 82.9%（优于 Codex 的 81.8%，不及 Claude Code 的 86.7%）；DeepSWE 1.1 得分 59.3%。定价策略极为激进：按量付费每百万输入 token 1.25 美元、输出 4.25 美元，"贡献者版本"输出 token 仅 0.20 美元/百万，比竞品便宜 10 倍以上。产品同步上线"零数据留存"功能，不收集开发者数据用于模型迭代。

值得关注的原因：Meta 的入局标志着 AI 编程智能体赛道从"Claude Code vs Codex"的双雄格局进入三方混战。虽然跑分居中，但 Meta 的核心策略不是比拼尖端能力，而是以价格作为差异化武器——贡献者版本每百万输出 token 仅 0.20 美元，对比 Claude Sonnet 5 的 10 美元、Opus 5 的 25 美元，成本优势碾压级。这意味着 AI 编程工具的使用门槛将大幅降低，中小团队和独立开发者也能用上终端级编程智能体。"零数据留存"功能直击企业客户痛点，可能在 B 端市场形成差异化竞争力。对开发者而言，编程智能体价格战意味着更低的实验成本和更高的采用率。

从 Loop 到 Graph：AI Coding 范式六周内再次进化，多智能体图编排成为新焦点

编程范式 Graph Engineering 多Agent协同

仅火了一个多月的"Loop Engineering"（循环工程）概念正在被"Graph Engineering"（图工程）取代。当 Coding Agent 从单次回答走向连续执行、从单个 Agent 走向多智能体协作时，工程师要处理的问题从"怎样让它继续做"扩展到"这些工作该怎样连接"。Graph Engineering 的核心是任务编排系统——管理多个工作单元之间的连接、共享状态与选择路径。OpenAI Codex 已支持主 Agent 将探索、测试等独立工作委派给多个子 Agent 并行执行；Claude Code 的 Subagents 和实验性 AgentTeams 引入了团队负责人、共享任务列表、任务依赖和成员间通信；Cursor 2.4 版本也加入了默认与自定义 Subagents。LangGraph 和 Google ADK 2.0 则允许开发者显式定义节点、边、状态和路由。

值得关注的原因：AI Coding 正经历从"写代码的文员"到"工程团队"的范式跃迁。Prompt → Context → Harness → Loop → Graph 的五阶段进化路径，清晰展示了 AI 编程能力边界的持续扩张。Graph 阶段的关键突破在于：工程师不再只设计"怎样重复"，而是设计"多个执行单元怎样连接"——这直接对应真实软件工程中的分工、并行、回退和交接。但 Nature Machine Intelligence 的研究也提醒：在可拆分任务中多 Agent 最高提升 80.8%，在强顺序依赖任务中反而下降 70%，"组队"并非万能解法。对从业者而言，掌握 Graph 编排思维将成为使用和构建 AI 编程工具的核心竞争力。

DeepSeek 斥资 1.41 亿元入股宇树科技，签署联合开发人形机器人 AI 模型协议

资本合作 DeepSeek 宇树科技

8 月 6 日，"人形机器人第一股"宇树科技在科创板 IPO 战略配售中引入 DeepSeek，后者以约 1.41 亿元（约 2080 万美元）认购 93.34 万股，占战略配售的 2.31%，锁定期 36 个月。宇树科技发行价 150.8 元/股，发行市值约 610 亿元。除资金认购外，双方签署联合开发协议：DeepSeek 将把基础模型训练与推理优化能力，与宇树在机械结构设计、运动控制、具身智能方面的工程经验结合，共同打造面向人形机器人的专用 AI 模型体系。宇树未来采购模型训练服务优先选择 DeepSeek，DeepSeek 采购机器人硬件也优先选择宇树。腾讯、中石油昆仑资本、南方电网产融等也参与了战略配售。

值得关注的原因：这是 DeepSeek 首次直接持股机器人制造商，标志着头部大模型公司加速切入具身智能硬件赛道。大模型公司拥有"大脑"（语言推理、视觉理解），机器人公司拥有"身体"（运动控制、硬件迭代），两者的深度绑定将加速"AI+人形机器人"从实验室走向量产落地。宇树 G1 人形机器人零售价仅 1.6 万美元，是市面上最便宜的带关节手电动人形机器人，计划 2026 年 Q4 产能提升至 500 台/月。DeepSeek 的模型在 RT-2 操作任务和具身问答基准上表现强劲，与宇树低价硬件的结合，有望在消费级人形机器人市场形成"高性价比大脑+低成本身体"的差异化优势。

黎曼动力携手光轮智能与诺亦腾，共建百万小时具身智能数据底座

数据基建 黎曼动力 多模态数据

8 月 6 日，黎曼动力宣布与光轮智能、诺亦腾机器人达成战略合作，目标 2026 年底完成 100 万小时具身智能数据采集与训练，力争成为全球首个突破该规模的企业。三方分工明确：黎曼动力出"大脑"——Riemann-1.0 具身世界动作模型（在 RoboCasa-365 家务大考中以 62.6% 成功率拿下第一，高出此前行业纪录 8.4 个百分点）和 Matrix-Game 3.5 交互式世界模型；光轮智能负责"数据工厂"——EgoSuite 人类数据平台组织规模化多模态数据生产，RoboFinals 评测平台和 RoboStack 部署反馈平台完成验证闭环；诺亦腾机器人补"手感"——在人体动作捕捉（全球 70% 市场份额）、力反馈采集方面提供包含动作轨迹、关节运动、接触力觉的高精度多模态数据。

值得关注的原因：具身智能的核心瓶颈不在"看见"而在"手感"——机器人需要理解手指抓握的力度变化、关节运动状态和三维空间连续轨迹，这些数据光靠摄像头视频无法获取。百万小时多模态数据底座的建设，相当于为机器人通用大脑提供了从"视觉理解"到"触觉操作"的完整训练素材。更值得关注的是三方构建的"数据→模型→真机验证→反馈迭代"闭环：模型训练后真机跑验证，根据能力短板反推数据缺口，而非单纯堆数据规模。这种"模型驱动的数据采集"模式，可能成为具身智能数据工程的新标准。黎曼动力脱胎于昆仑万维 Matrix 世界模型团队，将游戏世界模型的"动作如何改变世界"理解迁移到机器人领域，技术路径值得关注。
