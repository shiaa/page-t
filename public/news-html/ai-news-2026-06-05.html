AI Coding 方向

本地 Agent 300 子 Agent 集群

月之暗面推出 Kimi Work Beta：支持 300 子 Agent 并行协作的通用本地智能体，92% 代码由 AI 自主生成

核心内容：6 月 3 日，月之暗面正式开启 Kimi Work Beta 内测，这是一款面向知识工作者的通用型本地 AI Agent，随 Mac 和 Windows 客户端同步上线。用户无需打开终端、写命令或配置环境，仅需用自然语言描述目标，Kimi Work 即可自动拆解任务、并行执行。

Agent 集群架构：基于 Kimi Code 内核与 K2.6 模型，支持调度最多 300 个子 Agent 协作处理复杂任务，可自动完成从读取本地文件、调用浏览器查询、生成深度报告到输出 PPT/表格/文档的全链路工作流。

AI 开发 AI：该产品本身由 Kimi Code 深度参与开发，开发团队仅用 1 周时间完成 Mac + Windows 双端 Beta 版本，累计产出超 5 万行有效代码，其中 92% 的代码由 AI 自主生成，成为"AI 编程工具开发 AI 编程工具"的典型案例。
300 子 Agent 并行架构标志着 AI Agent 从"单助手"模式迈入"团队协作"模式。月之暗面选择本地化部署路径（而非纯云端），直面 Claude Code、Cursor 等工具在数据隐私和成本控制上的痛点。92% AI 代码生成率更是一个里程碑式的数据——当 AI 工具能自主构建同类产品，"AI 编程"赛道的竞争壁垒正在被快速拉低，产品差异将从"模型能力"转向"工作流设计"。
Vibe Coding 基础设施 双厂入局

阿里达摩院发布「语构」AI 原生开发平台 + 百度千帆推出 Token 工厂与 Harness 工程

核心内容：国内两大科技巨头本周同步加码 AI Coding 基础设施建设。

阿里达摩院「语构」：推出以 Vibe Coding 为核心的 AI 原生开发平台，用户可通过一句话或语音指令快速启动项目，无需编写代码即可将想法转化为可用数字产品。产品主打差异化体验，支持自然语言零代码应用开发。

百度千帆 Harness 工程：推出面向智能体时代的 Token 工厂与 Harness 工程，核心指标全面升级——推理速度提升 25%、首 Token 延迟降低 16%、Token 消耗减少 23%，任务成功率达 95%，已支持 150 个主流模型。Harness 工程旨在解决 AI 编程中"模型能力足够但任务执行成功率低"的工程化瓶颈。
阿里和百度的同步入局释放明确信号：Vibe Coding 不再只是创业公司的赛道，已升级为大厂必争的基础设施战场。「语构」将 AI 编程能力向下渗透至零代码用户群体，而百度千帆 Harness 则从工程化层面解决 AI Agent 任务执行的可靠性问题——两者分别从"降低门槛"和"提升成功率"两个方向，共同推动 AI Coding 从开发者工具走向全民生产力平台。

具身智能方向

具身基座模型 击败英伟达

千寻智能 Spirit v1.6 登顶北美「具身奥林匹克」RoboArena 榜首，力压英伟达 Cosmos 3

核心内容：6 月 3 日，千寻智能官宣自研具身基座模型 Spirit v1.6 在北美 RoboArena 榜单（被称为"具身奥林匹克"）登顶，力压英伟达 Cosmos 3 与 Physical Intelligence Pi0.5 模型。

实战表现：在多组真实场景双盲 A/B 实测中，Spirit v1.6 在翻盖开合、精细物件抓取、多步骤连续任务等复杂场景形成完整流畅的动作闭环。以"翻开笔记本"任务为例：Spirit v1.6 可模仿人手动作流畅完成全流程，而英伟达 Cosmos 3 未能打开笔记本。

融资里程碑：同日官宣完成 15 亿元 A+ 轮融资，3 个月内完成 4 轮累计近 50 亿元融资。资金将聚焦新一代基座模型研发、百万小时级真实世界交互数据基础设施建设，以及在宁德时代、京东、博世等标杆企业的商业化落地。
中国具身智能初创公司在北美权威评测中击败英伟达，这是一个具有标志性意义的里程碑。Spirit v1.6 在精细物理交互任务上展现的优势，证明了中国团队在"世界模型+动作执行"链路上的快速迭代能力。3 个月 50 亿的融资速度刷新赛道纪录，且资金明确投向"真实数据基础设施建设"——在具身智能领域，数据飞轮（场景→数据→模型→场景）正在取代纯模型参数竞赛，成为新的竞争核心。
具身智能融资 估值双双破局

星尘智能 3 轮 B 轮融资超 10 亿估值破百亿 + 戴盟机器人获中国电信亿元级 A 轮投资

核心内容：6 月 3 日，具身智能赛道迎来融资密集爆发日，两家头部企业同步完成大额融资。

星尘智能（Astribot）：有"中国版 Figure"之称的绳驱 AI 机器人公司，3 个月内完成 3 轮 B 轮系列融资，总额超 10 亿元，估值突破 100 亿元，跻身中国具身智能第一梯队。其新一代绳驱机器人 T1 定价 8.99 万元起，6 月 1 日已正式发货，已实现千台级交付。投资方包括博华资本、中科创达、科德教育、国科投资等。

戴盟机器人：完成 亿元级 A 轮融资，由汇川产投与中国电信共同投资，前阿里通义多模态专家袁伟浩加入担任首席 AI 科学家，将聚焦物理世界模型研发。

赛道全景：加上千寻智能近 50 亿融资、宇树科技 IPO 过会，6 月第一周具身智能赛道融资总额已超 60 亿元。
"千台级交付"是星尘智能最值得关注的数据——它意味着具身智能机器人已跨越"实验室样机"阶段进入规模化量产。8.99 万元的定价拉低了高精细操作机器人的商业化门槛，而绳驱技术路线提供了一条不同于电机直驱的差异化路径。中国电信入局戴盟机器人更释放了一个信号：电信运营商开始将具身智能视为 5G/6G 网络的关键落地场景，"网+机器人"的融合生态正在形成。

行业动态

开源模型 16GB 本地运行

Google DeepMind 发布 Gemma 4 12B：无编码器原生多模态架构，MacBook Air 即可离线运行

核心内容：6 月 4 日，Google DeepMind 发布 Gemma 4 12B 开源模型，这是 Gemma 系列首个支持原生音频输入的中等规模无编码器多模态模型，采用 Apache 2.0 协议完全开放。

架构创新：完全移除传统图像与音频编码器，视觉信息通过极轻量嵌入模块直接输入语言模型主干，原始音频信号直接投影到文本 Token 空间。内置多 Token 预测（MTP）草稿器降低推理延迟。

性能与部署：标准评测成绩接近 Gemma 4 26B MoE 模型，但内存占用不到其一半。仅需 16GB 统一内存即可运行，入门级 MacBook Air（M5）可完全离线使用。Gemma 4 系列全球总下载量已超 1.5 亿次。

Agent 能力：支持多步推理和智能体工作流，可基于模型构建本地或边缘侧 Agent 应用，无 Token 使用限制，适配 Hugging Face、llama.cpp、vLLM 等主流框架。
Gemma 4 12B 的核心价值在于"将多模态 Agent 能力装进笔记本电脑"。16GB 内存门槛意味着开发者可以在不依赖云端的情况下构建本地 AI Agent，这对数据隐私敏感场景（金融、医疗、企业内部工具）意义重大。无编码器架构的探索为行业提供了一条降低多模态模型推理成本的新路径，Apache 2.0 协议的完全开放也让它成为开源社区构建 AI Coding 工具和具身智能系统的优质基座选择。
