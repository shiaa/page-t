工信部、国资委启动 2026 实景实训专项行动，经济日报定调：具身智能从"运动能力"转向"作业能力"

产业政策 实景实训 方向信号

今年 6 月，工信部、国务院国资委联合启动 2026 年度人形机器人与具身智能实景实训专项行动，推动重点产品在代表性场景中完成应用验证和常态部署，开启"作业模式"。9 月 12 日《经济日报》发文强调，产业竞争正由单一整机突破向模型、数据、本体、制造协同发展转变，需防止"重展示轻应用、重数量轻质量"，并以上海、江西、杭州等地真实场景应用为例说明落地进展。

值得关注的原因：从政策到主流媒体层面，都明确把"能不能真实干活"设为产业考核标尺。这意味着具身智能的评估重心正从跑跳等运动能力，转向稳定抓取、装配、操作工具的作业能力——对关注该赛道投融资、供应链与岗位机会的人，这是判断企业能否越过产业化临界点的关键风向标。

💻 AI Coding 方向

微软杰出工程师 David Fowler："手敲代码的时代已彻底终结"，Copilot Agent 接管完整开发流程

AI Coding Microsoft 范式拐点

9 月 3 日，微软杰出工程师、Aspire 负责人 David Fowler 在 X 上表态"typing code is absolutely over"。支撑这一判断的是一整套基础设施：GitHub Copilot 的 coding agent 现在能自主搭建环境、改仓库、跑测试、开 PR 供人审查，并已支持 Windows 开发环境与 WSL 跨链；Aspire 13.1/13.2 接入 MCP，让 Agent 直接启动服务、排查遥测、读取日志并自动修复崩溃；9 月 4 日公布的 Project Zenith 推出 64GB 统一内存、250GB/s 带宽的本地大模型开发机（首发 AMD Ryzen AI Halo）；MDASH 则用 100+ 个 Agent 扫描 Windows、Azure 与身份系统漏洞。

值得关注的原因：这是软件开发从"写代码"到"编排 Agent"的范式拐点。但拐点伴随质量隐忧——Veracode 报告称 44% 的 AI 生成代码含已知安全漏洞，因此 MDASH 这类"用 Agent 做质量门禁"正成为刚需。对 DevOps/SRE 而言，Agent 接管环境搭建与故障排查是减负的直接红利，但"人审 AI 产出"的复核职责只会更重。

OpenHands 1.0 发布：开源自治编程 Agent 走到"生产可用"，成本仅商业方案约 5%

AI Coding 开源 自托管

9 月 8 日，All Hands AI 发布 OpenHands 1.0（前身 OpenDevin）——首个达到"生产可用"的开源自治编程 Agent。它在 SWE-bench Verified 上配合 Qwen3-Coder-480B 完成 68% 任务、配合 Claude Sonnet 4.5 达 72%；内置生产级 Docker 沙箱隔离、LLM 安全分析器（按 LOW/MEDIUM/HIGH 给每次动作打分）、非 root 执行、BYOM 自托管与插件系统。自托管每任务成本约 0.2–1.05 美元，约为 Devin 等商业方案的 5%。

值得关注的原因：开源侧第一次把"安全隔离 + 自托管"做成开箱即用，给不愿把代码库交给闭源云服务的团队一个可审计、可复现的选项。对教学、企业内训和敏感代码场景尤其关键——无需依赖外部 API 即可本地搭建可控的 Agent 实验环境。结合同日 GitHub Copilot Workspace 的多 Agent 并行，编程 Agent 主线正从"更强单人"转向"带护栏的编排团队"。

🤖 具身智能方向

《经济日报》聚焦"灵巧手"：成为具身智能从"秀场"走向"用场"的关键一环

具身智能 灵巧手 作业能力

9 月 12 日《经济日报》以"人形机器人可望不再无从下手"为题指出，机器人比拼正在发生变化：会跑、会跳、会交互已不再是唯一看点，能不能稳定抓取、装配、操作工具正成为新的能力标尺。2026 世界机器人大会与第二届世界人形机器人运动会相继举办后，产业链创新集中亮相；《2026 年人形机器人产业发展报告》显示，上半年中国人形机器人出货量已超 4 万台、全球占比升至 97%。文章强调，灵巧手不只是整机末端零部件，更是智能作用于物理世界的直接界面，其价值还延伸到数据采集环节。

值得关注的原因：从"运动能力竞赛"转向"作业能力竞赛"，意味着整机的价值锚点从炫技演示下沉到真实操作闭环。灵巧手的单指独立控制、多指时序协同与容错能力，以及背后的遥操作/模仿数据采集，是产业化落地的关键底座——这恰是研发、投资与岗位机会最值得跟踪的子赛道。

具身智能 场景落地 一脑多机

9 月 9–12 日 2026 Inclusion·外滩大会在上海举行，超 300 家企业参展，其中 40+ 具身智能厂商集中亮相，今年展区重心从"跑跳演示"转向产业与生活场景"真干活"：蚂蚁灵波 × 国大药房"机器人智慧药房"已在零售店真实落地，可在 80cm 窄通道内自主接单、识别、分拣、交付；灵心巧手 Linker Hand L6 以 0.35 秒高速开合完成钢琴演奏，验证单指独立控制、多指时序协同与机械臂协同三项核心能力，可迁移至精密装配；眸深智能轮式双臂机器人自主完成洗衣机螺栓抓取、定位、插入、拧紧；辰行远略的飞行智能体 + 机器狗进入核电、地铁、水厂等无 GPS/无光受限空间巡检。灵波 LingBot-VLA2.0 已适配 17 个主流机器人品牌、20 种构型，呈现"一脑多机"走向千行百业。

值得关注的原因："一脑多机、千行百业"从口号走向门店真实部署，说明具身智能的评估标准正从运动能力转向作业成功率与场景适配。灵巧手核心能力、VLA 模型泛化与跨本体适配，成为能否规模化的硬指标；同时数据要素跨境流通平台的亮相，补上了真实数据迭代的关键一环。
