行业头条

终极交汇 全面开源

1英伟达 ENPIRE：8 个 AI Coding Agent + 8 台机器人组队自主科研——自学插 GPU 显卡，全部开源

6 月 18 日，英伟达 GEAR 实验室具身智能负责人 Jim Fan 公布了名为 ENPIRE 的全新项目。8 个 AI coding agent（基于 Codex / Claude Code / Kimi Code）与 8 台 YAM 机械臂组成一支"科研团队"：它们自己设计实验、自己修改代码、自己验证结果，并持续优化机器人策略——人类研究员只负责设定目标和观察结果。

最引人注目的成果：机器人全自主完成了毫米级精度的 GPU 显卡插拔操作（PCIe 金手指对接 + 卡扣锁死），以及4mm 孔径插针、剪扎带等高精度任务。在插针任务中，agent 自主尝试行为克隆、在线/离线强化学习等多种策略，最终实现连续 50 次成功插针。更震撼的是——英伟达宣布将整套算法、端到端模型和硬件控制接口全面开源。

ENPIRE 核心突破
  • AutoResearch 进入物理世界：Agent 不只在屏幕里写代码，还驱动机器人抓取、插入、剪切
  • 模拟→真实泛化：3 个 Agent 模拟全成功，2 个在真机上失败——物理世界的不确定性是新挑战
  • 两阶段架构：人搭基础设施→Agent 全自主研究
  • 连续 50 次成功插针（4mm 孔径）
  • GPU 插入任务：毫米级力控 + 视觉反馈
Scaling 新范式
  • 1 台机器人：1.5h+ 达到近完美成功率
  • 4 台机器人：约 50 分钟
  • 8 台机器人：约 40 分钟
  • 机器人数量成为新的 Scaling 资源
  • 经验迁移：插针经验→GPU 插入（Markdown 文档而非参数）

"我们所做的只是为 Codex 提供了一个通往原子世界的 API，其余的一切都是涌现。"——Jim Fan

💡 为什么重要

这是 AI Coding 与具身智能两个赛道终极交汇的标志性事件。第一，AI Coding Agent 第一次拥有了物理身体——过去 Agent 只在屏幕里写代码、跑程序；现在它们写下的代码直接驱动机器人去抓取、插入、剪切真实物体。代码不再只是数字结果，而是物理世界的动作。第二，「机器人数量成为新的 Scaling 资源」——过去大模型靠更多 GPU 提升能力，ENPIRE 证明增加机器人数量也能加速研发；这是 Scaling Law 从硅基世界向碳基世界的延伸。第三，全面开源 =「机器人的安卓」——马斯克 Optimus 走苹果式闭环路线，英伟达选择开源路线让全球所有机器人厂商免费获得顶级"网管大脑"，这是「开源安卓生态」对抗「闭环苹果帝国」的终极对决。

AI Coding 方向

Agentic IDE 苹果生态

2苹果 Xcode 27 首次深度集成 AI 智能体——自然语言修 Bug、构建 App，接入 Claude / GPT / Gemini

6 月 18 日，苹果在 WWDC 2026 后发布《Apple 智能与 Xcode 揭秘》特别讲座，正式宣布 Xcode 27 核心组成部件首次整合 AI 智能体。这是苹果 IDE 从"辅助补全"到"Agentic Coding"的范式跃迁：

AI 智能体能理解 Swift 语言，通过自然语言多轮对话帮助开发者完成编程任务；支持跨多个文件修改整个代码库；可根据提示和资源（如图标）独立构建完整应用。更重要的是，Xcode 27 支持接入 Anthropic、OpenAI 和 Google 等第三方 AI 模型——苹果不再封闭，而是开放选择。

技术层面，苹果引入 Core AI 框架，提供现代 Swift API 调用端侧 AI 模型；同时升级开源框架 MLX，让 AI 能力深度融入开发流程。这是库克 CEO 任内最后一届 WWDC，AI 落地系统和工具链成为最大主题。

Xcode 27 AI 能力
  • 自然语言修 Bug：描述问题→Agent 定位+修复
  • 跨文件代码库修改：多轮对话 + 全项目范围
  • 独立构建 App：提示 + 资源→完整应用
  • 接入 Claude / GPT / Gemini 等第三方模型
  • Core AI 框架 + MLX 端侧推理
Agentic Coding 趋势
  • 苹果：Xcode 27 + Core AI + 开放模型
  • Adobe：Creative Agent 全线嵌入
  • OpenCode：开源 Agent 登顶实力榜
  • Claude Code：SWE-bench 80.8% 性能领先
  • 2026 = Agentic IDE 从「补全」到「编排」之年
💡 为什么重要

第一，Agentic Coding 正式进入主流 IDE——苹果不是在 Xcode 里加一个聊天窗口，而是将 AI Agent 作为核心组件深度整合，这意味着全球数百万 iOS/macOS 开发者的日常工作流将从根本上改变。第二，苹果放弃封闭、拥抱开放模型生态——Xcode 27 支持接入 Claude、GPT、Gemini 等第三方模型，这打破了苹果一贯的"自给自足"路线，说明在 AI Coding 时代，「模型无关」已成为刚需而非选项。第三，与 ENPIRE 形成呼应——英伟达让 Agent 从屏幕走向物理世界，苹果让 Agent 从对话走向全项目编排；两条路线殊途同归：AI Agent 正从"辅助工具"升级为"自主工作流引擎"。

开源王者 格局重塑

3OpenCode 登顶 LogRocket AI 开发工具实力榜第一——开源编程 Agent 的逆袭：160K+ Stars、750 万 MAU

据 LogRocket 2026 年 6 月版《AI Dev Tool Power Rankings》，开源编程代理 OpenCode 一举超越 Cursor、Claude Code 等众多强敌，登顶 AI 开发工具排行榜第一名。关键数据：160K+ GitHub Stars（部分统计已达 172K）、750 万月活用户、75+ 个模型即插即用。

OpenCode 从 2025 年 6 月上线到 2026 年 6 月登顶，不到一年完成了从"无名小卒"到"开源 AI 编程之王"的跨越。登顶的关键维度是价值主张（MIT 开源 + 免费 + 自托管）和可访问性（75+ 模型广覆盖），而非纯粹的极致性能——Claude Code 在 SWE-bench 上仍以 80.8% 领先。

OpenCode 登顶密码
  • Model-Agnostic：75+ 模型自由切换，不绑定厂商
  • MIT 开源：源码可审查、可二次开发
  • CLI 原生：终端深度契合资深开发者
  • 社区飞轮：插件生态 + 提示词模板持续丰富
  • 可配合 Ollama 完全离线运行（air-gapped）
2026 编程 Agent 五强
  • #1 OpenCode：开源、模型无关、社区王者
  • #2 Claude Code：性能最强（SWE-bench 80.8%）
  • #3 Codex CLI：Terminal-Bench 83.4%
  • #4 GitHub Copilot：企业/IDE 领域稳定领导者
  • #5 Cursor：$20/月综合性价比之选
💡 为什么重要

OpenCode 的登顶传递了三个清晰信号。第一，「开源正在反超闭源」——当模型能力趋同，开发者更看重"自由度"和"成本"；OpenCode 在价值主张和可访问性维度几乎没有对手。第二，「模型无关」成为刚需——上周 Anthropic 被曝切断高端模型访问、SK Telecom 因出口管制被切断 Mythos 访问，单一厂商绑定越来越被视为风险；OpenCode 的 75+ 模型即插即用直接回应了这一焦虑。第三，CLI 工作流复兴——在 IDE 普遍臃肿的今天，轻量、可组合的终端工具重新获得青睐；英伟达 ENPIRE 的 Agent 也是 CLI-native，两条线索指向同一个方向：编程 Agent 的未来是终端原生、模型无关、社区驱动。

具身智能方向

家庭场景 自研大模型

4越疆发布下一代家庭陪伴交互 AI 人形机器人——搭载自研"空弈 DobotWAM"具身大模型，人形机器人从工厂走向家庭

6 月 16 日，深圳市越疆科技股份有限公司（02432.HK）预告即将发布下一代陪伴交互 AI 人形机器人，宣告重新定义家庭具身智能赛道。这款新品搭载越疆全栈自研的 "空弈 DobotWAM"具身大模型——号称全球最"懂物理"的具身大脑，具备理解人、适配人、服务人的全维度智能能力。

产品专为家庭场景打造：外形亲和可爱，语音交互流畅自然，是能陪伴交互、家务协助、安全守护的家用机器人。这标志着人形机器人从工商业场景向真实家庭场景的里程碑式跨越。越疆此前已在全球累计出货协作机器人超 80 万台，覆盖 70+ 国家，此次从工业协作机器人向家庭人形机器人延伸，是对自身技术栈和商业模式的双重拓展。

空弈 DobotWAM
  • 全栈自研具身大模型
  • "懂物理"：空间理解 + 物体交互 + 力控直觉
  • 理解人：语音交互流畅自然
  • 适配人：个性化行为适配
  • 服务人：家务协助 + 安全守护
人形机器人场景迁移
  • 2024：概念爆发年（融资 + 展示视频）
  • 2025-2026：量产交付年（工厂 + 工业）
  • 越疆新品：家庭场景里程碑
  • 宇树：5500 台年出货（工业/物流）
  • 智元：5000 台量产下线（工业组装）
💡 为什么重要

第一，人形机器人从"工厂车间"走向"家庭客厅"——此前宇树、智元的量产交付聚焦工商业场景，越疆是第一家明确将人形机器人定位为"家庭陪伴交互"产品的上市公司。家庭场景的不确定性远高于工厂——光照变化、物品杂乱、儿童宠物突发行为——这对具身大模型的泛化能力提出了全新要求。第二，自研具身大模型的护城河——越疆不是调用通用大模型 API，而是自研"空弈 DobotWAM"具身大模型；当大模型能力趋同（如 ENPIRE 证明的），物理世界的理解力、力控直觉、人机交互才是真正的差异化。第三，从协作机器人到人形机器人的全栈延伸——80 万台协作机器人出货经验 + 自研大模型 + 家庭场景定位，越疆正在构建从工业到消费的完整产品矩阵。

行业动态

企业级基础设施 政策加速

5MCP Zero-Touch OAuth 企业级鉴权发布 + 七部门平台经济行动方案力推大模型国产算力——AI Agent 基础设施走向企业标配

6 月 18 日，Anthropic 主导的 Model Context Protocol（MCP）项目发布 "Zero-Touch OAuth for MCP" 企业级托管鉴权方案。传统 MCP 客户端每次调用工具都要弹出 OAuth 弹窗要求用户确认，对企业内大批 Agent 自动化场景几乎不可用；新方案让企业管理员预先在 Okta、Entra ID 等身份提供方配置服务账号与策略，Agent 在调用时无需任何用户交互即可获得受控访问。MCP 已被 OpenAI、谷歌、Cursor、Cline 等广泛采用，是 AI Agent 与外部工具对接的事实标准。

6 月 19 日，工信部等七部门联合印发《促进平台经济大中小企业协同发展行动方案（2026—2028年）》。文件明确要求互联网平台加大通用大模型、行业 AI 智能体研发投入，联合中小企业攻关高端芯片、自研操作系统；推行平台发榜、中小企业揭榜协同机制。同日，国家金融监督管理总局发布银行业保险业 AI 安全应用指导意见，强制金融 AI 系统自主可控，优先选用国产算力节点。

MCP 企业级升级
  • Zero-Touch OAuth：无需用户交互的受控访问
  • 支持 Okta / Entra ID 等企业身份系统
  • MCP 生态：OpenAI + 谷歌 + Cursor + Cline 已采用
  • 从"开发者玩具"→"企业基础设施"
  • Agent 大规模部署的最后一块拼图
政策双线驱动
  • 七部门：平台经济行动方案（2026-2028）
  • 力推通用大模型 + 行业 AI 智能体
  • 攻关高端芯片 + 自研操作系统
  • 金融监管总局：强制 AI 自主可控
  • 优先国产算力 + 规范数据安全
💡 为什么重要

两条线索指向同一个方向：AI Agent 正从"开发者工具"升级为"企业基础设施"。第一，MCP Zero-Touch OAuth 解决了 Agent 大规模部署的最后一块拼图——此前 Agent 每次调用外部工具都要弹窗确认，对企业批量自动化场景不可用；新方案让 Agent 无需交互即可受控访问，意味着企业可以真正大规模部署 Agent 工作流。第二，政策从"鼓励创新"转向"强制筛选"——七部门要求平台加大底层原创技术投入，金融监管总局强制 AI 系统国产算力优先——政策正在倒逼产业从"拿来主义"走向"自主可控"。第三，技术标准 + 政策标准双轮驱动——MCP 让 Agent 的工具调用有了企业级安全通道，政策让大模型的算力底座有了国产替代路线；AI Agent 进入企业不再是技术问题，而是基础设施问题。
