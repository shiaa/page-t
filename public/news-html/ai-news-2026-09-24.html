OpenAI Sora 2 API 今日正式关停，战略重心转向编程工具与企业客户

行业动态 OpenAI 战略调整

9 月 24 日是 OpenAI Sora 2 API 的正式关停日。网页版与 App 已于 4 月 26 日下线，今天起所有 sora-2、sora-2-pro 及带日期快照的模型别名调用均返回 410 Gone；9 月 25 日之后将永久删除所有 Sora 账户数据，且不提供恢复窗口。已购的 ChatGPT/Sora credits 仍可在 Codex 中使用。官方将算力向编程工具和企业客户倾斜——Sora 降级为"世界模型"研究项目，消费级视频生成 API 赛道让位给 Runway、可灵、Veo 等仍在持续迭代的玩家。

值得关注的原因：对开发者这是硬截断而非软弃用——依赖 Sora 2 API 的产品必须立刻导出素材并迁移集成，而非拖到下一季度。更深层信号是头部模型公司的资源正系统性转向编程 Agent 与企业级工作流，这与 Anthropic 把 Opus 成本砍 40% 的动作同构：消费级生成式 API 的红利期正在收窄，开发者工具与 B 端生产力才是下一个主战场。

💻 AI Coding 方向

Anthropic 发布 Claude Opus 5.5：Fable 5.1 级性能，运行成本直降 40%

AI Coding Anthropic 模型发布

9 月 22 日 Anthropic 发布 Claude 5.5 家族首款模型 Opus 5.5，是 CEO Dario Amodei 在《We Must Pace the Frontier》"减速前沿"呼吁后交出的首份答卷——方向不是顶高天花板，而是把接近 Fable 5.1 的性能大幅降价。官方口径：多数任务达到 Fable 5.1 水平，但成本比 Opus 5 低 40%；输入/输出 token 各降 20%，构成 Agentic 编程成本大头的缓存读（cache reads）降至 $0.20、降幅高达 60%；输出速度提升 30% 以上。早期测试者用其不到一天完成 68 万行代码迁移、3 小时审完 20 万行代码库，而 Opus 5 需 20 多小时、多花 2.5 倍 token。

值得关注的原因：这是明确的"预算优化"信号——想用 Fable 级能力又嫌贵，切到 Opus 5.5 大概率能省钱，尤其 cache 读密集的 agentic coding 场景。对 SRE/DevOps 的远程排查、大规模代码迁移与审计是实打实的成本与效率红利，值得把现有 Claude 工作流跑一遍对比迁移成本与账单。
来源：Anthropic 官方 · VentureBeat · The Decoder

OpenAI Academy 扩展「用AI构建」开发者路径，新增 8 门 AI Coding 课程

AI Coding OpenAI 开发者教育

9 月 24 日，OpenAI 扩充免费学习平台 OpenAI Academy，在原有「工作中的 AI 应用」之外新增面向开发者、管理者、教育工作者与高校学生的四条学习路径、共 14 门课。其中「用AI构建」面向开发者与技术团队共 8 门，内容覆盖用 Codex 或 OpenAI API 做产品、软件开发生命周期的变化与质量控制、方案设计、评估、智能体、检索与生产环境运维；课程配套评估，通过后可获 Academy 徽章。OpenAI 称课程由内部多团队设计，随模型与产品更新持续迭代。

值得关注的原因：这是 OpenAI 把"AI Coding 能力"从工具层推向"方法论 + 人才层"的信号——把 Codex 用法、Agent 评估与生产过程管控体系化输出给开发者与企业。对正在转型 SRE/DevOps、想把 AI 编程真正落地的工程师，这套免费路径是补齐"如何用 Agent 做生产级工程"认知的低成本入口。

微亿智造赴港上市备案，冲刺"工业具身智能第一股"

具身智能 IPO 工业机器人

证监会国际合作司 9 月 18 日披露微亿智造境外发行上市备案通知书，公司拟发行不超 4286.71 万股登陆港交所主板，东方证券保荐。按 2024 年收益计，微亿智造是中国最大的工业具身智能机器人产品提供商，市场份额约 31%，2025 年营收 7.96 亿元且连续两年盈利。

值得关注的原因：在多数人人形机器人企业仍携亏损招股书排队之际，首张通往"盈利后 IPO"的门票落在工业场景机器人公司，行业分化信号强烈——具身智能的商业化破局点先在工业（搬运、装配、巡检），而非消费级人形；盈利模型跑通的企业将率先获得资本定价权。
来源：证监会 · 腾讯新闻 · 中国经济新闻网

海光信息首发嵌入式工控芯片 1000 系列，国产算力下沉工业机器人边端

具身智能 边缘算力 国产芯片

9 月 22 日，海光信息正式发布首款嵌入式工控芯片——1000 系列 CPU，把技术版图从服务器/数据中心延伸至工业控制、能源终端、交通设施、工业机器人、边缘网关等"物理世界"场景。总裁沙超群称算力正从云端向边缘、端侧下沉，AI 要走向真实物理世界、落地工厂与能源场站。官方引用数据：全球边缘计算支出预计从 2025 年 2610 亿美元增至 2028 年 3800 亿美元，同期中国边缘计算硬件市场由 74 亿美元增至 132 亿美元。

值得关注的原因：具身智能落地的关键约束之一是把感知、实时分析与本地决策下沉到设备端（时延、数据安全、带宽）。海光 1000 系列给国产端侧 AI 提供新的底层选择，但工业级生态成熟度、协议兼容与迁移成本仍是短期选型重点——它是"国产替代备选"，真正规模落地要看整机与软件伙伴的适配进度。
