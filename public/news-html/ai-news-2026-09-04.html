OpenAI 发布 GPT-6 Astra：10 万 GPU 训练，宣称"欢迎进入 AGI 时代"

行业头条 OpenAI GPT-6 Astra

美东时间 9 月 3 日，OpenAI 正式发布新一代旗舰模型 GPT-6 Astra，总裁 Greg Brockman 称之为一次"代际跃迁"，并称"欢迎进入 AGI 时代"。Astra 在得州 Stargate 基地使用超过 10 万块 GPU 训练，能直接操作计算机和软件，替用户完成编程、科学研究、金融建模、制作演示文稿和电子表格等复杂任务；同时是 OpenAI 首个达到内部"关键"(Critical) 网络安全能力门槛的模型，可发现此前未知漏洞并开发漏洞利用程序（最先进的网安能力设更严格访问限制）。

值得关注的原因：AI 竞争的衡量标准正在从"生成更好的文字、代码和图片"转向"能否独立完成一项完整工作"。对 AI Coding 而言，Astra 的"进入软件环境直接完成任务"意味着编码智能体从"写代码"走向"交付可运行成果"——开发者角色进一步从执行者转向验收者。这也是 OpenAI 对 agentic coding 路线的一次强力定调，将重塑企业软件交付与 DevOps 工作流。

Google 发布 Gemini 3.8 Flash 与 Flash Cyber，强化软件工程与 Agent

AI Coding Google Gemini 3.8 Flash

谷歌推出 Gemini 3.8 Flash 及网络安全专用版 Gemini 3.8 Flash Cyber，定价与 3.7 Flash 持平（输入/输出 0.75/3.75 美元每百万 token）。在长周期软件工程测试 DeepSWE v1.1 中超过多数更大规模前沿模型，HLE-Verified 得分 54.9%；同步推出的 Flash Cyber 内部漏洞发现成功率超 70%，CWE-Bench 补丁修复 Pass@1 达 47.2%，经 Fairwind Program 向可信安全人员开放。

值得关注的原因：编程优先的 Flash 版本延续 Google 在开发者侧的布局，以平价提供代码生成与安全防护的差异化能力。Flash Cyber 把"漏洞发现 + 自动修复"打包进模型，对 DevOps/SRE 的自动化安全工作流是直接增益——开发者的安全左移（shift-left）成本进一步下降，CI/CD 流水线可在提交阶段即获得模型级安全审查。

Meta 将 Muse Code 推出 GA，加入多智能体工作流与开发者 SDK

AI Coding Meta Muse Code GA

Meta 将 Muse Code 推出 beta 测试，新增面向复杂工程任务的多智能体工作流（multi-agent workflows）与跨会话状态共享（inter-session state sharing），并推出开发者预览 SDK 用于构建自定义 Agent，同时上线月度订阅方案；产品可通过单条命令在终端安装。这是继 Muse Spark 1.3 编程能力对标 Claude Fable 5.1 之后，Meta 在 AI Coding 产品化上的又一落子。

值得关注的原因：Muse Code 走向 GA 意味着大厂在 AI Coding 产品化上加速，多智能体工作流 + 跨会话状态是把"一次性代码生成"升级为"持续协作的工程伙伴"。对 SRE/DevOps 而言，可把日常排障、补丁编写、运维脚本生成交给多 Agent 流水线，工程能力的可复用性与连续性显著提升。

车企跨界造"人"成战略浪潮：小鹏 IRON 完成超 9 亿美元融资

具身智能 车企下场 人形机器人

今年以来人形机器人赛道持续升温，车企加大布局。8 月小鹏旗下人形机器人业务完成首轮超 9 亿美元融资，投后估值超 63 亿美元，何小鹏亲自出任机器人业务 CEO，计划年底规模量产、2027 年 IRON 正式上市面向零售与服务业交付；广汽孵化的慧仑科技第四代轮足式人形 GoMate Mini 已在 7 个项目中部署近 50 台并取得近千万元订单；奇瑞墨甲、比亚迪、理想等也相继披露进展，蔚来则战略投资任少卿创立的物理 AI 具身智能公司。

值得关注的原因：车企具备可共用的供应链体系与真实工厂训练场，正把人形机器人当作"第二/第三增长曲线"。这会带来量产能力、成本下探与场景数据反哺的正循环——相比单点 Demo，车企入局是具身智能产业化更关键的供给侧推力，也意味着行业竞争将从"谁演示得炫"转向"谁能量产、谁有真实场景数据"。

人形机器人从"展台"到"赛场"：上半年国内具身融资 935 亿元，同比增 5 倍

具身智能 产业落地 数据集开源

第二届世界人形机器人运动会落幕，天工 Ultra 400 米跑进 38.15 秒（一年前冠军为 1 分 28 秒），绝大多数项目要求全程自主决策执行，灵巧手全自主方式分值权重设为遥控的两倍；闭幕式发布总时长超 2500 小时的全量数据集。新华社报道，上半年国内具身智能赛道融资总额达 935 亿元，同比增长 5 倍，行业正从技术验证迈入商业落地的关键转折期。

值得关注的原因：赛场是低成本的"压力测试"，暴露的运动控制与快速恢复短板正是产业攻坚方向；超 2500 小时开放数据集将摊薄具身模型训练成本，加速 Sim2Real 与泛化能力突破。资本 5 倍增长说明市场已从"看热闹"转向"算回报"，具身智能进入产业化加速期——对关注供应链与就业机会的运维/工程背景从业者，这是值得重点跟踪的新兴赛道。
