1 2026 全球数字经济大会在京开幕：北京 AI 产业规模突破 4500 亿，人形机器人 + 世界模型集中亮相

2026 全球数字经济大会于 7 月 2 日至 5 日在北京国家会议中心举行，主题为「建设数字友好城市——智惠无界，数联全球」。大会汇聚近 40 个高级别国际团组、千余位嘉宾，并设置 50 余场覆盖全产业链的专题分论坛。

新华社报道披露，北京数字经济增加值占 GDP 比重已达 46.4%，近一年人工智能产业规模突破 4500 亿元，大模型备案数量达 254 款，居全国首位。大会期间还将集中发布 近 20 项行业规则标准，覆盖 AI 伦理、数据治理、智能制造等领域。

展会现场集中展示了国内外最新人形机器人、世界模型、全栈自研仿真技术、脑机接口「北脑一号」等成果，工业级人形机器人已在工厂车间「搭把手」。

为什么值得关注

4500 亿产业规模 + 46.4% 数字经济占比，标志着北京已从「AI 创业高地」升级为「AI 产值高地」。大会同期发布的近 20 项行业标准，将直接影响 AI Coding 工具、人形机器人、世界模型等赛道的合规边界与竞争格局。人形机器人和世界模型的集中亮相，也是检验 2026 年具身智能阶段性成果的最佳窗口。

2 Kimi K2.7 Code 成为 GitHub Copilot 首个开源权重编程模型

月之暗面（Moonshot AI）的 Kimi K2.7 Code 已作为首个开源权重模型接入 GitHub Copilot 的模型选择器。企业管理员可手动开启后供开发者使用，按实际使用量计费。

这意味着 Copilot 不再仅依赖 OpenAI、Anthropic 等闭源模型，开源权重编程模型首次进入全球最大开发者生态的核心入口。Kimi K2.7 Code 在多项代码生成与推理评测中表现突出，对中文开发场景和本地化部署也有天然优势。

接入方式
  • 在 GitHub Copilot 模型选择器中可见
  • 需企业管理员手动启用
  • 按 token 使用量计费
  • 支持私有化 / 本地化需求
信号意义
  • Copilot 首次引入开源权重模型
  • 降低对单一闭源供应商依赖
  • 开源编码模型进入主流工作流
  • 利好企业合规与成本控制
为什么值得关注

GitHub Copilot 是开发者使用最广泛的 AI 编程工具之一。Kimi K2.7 Code 的接入标志着开源权重模型在代码场景完成了从「可用」到「被主流平台采纳」的关键跨越。对企业而言，这意味着未来可以在合规、成本、私有化之间拥有更多选择权，而不再被单一闭源 API 锁定。

8090 Labs / Salesforce Ventures / EY 资本+落地

3 8090 Labs 获 1.35 亿美元 A 轮：AI 编码智能体「Software Factory」进入受监管行业

面向医疗、航空航天、汽车等受监管行业的 AI 编码智能体平台 8090 Labs 完成 1.35 亿美元 A 轮融资，由 Salesforce Ventures 等领投。其核心产品「Software Factory」已在 EY（安永）数万顾问中推广， reportedly 将软件开发生产力提升 70%。

与传统 AI 编程工具不同，8090 Labs 强调在合规、审计、可追溯要求极高的行业中实现智能体编程，自动生成符合行业规范的代码、文档与测试。

融资与落地
  • A 轮：1.35 亿美元
  • 领投：Salesforce Ventures
  • EY 部署范围：数万顾问
  • 生产力提升：约 70%
差异化定位
  • 聚焦医疗、航空、汽车等强监管行业
  • 强调合规、审计与可追溯
  • 不止写代码，更生成文档与测试
  • 智能体编程进入企业核心系统
为什么值得关注

AI Coding 的下一个战场不是「写更多代码」，而是「在不能出错的行业里写对代码」。8090 Labs 的高估值和大规模企业落地证明，市场愿意为「合规 + 智能体」买单。这也预示着金融、医疗、航空、政务等强监管领域将成为 AI Coding 企业的必争之地。

4 《中国具身智能产业发展报告（2026）》发布：2026 年市场规模预计达 1.09 万亿元

《中国具身智能产业发展报告（2026）》于 7 月 2 日在 2026 上海国际具身智能产业博览会（CIEI2026）开幕式上发布。报告显示，中国具身智能市场规模从 2018 年的约 2133 亿元增长至 2026 年预计的 1.09 万亿元，年均复合增长率达 22%–23%，已成为全球增长最快的具身智能市场之一。

同期，工信部、国资委联合启动的 2026 年度人形机器人与具身智能实景实训也在推进，目标是加速人形机器人从实验室走向真实工业与服务业场景。

市场数据
  • 2018 年：约 2133 亿元
  • 2026 年预计：1.09 万亿元
  • 年均复合增长率：22%–23%
  • 全球增长最快的市场之一
政策与展会
  • CIEI2026 上海国际具身智能产业博览会开幕
  • 工信部 + 国资委实景实训启动
  • 从实验室走向工业/服务场景
  • 行业标准与落地并行推进
为什么值得关注

1.09 万亿元的市场预期和 22% 以上的年复合增长率，意味着具身智能已从「概念赛道」变为「产值赛道」。政策层面的实景实训启动，也说明监管方正在推动人形机器人从 demo 走向真实作业。对产业链上下游（减速器、丝杠、传感器、控制算法）而言，订单放量可能已在路上。

5 人形机器人量产前夜：优必选 Walker C1 发布、宇树 R1 降价至 2.99 万、特斯拉 Optimus Gen3 产能上调

近期人形机器人赛道密集释放量产信号。优必选发布全新一代面向商用服务场景的具身智能人形机器人 Walker C1；宇树科技 R1 人形机器人起售价降至 2.99 万元，进一步压低消费级门槛；特斯拉据野村研报已将 Optimus Gen3 弗里蒙特产线年化产能目标从 5 万台上调至约 7 万台，并计划 2028 年在奥斯汀新增产线。

二级市场已率先反应：7 月 2 日 A 股人形机器人板块多股涨停，机器人 ETF 涨超 1.76%。

三款关键产品
  • 优必选 Walker C1：商用服务场景
  • 宇树 R1：2.99 万元起，消费级门槛
  • 特斯拉 Optimus Gen3：产能目标 7 万台/年
产业拐点
  • 价格从百万级降至 3 万级
  • 产能目标从万台级向十万台级迈进
  • 工业 + 商用 + 消费三线并进
  • 资本市场对量产预期升温
为什么值得关注

2026 年可能是人形机器人从「能跑能跳」转向「能卖能干活」的关键年份。优必选、宇树、特斯拉三家分别代表商用服务、消费普及、工业量产三条路径，同步推进说明行业共识已经形成：人形机器人的竞争已从技术展示进入成本控制和规模交付阶段。2.99 万元的起售价更是直接把行业拉入大众可讨论的价格区间。
