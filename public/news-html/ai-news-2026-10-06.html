「AI 教父」Hinton 首发 RSI 论文，22 位顶级学者联署；白宫六巨头签「前沿责任联合承诺」

AI 安全 递归自我改进 治理

Hinton 首篇关于递归自我改进（RSI）的论文正式发布，Bengio、OpenAI 首席科学家 Pachocki、微软 Horvitz 等 22 位学者联署。论文给出两组关键数据：Anthropic 内部 AI 生成的获批代码占比从 2025 年 1 月的低个位数升至 2026 年 5 月的 80%+；Claude 在仅接受高层监督下自主完成内部 AI 研发的比例从 3 月 1% 飙至 8 月 26%。同日白宫宣布六家前沿实验室 CEO 签署「前沿责任联合承诺」（内部管控/专职团队/外部审计/董事会独立委员会四层监督），特朗普宣布成立「超级智能部队」。论文承认算力、数据、实验时间、边际收益递减四道「摩擦力」仍未闭环，但呼吁「窗口期关闭前」尽快建监管框架。

值得关注的原因：递归自我改进与「智能爆炸」从科幻议题正式进入主流治理议程。对 AI Coding 从业者而言，这意味着前沿模型的发布节奏、能力开放范围将被合规与安全审查显著约束——企业级编码 Agent 的「自主权限」边界也会被重新定义。当 AI 自身承担了 80%+ 的代码产出，开发者的角色正从「写代码」转向「定义验收标准与监督」。

Claude Code 2.1.289 支持共享智能体派生，Codex 负责人称模型选择器将被自动路由取代

AI Coding Claude Code 编排平台化

Claude Code CLI 2.1.289 列出 27 项变更，最关键的是 agent.spawn——团队成员可在会话中派生「共享智能体」，Agent ID 统一、明确 idle 与 waiting 状态，并用 @ 引用文件时 read-deny 规则覆盖。与此同时，OpenAI ChatGPT 与 Codex 负责人 Thibault Sottiaux 在播客中表示「模型选择器很可能消失，改为自动路由」，并认为 loops-and-graphs 编排只是过渡阶段；他承诺未来 28 天为 Codex/Work 用户每天交付一项明确改进或完整重置。

值得关注的原因：编码智能体正从「单人命令行工具」升级为「团队级编排平台」：共享 Agent 让多人协作同一工作流成为可能，自动路由则把「选哪个模型/怎么编排」的决策从用户转移到平台。对 DevOps/SRE 而言，日常排障、紧急修复可通过 Agent 团队异步完成，但也需要重新审视权限与审计模型——平台越「无感」，越要补上可观测性。

编码 Agent 重心转向「验得准、受控交付」：Airbnb 称 AI 写 60% 代码，CodeScene 三周重构 30 万行

AI Coding 企业落地 安全治理

应用侧，Airbnb 披露其 AI 已编写约 60% 的代码，交付量同比 +80%，并强调「原型即产物」与可解释性要求；CodeScene 公布与研究者合作的案例——在约 30 万行 C 代码库上让编码智能体连续三周重构，其负责人称「一半功劳在验收装置」（帧哈希回放 + Code Health 10.0 + 22 条重构配方）。安全侧，苹果收紧 macOS「完全磁盘访问」权限，要求 Dots、Muse 等常驻智能体获得明确授权，给 Agent 加了「权限锁」。

值得关注的原因：编码 Agent 的竞争焦点正从「写得多、写得快」转向「验得准、可控交付」：验收装置与权限治理成为企业规模化的前置条件。对计划引入 AI 编程的团队，值得关注的不再是代码生成率，而是可审计的验收链路与最小权限模型——这恰是运维/安全视角最容易补位的环节。

UBTech 柳州「机器人造机器人」超级工厂投产，月产能冲刺 1500 台并开源 Thinker 模型

具身智能 量产 UBTech

10 月 1 日，UBTech CEO 周剑带队探访柳州 1.4 万平米「超级智能工厂」，视频展示「机器人造机器人」：Cruzr Y1 拆包、S2 辅助包装、U7 叉车搬运成品。工厂 9 月投产、年产能超 1 万台，满产节奏约每 8-10 分钟下线一台，月产能有望达 1500 台；周剑称这是「人类制造史上罕见的量产挑战」。同时 UBTech 已开源自研视觉语言模型 Thinker，对外开放感知与推理栈。公司已披露约 13 亿元销售额。

值得关注的原因：中国人形机器人正式从「演示视频」跨入「规模化制造」阶段。每 8-10 分钟一台的产线节奏，第一次给出可被独立验证的量产数字；开源 Thinker 则把「本体+大脑」全栈能力向开发者生态开放。对关注供应链与产业落地的人，柳州工厂是观察 actuators/传感器/电池等零部件瓶颈是否真实缓解的最佳样本。

全球人形上半年出货近 2.5 万台（+432%），中国占 77.9%；美国 FCC 禁令重塑供应链

具身智能 市场格局 政策

IDC 数据显示 2026 上半年全球人形机器人出货量接近 2.5 万台、同比 +432.1%，其中中国超 1.9 万台、占 77.9%；智元（AgiBot）以 35% 全球份额领跑，宇树（Unitree）10 月推出升级版 H2 Plus。与此同时，美国 FCC 于 7 月将外国新款人形机器人列入禁入清单，但已认证型号（如宇树在售机型）凭 grandfather 条款豁免，美国本土厂商仍依赖亚洲供应链与零部件。有分析提醒，中国厂商公布的产能数据需第三方独立验证。

值得关注的原因：行业评价标尺已从「Demo 能力」切换为「真实订单与交付成色」。中国凭借供应链与场景优势占据出货主体，但 FCC 禁令与 IPO 节奏放缓（监管悄悄给过热估值降温）提示地缘政治与资本层面的分化风险。对求职者/投资者，下一阶段应重点跟踪「单位经济模型 + 零部件国产化率」而非发布会参数。
