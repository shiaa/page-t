2026 世界机器人大会开幕：具身智能从"能跑会跳"迈向"能想会干"

具身智能 产业大会 北京亦庄

8 月 19 日，以"人机共生 产需共融"为主题的 2026 世界机器人大会在北京亦庄北人亦创国际会展中心开幕。超 300 家企业参展（较去年增加 69%），展品超 3000 件、其中首发新品 300 余件。具身智能从"能跑会跳"加速向"能想会干"进化，成为本届最突出特点——机器人不再只是动作演示，而是进入仓储拣选、汽车上下料、家庭服务等真实作业场景。

值得关注的原因：这是具身智能从实验室走向真实世界的关键节点。3000+ 展品、300+ 首发，且落地场景从"炫技"转为"千行百业试用"，今年大会释放的"规模化应用"信号比往年任何一届都强。对关注产业化与供应链的人来说，大会同步展示的核心零部件（灵巧手、力矩传感器、端侧 AI 芯片）突破，比整机演示更值得跟踪。

💻 AI Coding 方向

Claude Code 全流程自主运维实测：累计 388 条 PR、180 条合并，AI 编程迈入"人机协同"新阶段

AI Coding Anthropic 人机协同

据中研网报道，Anthropic 公开实测数据：Claude Code 完成全流程自动化代码运维，短期内累计产出 388 条代码合并请求（PR），其中 180 条成功合并落地。全程无需人工实时干预，AI 自主定时启动任务、排查问题、生成修复代码并提交 PR，仅最终合并上线由人工审核。Faros AI 报告显示，高 AI 渗透团队史诗级任务完成量同比 +66.2%、吞吐 +33.7%；但单开发者人均 bug +54%、代码审查等待中位时长暴涨 441.5%。

值得关注的原因：AI 编程正从"代码生成工具"进阶为"全流程自主运维生产力载体"。但数据同时暴露核心矛盾：产能提升、落地放缓——AI 批量产出 PR 后，人工审查成为瓶颈，线上事故风险 +242.7%。这对 SRE/DevOps 尤其关键：AI 能接管崩溃巡检、死代码清理、漏洞修复，但"人审 AI"的防线必须同步升级，否则技术债与事故率会反噬效率红利。

智谱 GLM-5.3 上线：编程能力暴涨 50%，开源最强编程模型，单轮挖出 2436 个漏洞

AI Coding 智谱 AI 开源模型

8 月 14 日，智谱发布 GLM-5.3，官方给出三个标签：最强安全模型、最强编程模型、最强开源模型。基座未变，靠极致后训练（IndexShare 架构优化、SAO 强化学习、Slime 后训练框架），编程能力体感暴涨 50%，写代码直逼资深老架构师；漏洞挖掘能力对标 Mythos 5，单轮挖出 2436 个漏洞（中高危 1097 个）。官方编程工具 ZCode、AutoClaw 及 GLM Coding Plan 同步开放。

值得关注的原因：在 DeepSeek 之后，国产基座模型再次用"后训练"而非堆参数打出差异化——编程与安全成为主战场。对开发者而言，最强开源编程模型意味着本地/私有化部署高质量 Coding Agent 的可行性大幅提升；对企业则是降低对闭源 API 依赖、把代码资产留在内网的现实选项。

北京人形发布 Pelican-Unify 1.0 大一统具身世界模型 + 天工 Omni 新品

具身智能 北京人形 世界模型

8 月 20 日世界机器人大会分论坛，北京人形机器人创新中心发布 Pelican-Unify 大一统具身世界模型与天工 Omni 新一代人形机器人。Pelican-Unify 实现统一表征、端到端闭环，配套 Pelican-VL 2.0 在长程任务、工具调用上跃升并开放服务；天工 Omni 面向大众市场（身高 1.35 米），开放底层关节控制、传感器数据等接口，现场完成梅花桩、上下楼梯、匍匐爬行、办公打印等多任务演示。

值得关注的原因："一脑多能、一脑多机"是具身智能走通规模化的关键架构——不同形态机器人共享同一智能底座，打破"单一场景专项开发"模式。开放底层接口则把机器人变成可二次开发的平台，利好科研、实训与中小团队低成本接入，加速生态繁荣。

京东百亿机器人战略 + 优必选万台超级工厂投产，商业化落地加速

具身智能 商业化 供应链

京东在大会发布机器人战略：截至 2028 年投入百亿资源，助力 100 个品牌独立销售额破 10 亿；附身智能 JoyInside 打造"AI Home"，年内超千万终端接入；京东云两年采集超 1000 万小时真实场景数据。另一边，优必选与西门子合建的首个万台产能人形机器人超级智慧工厂 8 月投产；优必选与沐曦合资布局具身智能端侧芯片，计划 2027 流片、2028 量产。
