OpenAI 推出 Agents API 公测版，将 Codex 底层代理架构向开发者开放

Agent 基础设施 OpenAI 编程商业化

OpenAI 周三宣布 Agents API 进入公开测试，将此前仅支撑 Codex 及企业版 ChatGPT 的代理框架与基础设施以编程接口形式对外开放，开发者按实际消耗的 token 与工具调用量计费即可接入，无需额外付费。核心能力包括：上下文自动压缩（代理可连续运行数小时至数天）、工具搜索与并行调用、多代理协同（主代理分解任务下发独立子代理后汇总）。早期客户数据亮眼：SafetyKit 案例审核成本降 60%、Hypha 代理失败率压低 86%、Cirridae 评估分从 0.71 升至 0.85 且延迟降 4 倍；物流公司 Nash 已部署数千个长时运行代理管理全球数亿次配送。

值得关注的原因：这是 OpenAI 把"代理操作系统"从内部能力变为平台层产品的关键一步——开发者无需自建上下文管理、子代理编排等底层设施，一次 API 调用即可生产级落地。对 AI Coding 与运维自动化（长时运行、断点续跑、多 Agent 协作）尤其友好，也意味着 Coding Agent 的竞争正从"模型能力"上移到"运行时基础设施"，Codex 生态护城河被进一步加宽。

Cognition 发布 SWE-2 编程模型，性价比对标 Fable 5.1，可配置 effort 等级

AI Coding Cognition 编程模型

Cognition 发布其迄今最强编程模型 SWE-2，在 FrontierCode 1.1 Main 上达到 50.0% 成绩，通过对多万亿参数强化学习的扩展，以比 Fable 5.1 低 64% 的成本实现同等水平。模型引入可配置 effort 等级（configurable effort levels），今日已在 Devin Desktop 与 CLI 中上线，Pro/Max/Teams 订阅用户享一个月免费期。

值得关注的原因：SWE-2 把"顶级编程能力"与"可调节成本"直接挂钩，effort 等级让开发者在质量与开销间自主权衡，是 agentic coding 走向工程化、可量化的标志。结合同日 OpenAI Agents API，编程 Agent 的底层（模型 + 运行时）在同一天双双刷新，AI Coding 正从"能写代码"进入"按预算交付"的阶段。

Eclipse Theia 1.75 采用 Agent Plugins 1.0 开放标准，Google 加入指导委员会

AI Coding 开放标准 MCP

Eclipse Theia 1.75 正式采用开放标准 Agent Plugins 1.0，定义了 Agent Skills 与 MCP 的可移植目录格式。其技术指导委员会现已囊括 Amazon、Cursor、Microsoft、OpenAI、Vercel，并新增 Google。与此同时，围绕 GitHub Agent Client Protocol（ACP）与 DeepSeek Harness 的社区项目密集更新，生态正快速向新协议收敛。

值得关注的原因：Agent Skills 与 MCP 的可移植目录标准意味着"一次打包、多工具运行"成为可能，开发者写的技能包能跟随依赖树自动装进不同 AI 助手，降低被单一 IDE/厂商锁定的风险。Amazon、Cursor、Microsoft、OpenAI、Vercel、Google 同台，实质上是 AI Coding 工具互操作的事实标准正在成型，对 DevOps/SRE 的自研内部 Agent 可复用性意义重大。

优必选斩获超 5000 万元海外订单，小鹏 IRON 自主走下产线，监管拟抬高人形机器人 IPO 门槛

具身智能 商业化 资本市场

9 月 10 日，优必选接连与欧洲、日韩客户签约，斩获超 5000 万元海外订单（含 Walker C1 与优世界 U1），上半年营收 12.7 亿元同比增 104.2%。同日，小鹏全球首条高阶通用人形机器人自动化产线启用，IRON 完成总装后自主走下产线，核心制程自动化率超 80%。另据 The Information，证监会向投行作出非正式窗口指导，要求拟上市机器人企业证明持续收入、减亏或真技术创新，超 40 家企业排队背景下监管收紧。

值得关注的原因：一边是头部企业订单与量产双双兑现（技术出海 + 本地深耕），一边是监管为"未盈利、无真创新"的蹭热点 IPO 设卡，行业正经历"商业化提速"与"资本洗牌"并行。订单质量与真实出货量将取代概念热度成为估值锚点，马太效应（宇树、智元、优必选等头部约占全球 97% 出货）会进一步加剧。
