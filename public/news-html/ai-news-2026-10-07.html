Anthropic 扩大 Glasswing 计划，三级网络认证开放最强模型给 150 家机构做关键基础设施红队测试

AI 安全 Anthropic 关键基础设施

10 月 7 日，Anthropic 宣布将 Project Glasswing 从约 50 家初始伙伴扩展至约 150 家新机构，覆盖电力、水务、医疗、通信、硬件及上游开源维护者等此前覆盖薄弱的领域。原 Glasswing 与 Cyber Verification Program 合并为三级 CVP：Defense（事件响应/恶意软件分析）、Red Team（授权渗透测试，仅对机构开放）、Specialized（与美政府联合审查，面向电网、飞控、跨行清算等安全关键系统）。获权机构可使用 Claude Opus 5.5、Sonnet 5.5、Mythos 5.1 及未来模型；数据显示伙伴在 4-7 月已发现至少 12.9 万个已验证漏洞，其中 3.3 万+ 为高危/严重。

值得关注的原因：前沿模型的"能力红线"已从厂商自评走向制度化的授权红队——当模型强到能 27 年 OpenBSD 旧漏洞、16 年 FFmpeg 缺陷，单靠供应商内部对齐已不够，必须引入外部审计。对 AI Coding 开发者而言，这直接抬高了"你写的代码/工具链会被红队审视"的安全合规预期：能源、金融、医疗等强监管行业的 CI/CD 流程，未来大概率要对接这类模型级安全审查。安全不再是模型补丁，而是产业基础设施。

OpenAI Codex "28 天承诺" Day 1 落地：默认输出速度提升约 50%

AI Coding OpenAI 编码智能体

10 月 5 日（Day 1）OpenAI Codex 负责人 Tibo 报告，GPT-6 Astra 与 GPT-6.1 Sol 经订阅通道的默认输出速度从约 30 tokens/s 提升至约 50 tokens/s，约 50% 的提升来自基础设施优化而非模型改动，且约两小时内即覆盖所有 OpenAI 产品，以及通过"Sign in with ChatGPT"登录的第三方 harness——包括 OpenCode、Pi、Amp、Devin。该承诺承诺未来 28 天每天为 Codex/ChatGPT Work 用户交付一项明确改进，无改进日则重置用量上限。

值得关注的原因：编码 Agent 的核心循环是"读文件→改→跑测试→迭代"，成百上千次往返里，每 token 延迟会被复利放大。把延迟砍掉近半，等于在不换模型的前提下直接抬升长任务吞吐量。更关键的是"订阅即平台"信号：最快用上 Astra 的方式，是留在 OpenAI 登录生态里——无论你用哪个编辑器。这对所有第三方编码 harness 用户都是隐形福利，也意味着模型厂商正把"登录/订阅"做成 Agent 分发入口。

编程智能体安全危机升级："Friendly Fire" / "GhostApproval" / "Agentjacking" 三类漏洞被集中披露

AI Coding Agent 安全 供应链风险

10 月 7 日多家安全媒体汇总了针对自主编码智能体的新型攻击面：AI Now Institute 的 "Friendly Fire" 利用被投毒的 README 文件，在 Claude Code 的 auto-mode、Codex 的 auto-review 等自主模式下诱使 Agent 把恶意脚本当作"安全检查/初始化"执行；Wiz 的 "GhostApproval" 借 symlink 让 Agent 在界面显示无害路径时，实际写入 SSH 密钥或 shell 启动配置等敏感文件；Tenet 的 "Agentjacking" 用伪造的 Sentry bug report 诱骗 Agent，成功率约 85%。Sophos 还发现 Agent 使用 certutil、bitsadmin、PowerShell 等"离地"二进制时会触发 EDR 告警，与人类攻击者行为难以区分。

值得关注的原因：专家强调这些不是可一键 patch 的普通 bug，而是"自主 Agent 被授予执行权"这一架构的结构性风险——当 Agent 嵌入 CI/CD 与 PR 流程，它直接成了供应链攻击的导管。Google、Amazon、Cursor 已就 GhostApproval 推补丁，但 Augment、Windsurf 等尚待修复。这与同日 Anthropic 扩权做关键基础设施红队形成呼应：安全已成编码 Agent 从"提效玩具"走向"生产系统"的第一约束，DevOps/SRE 在接入 Agent 到流水线时必须先设好权限与沙箱边界。

启元机器人全球首店落地上海淮海中路，量产人形 Q1 / T1 首次以"商品"身份进个人消费市场

具身智能 消费落地 人形机器人

10 月 7 日上观新闻报道，国庆长假前夕启元机器人全球首店在淮海中路龙凤 PRSCO 开业，一周前发布的 Q1、T1 两款机器人直接摆进上海核心商圈橱窗——这是量产人形机器人首次以"商品"身份正式进入个人消费市场。门店长假期间日均接待 100+ 组顾客，主力为家庭、老人与大学生；最低不足 2 万元一台的定价覆盖了大学生低成本二次开发需求。现场出现"为独居老人买陪伴机器人"的真实订单：一对 50 多岁夫妇为成都 80 岁舅舅下单 T1，看重其跟随拍摄与互动功能。北外滩白玉兰广场、商场擂台等地也出现迎宾、导购、拳击互动等常态化展演。

值得关注的原因：具身智能过去一年在"工厂试验田"和"发布会秀"里反复验证，但真正进入 C 端零售货架、被普通家庭当场掏钱买走，是标志性一步。它把叙事从"能不能干活"推进到"愿不愿意带回家"，也验证了"低单价 + 可二次开发"的破圈路径。对关注供应链与生态的开发者，启元首店的模式（展示区+3D打印配件区+互动区+后续 AI 启蒙/图形化编程课）值得跟踪——这可能是人形机器人最早的"应用商店"雏形。

首尔 Smart Life Week 开幕（10/6-8），人形机器人登台，中国产人形亮相韩国国会引发"physical AI 投资不足"警示

具身智能 国际展会 全球竞争

10 月 6-8 日，Smart Life Week 2026 在首尔 COEX 举行，529 家参展企业/机构/市政府参与，其中 Seoul AI Robot Show 汇聚 51 家机器人公司（现代起亚 Robotics LAB、LG CNS、Doosan Robotics、Robotis 等）。开幕日人形机器人随 K-pop 起舞、与人类打羽毛球、迷你拳击对打；波士顿动力创始人 Marc Raibert（RAI Institute 执行总监）做开幕主题演讲，谈机器人"通过观察人类动作学习"、最终进入家庭与养老。同期，一款中国产人形机器人在韩国国会审计中亮相，有企业高管直言 physical AI 核心是软件而非硬件，直接引发议员对韩国相关投资"严重不足"的警告。

值得关注的原因：这届展会把"具身智能"从工厂演示拉到城市公共服务与政治议程里——首尔规划的 Physical AI Belt（杨才 AI 科技城—水西机器人集群）要成为公共空间技术试验场，韩国还在筹建护理机器人委员会以厘清安全、责任与家庭数据规则。而中国产人形进入他国国会审计环节，是"中硬件/美模型"分野下，全球竞争与治理差距被公开摆上桌面的信号。对跟踪产业的人来说，政策与标准（而非单品参数）正成为下一阶段的胜负手。
