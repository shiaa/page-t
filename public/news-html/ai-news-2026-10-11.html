Meta 几周内推出消费级 AI Agent 平台 Hatch，新一代模型 Watermelon 10 月发布

行业格局 Meta Agent 平台

据 The Information 审阅的内部文件，Meta 正准备在数周内推出面向消费者的 AI Agent 平台「Hatch」，与其新一代前沿模型「Watermelon」（计划 10 月发布）同步亮相。Hatch 采用分层订阅模式、高端档位月费可达 199.99 美元，深度集成 DoorDash、Etsy、Reddit、Yelp、Outlook 等应用，并直接嵌入 Instagram 超 20 亿日活生态；WhatsApp 也将开放为第三方 Agent 的接入平台。Meta 意在把对广告（占比 97% 以上）的单一收入依赖，转向订阅制 Agent 变现。

值得关注的原因：这是头部社交平台把「通用 Agent」推向大众消费的标志性动作——与 OpenAI 的 Dots、Google 的 Gemini Agent for Work 形成三足鼎立。核心看点有二：一是 Meta 自持算力基础设施（对比依赖外部推理的第三方 Agent）带来的成本护城河；二是「聊天工具 → 能替你办事的订阅制代理」正在成为大模型公司争抢的第二个增长曲线。对开发者而言，Hatch/WhatsApp 的开放接口意味着又一块 Agent 入口与新的生态位。

斯坦福 DeLM 去中心化多智能体系统在复杂编码任务上击败 Claude Code 与 Codex

AI Coding 斯坦福 多智能体

10 月 10 日，斯坦福一篇新论文证明：去中心化多智能体系统 DeLM 可在复杂编码任务上同时超越 Claude Code 与 Codex。DeLM 用「共享上下文 + 任务队列」取代中央协调智能体，让各 Agent 自主领取任务、即时共享发现、基于彼此进展构建，消除了多智能体协作中最常见的「等待气泡」与「重复劳动」。在 Terminal-Bench 4.0、DeepSWE v1.1 与 ProgramBench 的长时程任务上，DeLM 的执行速度最高达原版基准的 2.49 倍，准确率提升最高 +19.2 个百分点，相同 120 分钟预算下 ProgramBench 通过率提升最高 +19.9 点。系统基于 Codex 与 Claude Code 构建，代码与 720 条轨迹已开源，并提供可直接在两者中试用的插件。

值得关注的原因：这条路线点破了当前单 Agent「越长会话越易丢东西」的瓶颈——瓶颈不在模型档位，而在编排结构。DeLM 把「并行 + 异步共享状态」做成可插拔插件，意味着开发者无需换模型即可给现有编码 Agent 提速近 2.5 倍、提准近 20 点。对 DevOps/SRE 场景（长链路排障、多文件重构）尤其有价值，也预示着「多智能体协作」将取代「更强单模型」成为下一阶段编码 Agent 的胜负手。

Google 停止销售 Gemini Code Assist，引导企业客户转向 Antigravity

AI Coding Google 产品整合

Google 于 10 月 9 日发布说明，正式停止销售 Gemini Code Assist 的 Standard 与 Enterprise 新订阅。现有订阅在 2026 年内仍可自动续费，但自动续费将于 2027 年终止；Google 将开发者导向 Antigravity——该产品通过符合条件的 Gemini Enterprise 订阅或 Gemini Enterprise Agent Platform 提供。说明中未给出过渡定价、迁移工具，也未提及免费档与 Individual 用户的处理方式。

值得关注的原因：这是 AI 编码工具从「独立付费单品」并入「企业 Agent 套件」的最新例证，与近期 Claude Code 反超 Copilot、字节 TRAE 合并办公与编码的趋势一致——市场正在从碎片化工具走向一体化平台。对企业选型者来说，需在 2027 年自动续费失效前规划迁移或重新议价；对开发者而言，编码助手的「入口」正被云厂商重新收编到更大的 Agent 工作流里。

珞石机器人第 10000 台人形力控臂下线交付，国产力控臂迈入万台级量产

具身智能 珞石机器人 力控执行单元

日前，珞石机器人第 10000 台人形力控臂在山东邹城智能制造未来工厂正式下线交付，成为国内人形力控臂领域首个实现万台级规模交付的企业。该力控臂采用仿人化七自由度设计、十字腕构型，实现全臂力觉感知与微秒级高动态力控，解决装配、插拔、搬运、贴靠等接触式操作中「看得见位置、看不见力」的痛点。目前珞石已与 80 余家产业头部企业合作，70 多家具身智能公司正将其力控手臂接入各自机器人系统；邹城已集聚 25 家机器人及零部件企业，构建起「机器人产业 15 分钟供应圈」。

值得关注的原因：力控臂是具身机器人与物理世界交互的核心执行单元，长期被视为从「演示秀」走向「真实干活」的关键卡点。万台级交付意味着国产核心执行单元正式从技术验证跨入规模化量产与常态化应用阶段——工业机器人工程化经验正在向具身智能迁移，为整机厂提供可复用的「基础设施」。叠加国内首个人形机器人与具身智能标准体系发布，产业正从单点创新迈向标准化、体系化发展。

西湖机器人 WR1 实现全球首个全身协同自主叠衣，家庭连续家务任务取得突破

具身智能 西湖机器人 家庭家务

10 月 10 日，由华为云驱动的杭州西湖机器人科技推出人形机器人 WR1，实现全球首个全身协同自主叠衣。WR1 采用全球首创的「通用大小脑双预训练系统」架构，将多模态任务理解与全身控制深度耦合，融合世界模型（WM）与视觉-语言-动作模型（VLA），统一输出包含身体移动、全身姿态、灵巧手操作的完整动作序列；高速稳定执行则由原创自研的通用动作大模型 GAE 完成。演示中，WR1 与另一台人形协同完成取衣、承托、转移、展开、折叠的连续动作链，并实时应对晾衣架晃动、衣物位置偏移等扰动。

值得关注的原因：让机器人做家务是具身智能公认的高门槛场景——柔性物体形态随拉扯改变、任务链环环相扣、场景切换易断裂。此前多数演示停留在「抓杯子」「叠毛巾」单点技能，WR1 把长链条连续家务（取衣→协同折叠）跑通，标志着家庭场景从单点技能迈向连贯作业。对关注具身落地的开发者，VLA + 世界模型 + 通用动作大模型的「大小脑双预训练」组合，正成为家庭服务机器人可复用的技术范式。
