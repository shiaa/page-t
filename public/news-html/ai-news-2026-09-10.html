OpenAI GPT-6 Astra 全面铺开：105 万 token 上下文把"编程与长程任务"推上新基座

大模型 OpenAI 编程基座

9 月 3 日 OpenAI 发布 GPT-6 Astra，上下文窗口达 105 万 token、最大输出 12.8 万 token，重点增强编程、研究与复杂多步骤任务处理；数日内已快速接入 Codex、Devin、Claude Code（社区插件）等主流 Agent 工具链。第三方评测分化明显：Cognition FrontierCode 1.1 得分 64.5 超过 Claude Fable 5.1（63.6），单次成本约低 64%，但单价约为上代 2.5 倍；其"规划-委派"型编排能力突出，擅长把任务拆给更便宜子代理、自己守住上下文做决策。

值得关注的原因：模型能力已不再是唯一差异点——各大工具在数天内接入同一前沿模型，竞争焦点正转向 harness（执行框架）质量与单位任务成本；"OpenAI 模型 + Anthropic 框架 + 便宜子代理干活"的混搭用法开始流行，模型与工具解耦是重要信号。企业选型需按任务分层测算，不能再按单一 benchmark 拍板。

💻 AI Coding 方向

Claude Code v2.1.265 大版本发布后数小时紧急 hotfix v2.1.266：AI 编程工具转向"企业治理"

AI Coding Anthropic 工程治理

9 月 8 日 Anthropic 发布 Claude Code v2.1.265（近期最大更新），覆盖插件加载、prompt-cache 稳定性、Windows 沙箱、VS Code 会话处理等；磁盘工具结果上限 1GB 并明确截断提示，--plugin-dir 支持多插件热加载，Windows AppContainer 沙箱内不再直接阻断 Read/Write/Edit。数小时后因 CLAUDE_CODE_USE_GATEWAY 回归导致经网关/代理的部署全部"未登录"失败，同日推送 v2.1.266 恢复旧行为。同一天 GitHub 也为 JetBrains 版 Copilot 加入企业级沙箱策略、跨文件光标跳转与全局项目上下文。

值得关注的原因：本周两家方向一致——不卷新模型，而是卷治理：限制资源用量、锁定沙箱、给管理员统一杠杆来规范 AI 编码 Agent 在一批开发机上的行为。凡经 LLM 网关/代理跑 Claude Code 的团队应立即升到 v2.1.266；正在铺开本地沙箱的管理员也值得先审一遍 Copilot 的新策略控制。对 DevOps/SRE 而言，Agent 进生产环境的合规闸口正在成型。

OrcaReplay 开源 + Prime Agent 走红：Agentic Coding 从"单轮对话"走向"后台任务编排 + 多 Agent 并行"

AI Coding 开源工具 多 Agent

OrcaRouter 开源 OrcaReplay，可录制、回放、调试并分支 AI Agent 的执行轨迹，将 Agent 活动捕获为 trace 便于复现与排错；与此同时，GitHub 上受关注的 Prime Agent 定位"后台长跑 + 多 Agent 协作"编码助手，支持把耗时工程任务放到后台异步执行、同时拆解多个子 Agent 并行处理不同模块，由主 Agent 负责编排与汇总。社区同步热议"退掉年费订阅、本地模型兜底"的降本思路与"程序员的护城河转向判断力"的判断。

值得关注的原因：两者共同指向 Agentic Coding 的形态跃迁——从"我和单个 Agent 单线程对话"进化为"我在后台委托任务、多个子 Agent 并行干活、主 Agent 编排汇总"。对跨文件/跨服务重构、以及需要可观测/可回放的调试流程（远程排查、紧急修复）尤其友好，也呼应了"会提需求、会验收、会取舍"成为新护城河的产业判断。

优必选上半年交付约 600 台 Walker S2，工业客户复购，全年 EBITDA 有望 Q4 转正

具身智能 优必选 工业交付

9 月 9 日大和报告引述优必选业绩后路演：上半年收入超 10 亿元、同比增逾 100%，交付约 600 台 Walker S2，部分工业客户已复购；公司重申全年收入指引 35 亿元，并预期第四季度有实际机会实现 EBITDA 转正。同日提及优必选将与沐曦合作开发人形机器人专用芯片，以边缘计算降低云端依赖、提升现场实时决策能力。

值得关注的原因："复购"是工业机器人从试用走向规模化的关键验证信号——客户愿意二次下单，说明场景价值与稳定性初步成立；专用芯片则指向部署成本与现场可靠性的下一关。叠加 9 月 9 日人社部新增"具身智能机器人应用技术员"新职业（数字职业占新增 45.5%），产业正从研发走向应用部署、人才侧短板开始补齐。

小鹏机器人产线启用，全球首台高阶通用人形机器人自主走下产线；广东"十骏"拼真实订单

具身智能 小鹏 量产交付

9 月 9 日报道，小鹏机器人生产线正式启用，全球首台高阶通用人形机器人完成自动化总装并自主走下产线，标志其从研发试制跨入产线制造。在中博会现场，逐际动力、自变量、智平方、乐聚、众擎、美的、小鹏、荣耀、优必选、越疆等"广东机器人十骏"多元"上岗"，在车间、园区、商场等真实场景展示作业能力。行业共识正从"会跳舞"转向"会干活、能拿到商业订单"。

值得关注的原因：人形机器人进入"交付时刻"——小鹏自走下产线代表制造能力闭环，广东十骏的实战路径代表从讲故事到"交作业"。当竞争焦点从参数转向真实场景运营能力，"能不能上岗、拿到商业订单"成为产业核心议题，也意味着供应链（灵巧手、力矩传感器、端侧 AI 芯片）与交付服务将率先兑现价值。
