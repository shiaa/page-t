行业头条

史诗并购 格局重塑

1SpaceX 600 亿美元全股票收购 Cursor 母公司 Anysphere——AI 编程赛道史上最大并购

6 月 16 日，马斯克旗下 SpaceX（NASDAQ：SPCX）向 SEC 提交文件，宣布将以 600 亿美元全股票交易收购 AI 编程工具 Cursor 母公司 Anysphere，预计 2026 年 Q3 完成。这是 SpaceX 上市后首笔重大战略收购，也是 AI 编程工具赛道迄今规模最大的并购事件。截至 6 月 16 日收盘，SpaceX 股价报 201.8 美元/股，三个交易日累计涨幅接近 50%，市值突破 2.66 万亿美元跻身全球前五。

交易核心条款
  • 交易形式：全股票合并收购
  • Cursor 并入 SpaceX 全资子公司
  • 分手费：一般终止 100 亿 / 监管终止 40 亿
  • 须在 SpaceX IPO 融资完成后方可落地
  • SpaceX 同期签有 260 亿/年算力协议
Cursor 关键数据
  • 年化 B2B 营收：约 26 亿美元
  • 此前融资估值：约 500 亿美元
  • 收购估值：600 亿美元（溢价 20%）
  • 投资方：a16z / Thrive / 英伟达 / Alphabet
  • 原占 Anthropic 收入比例：约 50%

"这笔收购的野心不止于编程工具——马斯克将 Cursor 视为'xAI 生态的开发者入口'，与 Grok 模型、SpaceX 算力形成'算力+模型+工具'的垂直整合。"

💡 为什么重要

三个维度至关重要。第一，竞争格局从"工具之争"升级为"帝国之战"：Cursor vs Copilot vs Claude Code 的产品竞争，变成 SpaceX/xAI vs OpenAI vs Anthropic 的阵营战争，"你用谁的模型就用谁的编程工具"将成为新常态。第二，600 亿美元估值锚点：年营收 26 亿美元、市销率 23 倍——为整个 AI 编程工具赛道设定极高估值基准，未来融资并购将以此为参照。第三，Anthropic 失去一半收入来源，将被迫加速 Claude Code 的独立化与商业化转型。

具身智能方向

阿里首发 千问具身

2阿里发布千问 Qwen-Robot 具身大模型三件套——首次构建"手·脚·脑"协同的通用底座

6 月 16 日，阿里巴巴正式发布千问具身智能大模型 Qwen-Robot 系列，包含 Qwen-RobotManip（VLA 操作模型）、Qwen-RobotNav（VLN 移动模型）、Qwen-RobotWorld（世界模型）三大核心模型，分别对应机器人的操作能力、导航能力与认知能力，既可独立部署，也能协同运转。这是千问大模型家族首个完整的具身智能模型矩阵。

Qwen-RobotManip（VLA）
  • 80 维统一动作表征：为不同硬件定义通用"肢体语言"
  • 基于摄像头相对位置操作，免去绝对坐标计算
  • 38000+ 小时开源数据预训练
  • RoboChallenge Table30 v1 包揽前二（Lira/Atlas）
  • 跨 30 项真实任务、4 个机器人平台真机测评
Qwen-RobotNav / World
  • 基于 Qwen-VL，五大导航任务统一框架
  • 任务自适应观察机制：灵活切换记忆策略
  • 原生支持多种智能体框架（业内少数）
  • 宇树 Go2 四足机器人已验证寻物导航能力
  • 世界模型可生成训练视频 + 预演未来轨迹
💡 为什么重要

两个突破值得关注。第一，打破"私有数据依赖"：Qwen-RobotManip 全程仅基于开源数据预训练仍取得领先（包揽 RoboChallenge Table30 v1 前二），意味着具身智能的"数据护城河"开始松动——开源路线有了合规可行的方案。第二，"手·脚·脑"三件套架构确立了具身智能的通用范式：VLA 模型解决操作问题、VLN 模型解决导航问题、世界模型解决推演问题，三者协同可泛化到不同形态机器人。这与之前厂商只做单一模型相比，更接近真实场景所需的全栈能力。

AI Coding 方向

双发布 自主可控

3智谱同日发布 GLM-5.2 开源旗舰 + ZCode 3.0——1M 真正可用上下文 + 自研 Agent 内核

6 月 13 日，智谱 AI 同日发布 GLM-5.2 开源大模型与 ZCode 3.0 编程工具。GLM-5.2 定位"智谱迄今能力最强的开源模型"，首次实现真正可用的 1M 上下文窗口，在 Code Arena 前端开发盲测中取得全球可用模型第一。ZCode 3.0 全面切换自研 ZCode Agent 内核，并宣布不再内置或维护第三方 Agent 适配。开源权重与 API 将在 6 月 20 日左右上线，采用 MIT 协议。

GLM-5.2 核心能力
  • 1M 真正可用上下文（非 PPT 指标）
  • Code Arena 前端开发盲测全球第一
  • 面向 Agentic Engineering 优化
  • Day 0 适配国产算力平台
  • 兼容 Claude Code / OpenCode / Cline
ZCode 3.0 三大优化
  • 自研 Agent 内核（告别"套壳"）
  • 长程推理不掉链子
  • 工具调用成功率显著提升
  • 大型工程执行链路全优化
  • Coding Plan 全档 150%配额

"前沿智能不应只属于少数人，也不应被少数规则随时收回。" ——智谱 GLM-5.2 发布公告

💡 为什么重要

这次发布的战略意义大于技术意义。第一，"模型+自研 Agent"垂直整合路线成型：此前国产编程工具普遍套用 Claude Code 内核，模型与 Agent 不匹配导致效果打折扣；ZCode 3.0 自研内核专为 GLM 优化，体验一致性和工具调用成功率显著提升。第二，MIT 协议商用友好：上周 Anthropic 被曝切断高端模型访问，让"模型随时可能被收回"成为企业焦虑。智谱此时选择 MIT 开源（可商用、可微调、可私有化部署），是直接对标"自主可控"叙事。第三，国产编程模型四强格局：GLM-5.2（自研 Agent）、Kimi K2.7 Code（开源兼容）、Qwen 3.7 Max（通用兼顾）、MiniMax M3（长上下文）形成清晰分化，6 月进入"淘汰赛"阶段。

开源王者 登顶榜首

4OpenCode 登顶 LogRocket 6 月《AI 开发工具实力榜》——160K Stars、750 万 MAU、75+ 模型兼容

据 LogRocket 2026 年 6 月版《AI 开发工具实力榜》，开源编码代理 OpenCode 凭借惊人的社区增长力压 Cursor、Claude Code、Codex CLI 等强敌，登顶 AI 开发工具排行榜第一名。关键数据：GitHub Stars 160K+（部分统计 172K）、月活跃用户 750 万、支持模型 75+ 个。OpenCode 于 2025 年 6 月上线，不到一年便成为开源 AI 编程领域 Star 数最高的代理。

2026 上半年 AI 编程工具梯队
  • #1 OpenCode：开源、模型无关、社区王者
  • #2 Claude Code：SWE-bench 80.8% 性能领先
  • #3 Codex CLI：Terminal-Bench 83.4% 榜首
  • #4 GitHub Copilot：企业/IDE 稳定领导
  • #5 Cursor：$20/月性价比之选
OpenCode 登顶四大原因
  • 模型无关：不被任何厂商绑架
  • MIT 许可证真开源
  • CLI 原生，工程师友好
  • 社区飞轮：插件/模板/集成反哺用户
💡 为什么重要

LogRocket 评分体系中，OpenCode 在"价值主张（开源+免费+自托管）"和"可访问性（75+ 模型广覆盖）"两个维度几乎无敌。传递出三个清晰信号：第一，开源正在反超闭源——当模型能力趋同，开发者更看重自由度与成本；第二，"模型无关"成为刚需——单一厂商绑定越来越被视为风险（特别是在 SpaceX 收购 Cursor、Anthropic 收紧访问的背景下）；第三，CLI 工作流复兴——在 IDE 普遍臃肿的今天，轻量可组合的终端工具重新获得青睐。值得注意：Claude Code 在部分基准测试中执行速度比 OpenCode 快约 78%——OpenCode 赢在"人心"，Claude Code 赢在"性能"，竞争将向两端分化。

资本动态

推理独角兽 融资超 20 亿

5硅基流动完成 20+ 亿元 B 轮融资 + 深朴智能数亿元 Pre-A——AI 基础设施与人形机器人持续吸金

6 月 16 日，模型推理服务商硅基流动宣布完成超 20 亿元B 轮融资，由携程战投、晶科能源控股、金蝶股份、联通新沃、盛奕资本（润泽集团产业资本）等联合投资，华兴资本担任独家财务顾问。同周，机器人公司深朴智能完成数亿元 Pre-A 轮融资，资本对具身智能产业链的押注持续加码。

硅基流动
  • 定位：模型推理服务商
  • 本轮规模：超 20 亿元
  • 轮次：B 轮
  • 投资方：携程战投 / 晶科 / 金蝶 / 联通 / 盛奕
  • 财务顾问：华兴资本
深朴智能
  • 定位：机器人公司
  • 本轮规模：数亿元
  • 轮次：Pre-A
  • 方向：具身智能产业链
  • 背景：阿里 Qwen-Robot 同周发布
💡 为什么重要

两条资本线索都指向同一个趋势——AI 价值链正从"模型层"向"推理/具身层"下沉。硅基流动 20 亿融资反映"模型即服务"红利消退后，推理成本与算力调度成为新护城河；深朴智能 Pre-A 与阿里 Qwen-Robot 同周发布，则说明具身智能已从概念验证进入"模型+硬件+数据"协同落地阶段。值得关注的是：SpaceX 收购 Cursor（600 亿美元）、硅基流动 B 轮（20 亿元）、深朴智能 Pre-A 三个事件叠加，标志着 AI 行业的"头部整合+长尾吸金"双线并行格局正式确立。
