Agnes-2.5 Flash 免费上线：中国开发者在"封号潮"下的新选择，Coding 能力对标 Claude Opus

AI Coding 免费模型 国产替代

7 月 13 日，Agnes AI 发布新一代文本模型 Agnes-2.5 Flash，定位开发者日常主力，Coding 能力对标 Claude Opus 级，且坚持不限期免费开放。同步上线 Agnes Code 桌面端，支持跨文件改造、定时任务与跨 AI 导入记忆。Agnes-2.5 Pro 旗舰模型也首次预告。这一发布恰逢中国开发者遭遇 OpenAI Codex 大面积误杀封号、Claude Code 推行严苛 KYC 实名认证的"双重暴击"时刻。

Superpowers 21 万星登顶 GitHub Trending：AI 编程最大的变化不是模型变强，而是"怎么管 AI"

AI Coding 开发者工具 行业拐点

过去两周 AI 编程圈最火的项目不是新模型，而是一个叫 Superpowers 的 GitHub 项目——21 万颗星，7 天涨 9 万。它的核心是一套 7 阶段结构化工作流（需求澄清→计划审批→TDD 实现→子 Agent 并行→审查收尾），关键是禁止 AI 直接写代码，必须"先想清楚再动手"。最狠的 TDD 铁律：测试先行，未通过测试的代码会被 Agent 主动删除。同一周，TypeScript 社区 Matt Pocock 的 skills 项目冲到 14.8 万星、agency-agents 12.3 万星、Google agents-cli 和小米 MiMo-Code 同周下场。

值得关注的原因：这是一个明确的行业信号——AI 代码生成能力已经过了临界点。"AI 能不能写更多代码"不再是瓶颈，"AI 写的代码能不能被信任、被维护、被安全重构"才是下一阶段的真正战场。编程规范工具正从极客实验变成行业标配，这直接影响每个开发者的日常工作流。

GPT-5.6「太阳系」全家桶全面上线：Codex 消失，ChatGPT Work 成为 AI 打工神器

AI Coding OpenAI 编程智能体

7 月 9 日 OpenAI 将 GPT-5.6 三款模型（Sol / Terra / Luna）全部开放。旗舰 Sol 在 Coding Agent Index 上以 80 分刷新 SOTA，力压 Claude Fable 5 2.8 分，而输出 token 不到一半、成本仅约 1/3。同步完成 ChatGPT 与 Codex 合并，推出 ChatGPT Work——可跨应用收集信息、拆分复杂任务、持续工作数小时的自主智能体。与此同时，Meta 发布 Muse Spark 1.1 直攻 Agentic Coding，KAT-Coder-Pro V2.5 发布主打"从写代码迈向做工程"。

值得关注的原因：GPT-5.6 的核心不是参数更大，而是推理效率的质变——同样的编程任务，用不到一半的时间和成本完成。Codex 与 ChatGPT 的合并意味着 OpenAI 不再把"编程"当作独立产品，而是把 Agentic Coding 作为超级应用的默认能力。大厂从"补全代码"到"接任务干活"的平台化转型，正在重塑整个软件工程的工作方式。

宇树 G1 人形机器人登 Nature：完成全球首例活体微创手术，单台 56 分钟完成胆囊切除

具身智能 医疗机器人 里程碑

7 月 14 日，国际顶刊《Nature》刊发重磅论文：基于国产宇树 G1 通用人形机器人，完成全球首例通用人形机器人远程操控活体猪腹腔镜胆囊切除微创手术。整套方案依托虚拟 RCM 视觉算法，无需专用手术机械臂，机器人可直接握持临床标准腹腔镜器械完成全套外科操作。单台机器人完整手术耗时 56 分钟，双机协同仅需 32 分钟。

值得关注的原因：这篇 Nature 论文的意义不在于"机器人能做手术"（达芬奇手术机器人已存在多年），而在于通用人形机器人用标准器械完成精密医疗操作——不需要千万级的专用手术机器人。这意味着人形机器人的灵巧操作能力已经跨过了一个关键门槛：从"能抓起东西"到"能在毫米级精度下稳定作业"。精密制造、实验室操作等场景的想象空间被彻底打开。

具身智能 量产落地 产业合作
