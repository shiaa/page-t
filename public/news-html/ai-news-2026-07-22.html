月之暗面发布 Kimi K3：2.8 万亿参数全球最大开源模型，编程能力登顶 Arena 榜首

开源大模型 Kimi K3 MoE

7 月 16 日，月之暗面正式发布 Kimi K3，采用 MoE 架构（896 个专家，每 token 仅激活 16 个），总参数达 2.8 万亿，支持 100 万 token 上下文窗口，原生具备视觉理解能力。发布后数小时即登顶 AI 代码评测榜 Arena，成为中国大模型首次拿下该榜单榜首。模型权重将于 7 月 27 日开放下载，API 已同步上线。K3 在 SWE-bench Verified、LiveCodeBench、AIME 数学推理等基准测试中均达到开源领先水平，部分项目接近甚至比肩国际顶级闭源模型。

为什么关注：Kimi K3 不仅是参数规模上的突破，更标志着中国开源模型从"追赶者"变为"并跑者"。其登顶 Arena 编程榜直接动摇了"中国模型落后美国 8-12 个月"的市场共识。月之暗面投前估值已涨至 315 亿美元，新一轮融资后的竞争格局将深刻影响全球 AI 开发者生态——这场竞赛已从"谁有最强模型"转向"谁拥有最大的开发者生态"。

Google 发布 Gemini 3.6 Flash 等三款新模型，强化编程与网络安全能力

Google Gemini 3.6 网络安全

7 月 22 日（今日），Google 发布 Gemini 3.6 Flash、Gemini 3.5 Flash Cyber 等三款新模型。其中 Cyber 版本专门针对网络安全场景优化，可自动发现软件安全漏洞。新模型在编程、金融等任务上表现显著提升，且推理成本进一步降低，直接对标 Anthropic Claude 与 OpenAI GPT 系列在编程和网络安全赛道上的布局。

为什么关注：Google 在同一天推出面向编程和安全两个维度的模型升级，释放了明确的竞争信号：AI 编程工具的市场争夺远未结束，而"安全原生"正在成为模型差异化的新战场。在 Claude Code 后门事件和沙箱逃逸漏洞频发的背景下，Cyber 版本的推出时机极为精准。

Claude Code 企业渗透率首超 GitHub Copilot，编程 Agent 进入"后 Copilot 时代"

编程 Agent Claude Code 格局巨变

AgentTracker 第 58 期榜单显示：Claude Code 企业职场渗透率达 40%，首次超越 GitHub Copilot，终结后者八年霸主地位；微软系整体份额首次跌破 40%。同期 Cursor 以 20 亿美元 ARR、720 万月活创 SaaS 增速纪录。开源 CLI 三角（OpenCode / Cline / Aider）汇聚超 80 万开发者。与此同时，安全研究机构 Pillar Research 披露 Cursor、OpenAI Codex、Google Gemini CLI 等主流编程 Agent 均存在沙箱逃逸漏洞，被称为"沙箱逃逸周"——核心风险在于 Agent 写入的文件会被宿主机后续信任加载。

为什么关注：Claude Code 超越 Copilot 是一个分水岭事件——编程工具从"微软生态绑定"走向"模型能力驱动"的新阶段。Claude Code 创始人 Boris Cherny 在 7 月 20 日受访时透露，Anthropic 内部约 90% 代码已由 Claude Code 完成，部分企业客户同时运行上千个 Agent。但"沙箱逃逸周"的集中爆发也敲响警钟：Agent 自主权越大，安全边界越需要从架构层面重构，而非仅靠提示词约束。

WAIC 2026：人形机器人告别"炫技"，近 60 台集体"上岗"

WAIC 2026 人形机器人 商业化落地

7 月 17-20 日在上海举办的 WAIC 2026 上，具身智能赛道完成关键转型：超 200 家企业参展，近 60 台人形机器人分散在会场各处承担导览、问询、零售等真实任务——这是国内大型展会首次大规模让人形机器人"上岗"而非表演。智元精灵 G2 Max 已在京东物流真实仓储 24 小时搬运码垛，单臂负载 18 公斤；睿尔曼 RealBot-S2 在新疆餐厅完成拉条子、烤肉等后厨作业；千寻智能 Moz1 展示长程推理与抗干扰动态调整能力。行业从比拼"能不能动"全面转向"能不能持续干活"。

为什么关注：WAIC 2026 是具身智能从实验室走向真实生产力的验证时刻。智元联合创始人彭志辉直言："关注点不再是能不能跑、能不能跳，而是能否真正进入工厂、能否长时间稳定工作。" 当人形机器人开始按"上岗天数"而非"演示次数"来评价，整个行业的估值逻辑和落地时间表都需要重新校准。

全国首个具身智能实训场样板间在沪建成，华为联合打造全链路方案

华为 实训场 产业落地

7 月 19 日，全国首个具身智能实训场样板点在上海揭牌，由国地中心联合华为共同建设，覆盖机器人本体、数据、模型、评测、应用部署、ICT 底座等全链路。同日发布六大标杆场景（应急救援、能源电力、商业零售、汽车制造、城市服务、精密铸造），国地中心依托上海人形机器人中试服务平台已实现年产 2000 台（套）整机模组。智平方发布全球首个原创类脑大模型 NeuroVLA，首次将人脑皮层、小脑、脊髓协同机制引入机器人控制系统。

为什么关注：实训场的建成意味着具身智能从单点突破进入系统化工程阶段。华为昇腾算力 + 国地中心中试平台的组合，正在降低企业从"造出一台机器人"到"部署一群机器人"的门槛。六大场景签约 + 中试保险的推出，标志着政策、资本、产业链三方正在合力推动人形机器人跨过"死亡谷"。
