模型发布 SWE-Bench Pro 80.3%

Anthropic 发布第五代旗舰模型 Claude Fable 5 与 Mythos 5：编程与网络安全双线突破，Mythos 级能力首次面向公众

6月10日，Anthropic 正式发布第五代 Claude 系列模型——Claude Fable 5（通用市场）与 Claude Mythos 5（专业领域）。

核心亮点：Fable 5 在 SWE-Bench Pro 达到 80.3%，大幅领先 GPT-5.5（58.6%）和自家上代 Opus 4.8（69.2%）。FrontierCode 生产级编码基准更以 29.3% vs GPT-5.5 的 5.7% 碾压式领先。Stripe 实战中 1 天内完成 5000 万行 Ruby 代码迁移，原计划两个多月。

Mythos 5 则聚焦网络安全，ExploitBench 得分 78%（上代 40%），并具备科学假设生成能力——盲测中科学家约 80% 更倾向其分子生物学假设，药物设计速度提升 10 倍。

AI Coding 方向

工具竞争 24项功能趋同

Claude Code 与 Codex 24 项核心功能高度趋同：AI 编程智能体进入"同质化竞速"阶段

开发者 Elie Bakouch 对两家产品进行功能时间线对比后发现：从 2025 年 2 月到 2026 年 6 月，Claude Code 与 OpenAI Codex 在斜杠命令命名、技能格式、Dreaming 机制、多智能体协作等 24 项核心功能上呈现高度趋同，Codex 新功能平均仅领先 Claude Code 11 天。

但市场数据呈现分化：Claude Code npm 月下载量约 4630 万次，是 Codex CLI（约 1400 万次）的 3 倍多；但 Codex 周活跃用户数已反超 Claude Code。Notion 联合创始人 Simon Last 公开转向 Codex，理由是其"多端协同与平台化能力更强"。

差异化竞争的关键已从"谁能做出新功能"转向"谁的底层模型更强"——Fable 5 的发布恰好强化了 Anthropic 的模型护城河。

AI 编程工具的同质化趋势意味着：竞争正从"功能创新"转向"模型能力 + 生态绑定"的双维度博弈。Claude Code 在重度开发者中保持忠诚度（3 倍 npm 下载量），但 Codex 借助 ChatGPT 超级入口在企业用户中快速扩张。Fable 5 能否在"模型更强 + 工具更专业"的组合拳中拉开差距，将成为下半年 AI Coding 格局的最大变量。
政策驱动

工信部发布"AI+信息通信"三年实施意见：优化算力设施、推动 AI 与通信深度融合

6月10日，工信部正式发布《"人工智能+信息通信"创新发展实施意见（2026—2028年）》。文件聚焦 5G-A/6G、新一代光网络、"IPv6+"、工业互联网等方向，提出优化算力设施部署、推动信息通信行业智能化升级的总体目标：到 2028 年初步构建 AI 与信息通信融合互促的创新发展格局。

这是在 6 月 10 日同日发布的第二份 AI 重磅政策——此前工信部已联合国资委启动人形机器人实景实训专项行动。两天两份政策文件密集出台，信号明确。

算力基础设施是 AI Coding 和具身智能的共同底座。这份意见从"通信管道"层面为 AI 应用铺路——更智能的网络意味着更低延迟的边缘推理、更高效的分布式训练、更可靠的机器人远程操控。对开发者而言，"AI+通信"融合意味着未来的 AI 工具将从"本地/云端"延伸到"端-边-云"全链路。

具身智能方向

资本热浪 14 亿美元

德国 Neura Robotics 完成 14 亿美元 C 轮融资：英伟达/亚马逊/高通参投，欧洲具身智能跻身全球第一梯队

6月10日，德国人形机器人公司 Neura Robotics 宣布完成高达 14 亿美元 的 C 轮融资，投资方包括英伟达、亚马逊、高通、Tether、博世、舍弗勒及欧洲投资银行。融资后估值约 70 亿美元。

这是全球全栈机器人公司有史以来规模最大的一轮融资。CEO David Reger 表示："AI 的未来不仅在屏幕上，它将在现实世界中移动、互动、学习并与人类并肩工作。"

据 Dealroom 数据，2026 年至今全球机器人企业融资总额已达 558 亿美元，几乎是去年全年纪录的两倍。虽然主力仍在中美，但 Neura 的崛起标志着欧洲正式加入具身智能的全球竞赛。

558 亿美元意味着什么？整个机器人赛道正以前所未有的速度吸收资本。Neura 14 亿美元单轮融资 + 英伟达/亚马逊/高通全明星投资阵容，说明巨头对"AI 走出屏幕进入物理世界"的确定性共识已经形成。对从业者而言，这是一个信号：具身智能的资本泡沫与真实需求并存，但"谁有工厂订单、谁能真正部署"才是下一阶段的分水岭。
产业落地 量产冲刺

中国具身智能三重奏：何小鹏亲自带队 200 天冲刺量产 + 光象 Phi-Bot X1 发布 + 无锡产业链大会开幕

小鹏机器人量产前夜：6月10日，何小鹏发布全员内部信，宣布即日起亲自兼任机器人业务 CEO，称小鹏机器人已站在"量产和商业化的前夜"，相当于 8 年前小鹏汽车 G3 发布时的节点。过去一年他每周投入完整一天围绕机器人业务决策，"最后 200 天"冲刺量产目标。

光象科技 Phi-Bot X1：同日，光象科技发布行业首个工业级自进化具身智能机器人，面向高精度、多工位、高节拍工业场景，搭载自研物理原生智能模型，具备"一机多能、快速上岗、自我学习"三大核心能力。

无锡具身智能大会今日开幕：6月11日上午，2026 长三角机器人及自动化展览会暨无锡具身智能机器人产业链伙伴大会在无锡国际会议中心举行，智元、优必选、银河通用、科大讯飞、摩尔线程等顶流企业齐聚，展览持续至 6 月 13 日。

同一天内，一位汽车大佬宣布亲自下场、一家新锐公司发布工业级产品、一座城市举办产业链大会——三条线索指向同一个结论：中国具身智能正从"实验室炫技"进入"产线真干活"的阶段。何小鹏"最后 200 天"的紧迫感来自真实订单压力；Phi-Bot X1 的"自进化"能力直指工业场景的柔性生产刚需；无锡大会则折射出地方政府将具身智能视为下一个新能源汽车级产业的战略决心。
