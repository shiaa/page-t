OpenAI 收购 Ona（原 Gitpod）：为 Codex 补上持久化云端 Agent 能力

AI Coding OpenAI 产业整合

7 月 19 日确认，OpenAI 已完成收购德国云基础设施公司 Ona（原 Gitpod），为 Codex 引入持久化云端执行环境。这意味着 Agent 在开发者关闭电脑后仍可继续运行，完成跨天的重构、测试生成、文档编写等长周期任务。Ona 的客户控制执行模型让企业能在自有云环境中运行 Agent，保留访问控制、审计日志和 VPC 部署。

值得关注的原因：这是 AI 编程从"会话级工具"升级为"持久化 Agent 平台"的关键拐点。Codex 周活已超 500 万，非开发者用户占比约 20% 且增速更快。Ona 解决了长周期任务被会话中断的瓶颈，同时满足金融、医药等强监管行业的数据治理需求。7 月以来，SpaceX 收购 Cursor、Anthropic 推出 Ode、OpenAI 收购 Ona，AI 编程赛道已发生三次重大整合，独立 IDE 的生存空间正在加速压缩。
来源：51CTO 咕泡科技 · OpenAI 官方

Agent Data Injection（ADI）新攻击类型被正式提出，多家主流编码 Agent 受影响

AI Coding 安全 Prompt Injection

7 月 6 日提交的一篇 arXiv 论文正式将 Agent Data Injection（ADI）定义为新型攻击：攻击者通过伪造机器解析的元数据或工具响应（如资源标识符、JSON 字段、响应模板），让 Agent 将攻击者控制的内容视为"可信数据"。论文展示了针对 Claude Code、OpenAI Codex、Gemini CLI 等主流编码 Agent 的利用方式，并指出传统的指令注入防御对 ADI 无效，因为 ADI 滥用的是机器解析通道而非自然语言通道。

值得关注的原因：ADI 把 AI 安全攻防从"人可读文本"转移到"机器解析数据"层面，企业级部署必须重新审视数据溯源、schema 验证和可信/不可信通道分离。同期 Anthropic 已发布 Claude Code v2.1.211 补丁，增加子 Agent 追踪输出和 UI 字符消毒；OpenAI 也将 Codex 整合进统一的 ChatGPT 桌面客户端，强化权限管理。这些动作说明：AI Coding 的竞争焦点正从"能不能写"转向"敢不敢在生产环境跑"。
来源：AI Agent Store · arXiv:2607.05120

WAIC 2026 闭幕：具身智能定调"部署态元年"，从炫技表演转向晒工单干活

具身智能 WAIC 部署落地

7 月 20 日 WAIC 2026 闭幕，新华社发文定调"具身、兴业、善治"三大主线。今年具身智能展区从去年的 80 余家暴增至 200+ 家，展台气质明显切换：机器人表演少了，工厂流水线、仓储搬运、公共服务等真实作业场景成为主流。智元将 2026 年定义为具身智能"部署态元年"，多款机器人在现场承担实际任务而非展示动作。

值得关注的原因：行业评判标准已发生根本切换——从"能跑多快"变成"能干多少活、能不能持续干"。这标志具身智能从 Demo 阶段进入商业验证阶段。对企业采购决策者和供应链从业者而言，衡量指标正在从关节参数、步态视频切换为故障率、TCO、交付周期和真实场景 ROI。
来源：每日经济新闻 · 新华社

智元精灵 G2 Max 在京东物流真实仓储部署，人形机器人首次进入规模化生产场景

具身智能 智元 京东物流

WAIC 期间，智元机器人集中发布 5 款新品，其中远征 A3 Ultra 被评为 WAIC 十大"镇馆之宝"中唯一入选的具身智能机器人。更值得关注的是精灵 G2 Max 与京东物流合作的场景——这是人形机器人首次在真实仓储作业生产场景中部署落地：单臂负载 18kg、双臂峰值 50kg，可实现 24 小时不间断搬运码垛。此外，智元联合擎天租在三地四馆部署 60 台机器人承担指路引导公共服务，被称为行业首次实现具身智能"部署态"公共服务。

值得关注的原因："真实仓储部署"是具身智能商业化的分水岭事件。相比实验室跑分或展会表演，京东物流场景意味着需要对接 WMS、满足安全规范、承受夜班连续作业和真实货损责任。如果后续能披露稳定运行时长、效率对比和 ROI 数据，将对整个人形机器人赛道产生估值重估效应。

华为 × 国地中心：全国首个国产化具身智能实训场揭牌，真机训练成本从百万级摊薄至共享级

具身智能 华为 国产化

7 月 19 日，国家地方共建人形机器人创新中心与华为在 WAIC 正式揭牌全国首个国产化具身智能实训场样板点。该实训场依托国产算力底座，搭载 VLA 大模型，从"固态训练"升级到兼顾室内与生产现场的"动态训练"。同期上海人形机器人中试服务平台启用，年整机试制产能达 2000 台；国地中心与卓益得完成千台套人形机器人试制专项签约。

值得关注的原因：具身智能长期被"真机训练成本动辄百万"卡住脖子，中小企业难以高频迭代。实训场通过开放共享把训练成本摊薄到可承受范围，相当于给行业提供"公共健身房"；华为的加入补上了国产算力底座这一关键短板。从实训场到中试平台再到千台套签约，具身智能的"研发→验证→量产"全链条在 WAIC 上首次完整落地，量产闭环开始形成。
