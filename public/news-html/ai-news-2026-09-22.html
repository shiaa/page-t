OpenAI 被曝加紧备战 Grok Bot 与 Muse，智能体之争从"会聊天"转向"能办事"

智能体竞争 OpenAI 行业格局

据财联社 9 月 22 日报道，随着 SpaceX 上月推出可跨应用自主完成多步骤任务的 Grok Bot（纳入月费 30 美元 SuperGrok，定位"数字幕僚长"，即便本地设备关机仍可运行，能在 Gmail、Notion、Figma 中直接执行操作），以及 Meta 9 月初推出消费级智能体 Muse（免费版 + 20/100 美元档），OpenAI 据称正开发新功能直接对标 Grok Bot，并讨论推出专门的个人 AI 助手以抗衡 Muse。报道指出，OpenAI 预计不会从零搭建，而是将 ChatGPT 与编程工具 Codex 中现有的智能体能力加以改造、重新包装推出。

值得关注的原因：智能体竞争焦点正从"会聊天"转向"能办事"，跨应用自主完成多步骤任务成为新战场。对 AI Coding 而言，Codex 的 Agent 能力被包装进通用个人助理，印证"编程 Agent 是通往通用 Agent 的桥头堡"——谁能把代码智能体做扎实，谁就握住了通往办公、生活自动化的入口。与此同时，平台与 Agent 的冲突已经出现（亚马逊封禁 Meta 购物 Agent Muse 流量，定性为未授权自动化），Agent 准入规则将成为下一个行业变量。

月之暗面推出 Kimi Code Desktop，编程 Agent 正式上桌面

AI Coding 月之暗面 桌面端

9 月 21 日，月之暗面发布 Kimi Code Desktop，macOS（Apple / Intel 芯片）与 Windows 版同步上线，访问 kimi.com/code 即可安装。作为 Kimi Code 官方桌面客户端，它把原本 CLI 形态的编程 Agent 套上图形界面：用户可在桌面端对话式读写代码、运行命令、完成自动化任务，并集中管理项目与配置、逐条查看 Agent 执行步骤。客户端内置终端、浏览器与 Git 状态视图，支持 Plan（先审方案后动手）、Goal（长程目标）、Swarm 及实验性 Tower（多 Agent 并行）模式；底层由 K3 旗舰模型驱动（2.8T 参数、最高 100 万 token 上下文）。

值得关注的原因：编程 Agent 正从"终端命令"走向"可视化工作台"，Kimi 与 Claude Code、Cursor 同台竞争"桌面原生 Agent"形态。内置浏览器闭环验证、截图标注补前端样式、Tower 多 Agent 并行，都是把 Agent 从"补全"推向"承包整段工程"的关键交互创新；K3 的百万级上下文也更适合长程编程与大型代码库。对习惯国内工具链的开发者，这是继 Codex / Claude 之后又一个值得接入的生产力选项。

华为云码道上线鸿蒙编码大模型，一句话生成应用

AI Coding 华为云 鸿蒙生态

据腾讯研究院 9 月 22 日速递，华为云码道 CodeArts 面向鸿蒙开发者升级，上线鸿蒙编码大模型、码道鸿蒙智能体与开发者实践中心，瞄准超 1100 万鸿蒙开发者的开发门槛。模型融合超百万鸿蒙原生素材，千行代码错误率降低 80% 以上、一次编译通过率提升 78% 以上、单次任务 Token 消耗降低 20% 以上，已上线 MaaS 供企业调用。

值得关注的原因：这是大厂把"领域专用编码大模型"直接嵌入开发平台、绑定自有生态（鸿蒙）的典型打法——用一手生态语料换取更低的错误率与更高的编译通过率。对鸿蒙原生应用开发者是实打实的提效；对行业则意味着 AI Coding 竞争正从"通用编程"下沉到"框架 / 平台专属编程"，谁掌握生态与语料，谁就掌握垂直场景的编程入口。

智元 × 长隆联手打造全球首个大型具身智能主题乐园，超 300 台机器人上岗

具身智能 智元 AGIBOT 文旅落地

据每日经济新闻 9 月 21 日报道，由智元（AGIBOT）与长隆集团联手打造的全球首个大型具身智能主题乐园将于 9 月 24 日正式启幕，开园当日超 300 台智元全系机器人将在横琴长隆飞船乐园集体"上岗"。

值得关注的原因：具身智能正从实验室、工业产线迈入文旅消费这类高客流、高交互的公开场景。超 300 台机器人集体上岗，不仅是品牌秀，更是一次多机协同、人机交互、稳定运维与真实数据闭环的大规模压力测试——能否从"开园爆点"变成可持续运营 IP，取决于成本、可靠性与体验差异化。它标志具身智能商业化从 B 端作业走向 C 端体验的关键一步。

海光信息发布 1000 系列 CPU，"让算力抵达物理世界"直指端侧机器人算力

具身智能 海光信息 端侧算力

据快科技 9 月 21 日消息，海光信息于 9 月 22 日在深圳发布全新 1000 系列 CPU，发布会主题"让算力，抵达物理世界"。该系列定位轻量级 CPU，采用 C86 架构，主攻低功耗、嵌入式与端侧算力，面向边缘终端、工业设备和物联网节点，为机器人、机器视觉、智能制造等真实场景提供基础算力，补齐海光从数据中心到端侧的产品矩阵。2026 上半年海光营收 90.99 亿元（同比 +66.52%），研发费用 26.52 亿元（占营收 29.15%）。

值得关注的原因：AI 从数字世界走向物理世界，对芯片的实时性、低功耗、安全性与边缘算力提出全新要求。海光以 C86 架构切入端侧，意味着国产算力开始系统性下沉到机器人 / 工业视觉 / 智能制造的"身体"里——具身智能的瓶颈不只在算法与数据，也在能否在低功耗端侧跑起可靠算力。芯片厂与机器人、工业软件企业的协同将更紧密，端侧算力成为具身产业化的底层变量。
