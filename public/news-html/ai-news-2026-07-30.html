MCP 协议史上最大改版正式发布：彻底无状态化，AI Agent 基础设施迎来转折点

基础设施 MCP 协议标准

7 月 28 日，Model Context Protocol（MCP）正式发布 2026-07-28 版本规范，官方称之为"自发布以来最大规模修订"。核心变化是彻底移除协议层的有状态设计——initialize 握手与 Mcp-Session-Id 全部删除，每个请求自包含所有必要信息，任意服务实例均可独立处理。同时引入了 Extensions 框架、Tasks 扩展、MCP Apps 及企业级授权（EMA）。GitHub MCP Server 同日上线新版本支持，移除了 Redis 和深度包检测依赖。主流 SDK（Python/TypeScript/Go/C#）均保持向后兼容。

值得关注的原因：如果说大模型是 AI Agent 的"大脑"，MCP 就是连接大脑与外部世界的"神经系统"。这次无状态化改版直接解决了生产环境最大痛点——旧版本每次调用都绑定到特定实例，水平扩展需要黏性路由或共享 Session 存储（如 Redis），运维成本极高。新版本让 MCP 服务器可以跑在普通轮询负载均衡后面，网关只需看 HTTP Header 就能路由。这不只是一次协议优化，它标志着 AI Agent 从"笔记本 Demo"正式进入"企业级可运维"阶段。对 AI Coding 工具开发者而言，远程工具调用的部署门槛大幅降低。

腾讯云发布 CodeBuddy NPC：首个 AI Native Git 范式产品，AI 编程进入"工程化协作"阶段

AI Coding 腾讯云 研发流程

7 月 29 日，腾讯云正式发布云端智能体 CodeBuddy NPC。开发者只需在云端开发平台 @ 一下 NPC，即可派发任务——NPC 自主完成问题调查、方案制定、代码开发、PR 提交，并根据 CI 结果持续修复，直到交付可验收的成果。这是业内首个提出并落地 AI Native Git 范式的产品，基于沉淀 8 年的 CNB 云原生构建平台（月活开发者超 10 万）。腾讯云将 AI 研发角色演进分为三个阶段：辅助研发 → 驱动开发 → 工程化协作，CodeBuddy NPC 定位在第三阶段。

值得关注的原因：2026 年上半年的 AI Coding 竞争焦点一直是"谁写的代码更快更准"，但 CodeBuddy NPC 把战场拉到了"谁能真正嵌入研发流程"。一款 AI 编程工具能不能像一个真正的团队成员那样接任务、走流程、交成果——这才是企业级落地的关键。NPC 背后是腾讯云 WorkBuddy → CodeBuddy → CNB 的产品矩阵布局，与 GitHub Copilot 的云端 Agent（7 月 23 日 GA，支持 Linear 集成）形成正面竞争。对 SRE/DevOps 从业者来说，这种"Agent 即队友"的范式会直接改变日常工作的协作方式。

月之暗面 Kimi K3 全量开源（2.8 万亿参数），蝉联前端开发榜全球第一

AI Coding 开源模型 国产突破

7 月 27 日，月之暗面正式宣布将旗舰大模型 Kimi K3 全量开源，总参数达 2.8 万亿，是目前全球参数规模最大的开源大模型。开源内容包括完整模型权重、技术报告及三项底层基础设施技术，全球开发者可免费下载和本地部署。同日 Arena 第 30 周榜单显示，Kimi K3 以 1682 分卫冕前端开发榜全球第一，超越 Claude Opus 5-high，代码榜升至第 8，智能体榜位列第 4（任务确认成功率 14.0% 为头部最高）。

值得关注的原因：Kimi K3 全量开源是一个多重信号事件。首先是规模——2.8 万亿参数的开源意味着企业可以完全自主部署一个与顶尖闭源模型比肩的基础设施，不受 API 调用限制；其次是前端开发能力登顶——国产模型在编程细分赛道上首次实现对 Claude 的超越，且 Arena 榜单近半数席位已被国产模型占据。对 AI Coding 生态来说，一个强大且完全开源的前端编程模型，将直接降低中小团队使用 AI 辅助开发的成本和门槛。央视 7 月 30 日也对此进行了专题报道，足见国家层面对此的重视。

头部车企密集布局人形机器人：比亚迪 8 月亮相，小鹏 IRON 量产在即，理想年内发布

具身智能 人形机器人 车企入局

7 月 28-29 日，多家头部车企集中释放人形机器人量产信号。比亚迪确认将于 8 月在"迪空间"正式发布自研人形机器人，这是其首次以官方身份公开展示实体样机；小鹏 IRON 人形机器人 7 月 24 日已在广州工厂开启小批量试生产，量产产线进入最后联调，2026 年底月产能目标突破 1000 台，2027 年 Q1 率先投放直营门店；理想汽车规划"双轮+双足"两款机器人，双轮款计划年内发布。工信部数据显示，2025 年国内人形机器人产量约 2 万台，2026 上半年已超 4 万台，全年预计超 10 万台。

值得关注的原因：车企造机器人不是跨界玩票——智能汽车与人形机器人的技术重合度超过 70%（感知、规划、控制、芯片、传感器），供应链高度共享，汽车工厂本身就是机器人最佳的首批落地场景。比亚迪入局尤其值得关注：作为全球最大新能源车企，其制造场景的规模效应和供应链议价能力可能加速人形机器人从"万元级"向"千元级"的成本下探。2026 年被业界公认为人形机器人"量产验证与场景落地"的关键窗口，车企的批量入局正在把这个窗口变成现实。

亚马逊战略大转向：砍掉多数 Nova AI 模型，集中资源由伯克利机器人专家挂帅攻坚具身智能

具身智能 亚马逊 战略转向

7 月 30 日，彭博社援引内部人士消息，亚马逊正在大幅收缩其 Nova 系列 AI 模型矩阵——文本模型、视频生成、图像生成几乎全部被打入"最低限度维持"状态，资源集中转向一个由 Pieter Abbeel 执掌的"前沿模型项目"。Abbeel 是伯克利机器人学习实验室主任、机器人公司 Covariant 联合创始人（2024 年被亚马逊整体收购），专攻面向机器人的 AI 模型。此前一周，亚马逊已关闭了旧金山约 80 人的 AGI 研究办公室。

值得关注的原因：这是近期 AI 行业最有信号意义的战略撤退。在谷歌、微软、Meta 仍在通用大模型赛道狂飙时，亚马逊选择主动从 LLM 竞赛中抽身，把 AI 的赌注全部押在物理世界自动化上——仓库机器人、物流自动化才是它真正有场景、有数据、有商业闭环的阵地。Pieter Abbeel 的挂帅意味着亚马逊不是放弃 AI，而是换了一个更有差异化优势的赛道。这也给行业提了个醒：当 LLM 投资回报的不确定性越来越高，拥有真实物理场景的公司会越来越倾向于把资源投向具身智能而非通用对话模型。
