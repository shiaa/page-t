模型底座双线突破：GPT-6 Astra 全量推送 + Anthropic 披露 Claude 主导 26% 研发

行业头条 OpenAI Anthropic

OpenAI 于 9 月 3 日发布、本周起向 ChatGPT Plus/Pro/Business/Enterprise 及 API、Azure、AWS Bedrock 全面推送 GPT-6 Astra。其采用 looped transformer 与原生多智能体架构（中枢 Agent 调度子 Agent 并行调试代码），支持 105 万 token 上下文，定价 $10/$50（百万 token）；在 ExploitBench 满分、ARC-AGI-3 99.9%、FrontierMath Tier 4 97.6%，并首次达到 OpenAI "Critical" 级网络安全门槛。

同期 Anthropic 9 月 17 日披露：截至 8 月，Claude 已主导公司 26% 的 AI 研发工作（3 月仅 1%），内部同时运行超 3 万个自主 AI 智能体，全程参与模型迭代、代码优化与算法调试。

值得关注的原因：两条新闻共同指向一个拐点——大模型正从"被使用的工具"变成"能自我迭代的研发主体"。GPT-6 Astra 的原生多智能体架构直接抬高了编码 / Agent 产品的能力上限，是本期几乎所有 AI Coding 动态的底座；而 Anthropic 用 3 万 Agent 跑通"机器驱动技术革新"的闭环，意味着头部公司的研发杠杆正被 AI 重写。对运维 / SRE 而言，这预示着"用 Agent 监督 Agent、用模型运维模型"的范式离生产落地更近一步。

GitHub Copilot 平台化升级并接入 Grok 4.7，编码 Agent 进入"可观测 + 成本可控"阶段

AI Coding GitHub Copilot xAI

GitHub 9 月中旬连发更新：Copilot Auto 模型选择新增"效率 / 均衡 / 智能"三档成本质量分层（9/14）；预算增加请求 GA（9/16）；Agent 遥测扩展至自定义 CLI、skills、MCP 服务器与插件用量指标 API（9/17）；代码审查（自动修复、智能提交信息）GA（9/18）。

同期 Copilot 模型选择器接入 xAI Grok 4.7（2.1T 参数，$2/$6 定价），在 CursorBench 4.0 得分 46.3%，Terminal-Bench 4.0 从 20.3% 升至 38.0%。

值得关注的原因：编码 Agent 的竞争焦点已从"谁写代码更快"转向"谁能把 Agent 工程化、可治理"。成本 / 质量分层、预算闸门、遥测指标三件套，本质是给企业一把"油门和仪表盘"——这正是 DevOps / SRE 团队把编码 Agent 搬进生产流水线前最关心的可控性问题。Grok 4.7 以一半价格切入，也预示编码模型市场价格战持续升温，推理成本下行利好中小团队。

Google 开源 Mantis 漏洞审查技能包，编码智能体从"写功能"走向"守安全"

AI Coding Google 安全左移

Google 开源 Mantis 模块化技能工具包（9/9），让编码智能体自动完成"发现缺陷 → 过滤误报 → 沙箱复现 → 写最小补丁 → 对补丁再攻击并给出 1-10 风险评分"的完整闭环。工具包协议无关，可挂载到既有 CI/CD 与代码库。

值得关注的原因：这是编码智能体角色的一次质变——从"生成代码的劳动力"升级为"守门的安全工程师"。结合本期 RubyGems / Hugging Face 因 Agent 评估运行引发的供应链与沙箱逃逸事件，"把安全左移交给 Agent"不再是口号而是可落地的开源工具。对运维 / 安全团队，这意味着把漏洞审查嵌进 PR 流程的边际成本大幅下降，但也反向要求更严格的 Agent 沙箱隔离与最小权限策略。

智元机器人 GO-1 通用具身基座大模型全面开源（ViLLA 架构，9/23 免费开放）

具身智能 智元机器人 开源

9 月 23 日，智元机器人 GO-1 通用具身基座大模型全面开源，这是全球首个采用 ViLLA（Vision-Language-Latent-Action）架构的通用具身智能模型，面向开发者免费开放，显著降低具身智能技术门槛。同期智元控股的上纬新材完成股份过户，邓泰华成为实际控制人，资本与技术的绑定进一步加深。

值得关注的原因：具身智能过去最大的瓶颈是"数据-模型-本体"高度耦合、各家各自训练。GO-1 以 ViLLA 架构把"通用动作表征"抽离出来开源，相当于给行业提供了一套可复用的"具身操作系统底座"——中小团队无需从零训模型即可驱动不同形态机器人。这与本期清华 × 无问芯穹开源 RPent 具身基础设施、服贸会展示 150 万小时人类行为数据集开源同频，具身智能的"基础设施层"正在快速成形。

具身智能"量产元年"：小鹏 / 特斯拉产线落地，高盛大幅上调出货量，宇树等集中上市

具身智能 量产 产业链

小鹏机器人 9 月 9 日启用生产线、全球首位通用人形机器人自主走下产线，计划年底进入规模量产、2027 年海内外上市；特斯拉将弗里蒙特工厂改造成 Optimus 专用产线，目标年底生产 10 万台，并已在长三角推进供应链审厂。

高盛最新报告大幅上调预期：全球人形机器人出货量由 2026 年约 7.5 万台增至 2030 年约 89 万台（此前预测 25.6 万）；德银亦上调至 2030 年 70 万台，并认为中国是全球增长核心引擎。资本侧集中上市：宇树科技 8 月登陆科创板，梅卡曼德 9 月港交所上市，本末科技 9 月 29 日挂牌，全产业链近 40 家企业组成 IPO 预备梯队；上半年国内具身智能融资 935 亿元，同比增 5 倍。

值得关注的原因：行业评价维度正从"跑蹦跳的技术秀"转向"能否真正干活、能否规模量产"。小鹏 / 特斯拉把汽车产线经验迁移到机器人制造（每 2.5 分钟下线一台），叠加高盛对出货量的数倍上调与一级市场资金向头部集中，说明具身智能已从概念机跨入"上量"阶段。对关注该赛道的运维 / DevOps 工程师，机器人本体的 OTA、端侧算力、力传感器与数据闭环正成为新的工程机会点。
