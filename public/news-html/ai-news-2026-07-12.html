OpenAI GPT-5.6 系列正式公开，Sol/Terra/Luna 三档定价，多 Agent 并行能力成旗舰标配

旗舰模型 OpenAI 多 Agent

7 月 9 日 OpenAI 结束 12 天受限预览，正式向全球开放 GPT-5.6 系列：旗舰 Sol、中端 Terra、高速低成本 Luna，并引入"持久能力档位"概念——档位名而非版本号可跨代延续。Sol 在 Artificial Analysis 编码 Agent 指数拿到 80 分（领先 Claude Fable 5 共 2.8 分），ExploitBench 网络安全 73.5%（对比 GPT-5.5 仅 47.9%）；ultra 模式默认协调 4 个并行 Agent，可扩展到 16 个。定价 Sol 5/30 美元、Terra 2.5/15 美元、Luna 1/6 美元每百万 token。同日发布的 ChatGPT Work 把聊天、编码、长任务 Agent 统一到同一界面，Responses API 的 Programmatic Tool Calling 允许模型写小程序内联调度工具。

值得关注的原因：GPT-5.6 把"多 Agent 并行"从论文概念推到商业 SKU，是模型厂商第一次把"协作"作为公共能力层卖——对企业内自建 Agent 平台的冲击是结构性的：单 Agent 解决不了的项目级任务，现在 OpenAI 直接包办。定价 5/30 美元相对 Opus 4.8 的 5/25 美元基本持平，附加能力却拉满；Luna 的 1/6 美元则把高频低成本赛道的价格底线进一步压低。对 AI Coding 开发者来说，工具栈组合（Claude Opus 4.8 写难代码 + GPT-5.6 Sol 调度多 Agent + Luna 处理日常对话）会变成 7 月底新默认。

OpenAI GPT-Live 同步全双工语音上线，Agent 入口从键盘扩展到"会听话的嘴"

多模态 OpenAI 实时语音

7 月 8 日，OpenAI 在全球推送 GPT-Live 全双工语音模型，分 GPT-Live-1 与 GPT-Live-1 mini 两档。区别于传统级联式或轮询式语音方案，GPT-Live 同时持续收听与生成响应，每秒做多次"说话/倾听/沉默/打断/调用工具"的决策，能识别"嗯、是的"等伴随反馈语、保留自然停顿，并支持实时同传。遇到需要深度推理的问题，它会后台把任务交给 GPT-5.5 再把结果拉回主对话，不打断节奏。GPQA 与 BrowseComp 上大幅领先 Advanced Voice Mode。

值得关注的原因：GPT-Live 是 Agent 范式的入口扩展——AI 不再只是 IDE 里那个编辑器，而是会议室、运维值班台、车里、电话里都能对话的同事。对 SRE 场景尤其值得关注：未来 ops Agent 可能直接接电话/听监控告警音并发起处置流程，值班工程师的"听与说"成为新的人机接口。结合 ChatGPT Work，这预示 OpenAI 正把 Agent 生态从"屏幕"扩展到"耳朵和嘴"。

Wiz 披露 GhostApproval 高危漏洞，六大主流 AI 编程助手可被恶意仓库静默植入 SSH 公钥

AI Coding 安全漏洞 供应链

7 月 8 日，安全公司 Wiz 公开 GhostApproval（CVE-2026-12958 等）——利用 Unix 符号链接，让 AI 编程助手把攻击者控制的 SSH 公钥写入 ~/.ssh/authorized_keys，全程无异常提示。影响产品：Amazon Q Developer、Anthropic Claude Code、Augment、Cursor、Google Antigravity、Windsurf。核心问题是"代理内部已识别危险路径，但审批对话框只显示无害的符号链接名"，属于 CWE-61 + CWE-451 的复合设计缺陷。Amazon Q Developer v1.69.0、Cursor v3.0、Google Antigravity v1.19.6 已修复；Windsurf 甚至在弹窗前就完成写入；Anthropic 主张该场景"超出威胁模型"引发争议。Claude Code 内部推理链识别出了异常，却没有同步到 UI。

值得关注的原因：这不是单点 bug，是 AI Coding 工具的"类别级盲区"——任何"人在回路"的工具只要把显示层和实际写盘行为解耦，就会落入同一陷阱。Wiz 三条缓解建议（规范化路径解析、跨工作区警告、写前授权）会成为后续所有 AI Agent 类产品的安全基线。对 SRE / DevOps 来说，开源仓库"一键 setup" 流程要重新审视，~/.zshrc、~/.git-credentials 也可能成为攻击目标——Agent 时代，clone 仓库 = 执行未知代码。

Meta Muse Spark 1.1 发布，Z uckerberg 时隔三年重返 X 力推"低价多面手 Agent"

AI Coding Meta Agent

7 月 9 日 Meta 发布 Muse Spark 1.1，主打 Agent 任务：100 万 token 上下文 + context compaction 支持长会话，主/子 Agent 委派模式，三种 computer-use 执行模式（脚本/点击/批量）。Agent 基准上，JobBench 54.7%（领先 Claude Opus 4.8 的 48.4%）、MCP Atlas 88.1（领先 82.2）；但纯编码基准 Vibe Code Bench 从 19.7% 跳到 72.2% 同时，SWE-Bench Pro 仅 61.5% 仍弱于 Opus 4.8 的 69.2%、DeepSWE 1.1 53.3% vs 59.0%。Zuckerberg 在 X 发文"This is an incredibly capable agent and coding model at a very low price"，是三年来首次发推。

值得关注的原因：Meta 的策略很清晰：放弃"卷纯代码基准第一"，转而用"低价 + Agent 编排能力"做差异化。SWE-Bench Pro 的差距说明纯硬编码场景仍落后 Anthropic；但 JobBench 和 MCP Atlas 的领先说明 Meta 在"让 Agent 协调工具、跨任务长跑"上找到了位置。对 AI Coding 用户，意味着大模型选型将出现更细致的分层——难代码给 Claude Opus 4.8、长任务编排给 Muse Spark 1.1、纯 Agent 协作给 GPT-5.6 Sol，单一模型通吃的时代正在结束。

NVIDIA × Hugging Face 联手开源人形机器人管线，Isaac GR00T 1.7 + LeRobot 打通行采集到部署全链路

具身智能 开源生态 VLA 模型

7 月 7 日 NVIDIA 与 Hugging Face 宣布扩展机器人合作：把 Isaac GR00T 1.7 视觉-语言-动作模型和 Isaac Teleop 数据采集框架集成进开源 LeRobot 库。GR00T 1.7 被官方称为"首个开放且商业可用的人形机器人大模型"——开发者无需任何专有工具链，就能在标准 LeRobot 工作流中微调与部署；Isaac Teleop 把高保真人示教数据采集为可互操作格式直接喂给 LeRobot 数据集。路线图上的 Cosmos 3 是合成数据世界基础模型，专治真实世界采集"贵且危险"的痛点。两家分别拥有 300 万机器人开发者与 1600 万 AI 构建者社群，形成"遥操 → GR00T 训练 → Cosmos 仿真 → LeRobot 部署"统一管线。

值得关注的原因：人形机器人领域第一次出现"全栈开源管线"——过去 VLA 模型、仿真平台、数据采集、部署框架都分散在各家手里。NVIDIA 把训练栈开放给 Hugging Face 社区，等于把通用人形机器人的开发门槛从"公司级项目"降到"个人开发者级别"。Cosmos 3 合成数据如果做出来，行业"数据稀缺"的核心瓶颈会被彻底改写。叠加即将开幕的 WAIC 2026（智算+具身两大赛道各汇聚 200+ 企业），具身智能的开源格局正在 7 月形成清晰分水岭。

WAIC 2026 将于 7/17-20 在上海三地四馆启幕，智算与具身智能各聚 200+ 企业

具身智能 WAIC 产业大会
