行业头条

监管收紧 合规升级

1Anthropic 宣布 7 月 8 日起强制实名制刷脸 + OpenAI 遭多州联合调查——AI 行业合规监管骤然升级

过去 24 小时，两起事件标志着 AI 行业监管正在从"政策讨论"加速进入"强执行阶段"：

Anthropic：强制实名制刷脸
  • 自 7 月 8 日起，Claude 免费/Pro/Max 用户需完成身份验证
  • 要求：上传带照片的政府签发证件（身份证/护照/驾照）
  • 拍摄实时自拍进行人脸比对
  • 商业客户（API/企业版）暂不受影响
  • X 平台引发热议："和 AI 聊天前先证明自己是人"
OpenAI：多州联合传票调查
  • 纽约州等多州总检察长联合发出传票
  • 调查覆盖广告、数据使用、未成年人保护、模型输出行为
  • 背景：OpenAI 已秘密提交 IPO 招股书
  • 早期员工及投资者已套现约 140 亿美元
  • OpenAI 回应"将配合调查"

更深层的背景：Anthropic 的实名制举措与 Fable 5 被美国政府出口管制下架的余波密切相关——模型能力越强，合规压力越大。而 OpenAI 的多州调查发生在 IPO 关键时刻，意味着 AI 企业在走向公开市场的同时，也将面临更严格的监管审查。两件事指向同一个趋势：AI 行业正在结束"野蛮生长"阶段，进入强合规时代。Anthropic 选择在 7 月 8 日（而非立即）实施也暗示了缓冲期——但方向已不可逆。

💡 为什么重要

实名制刷脸对 AI 编程的影响尤为直接：全球数百万开发者每天通过 Claude Code 进行编程工作，如果身份验证流程复杂化（尤其是对非美国用户），使用门槛将大幅提升。同时，Fable 5 被封禁+OpenAI 被调查+Anthropic 实名制三条线索共振，表明美国政府正在构建一套覆盖出口管制、数据合规、用户身份的多维 AI 监管体系。对于中国开发者而言，这意味着"用国外模型写代码"这条路径的不确定性正在系统性上升——实名制只是第一关，后续可能还有更严格的区域限制或内容审查。从产业层面看，监管加码将加速模型可用性从"能力驱动"转向"合规驱动"——谁的模型合规成本更低、可及性更高，谁就能获得更广泛的开发者基础。

AI Coding 方向

产品上线

2Kimi K2.7 Code 高速版今日正式上线——260 tokens/s，成本不到 GPT-5.5 1/3，编程模型的效率竞赛进入新阶段

月之暗面今日宣布 Kimi K2.7 Code 高速版正式上线，向 Kimi Code Beta 计划成员、Kimi API 开发者及 Kimi Business 用户全面开放。高速版与普通版是同一模型，但输出速度提升至 5-6 倍——常规场景约 180 tokens/s，短上下文场景最高可达 260 tokens/s。

K2.7 Code 核心性能
  • Kimi Code Bench v2：提升 +21.8%
  • Program-Bench：提升 +11%
  • MLS Bench Lite：提升 +31.5%
  • Agent 自主执行基准：提升约 10%
  • 长上下文编程指令遵循能力显著增强
效率与成本突破
  • 推理 Token 消耗降低 30%
  • 整体成本不到 GPT-5.5 的 1/3
  • 5 分钟内复刻《我的世界》，测试总花费 约 6.99 元
  • 输入价 6.5 元/M tokens，缓存价 1.3 元
  • MIT 协议开源，自由商用

关键洞察：K2.7 Code 的高速版并非只是"跑得更快"——它代表了一个趋势：编程模型的竞争已从"能不能写对"进入"多快能写好"的阶段。260 tokens/s 意味着开发者可以在近乎实时交互的体验中完成复杂编程任务，这对于 AI Coding 从"辅助工具"升级为"编程基础设施"至关重要。同时，开源+低价的策略正在系统性地压低 AI 编程工具的使用成本——当 6.99 元就能复刻 Minecraft，个人开发者和中小团队的门槛已被拉至历史最低点。

💡 为什么重要

K2.7 Code 发布是本周 AI Coding 方向最直接的产品信号。三个维度值得关注：第一，开源 MIT 协议意味着任何人都可以本地部署，不受地缘政治和出口管制影响——在 Fable 5 被禁的背景下，这一点的战略价值被放大；第二，260 tokens/s 的速度将显著改善 Agent 编程场景的交互体验——Agent 需要多轮推理和工具调用，速度直接决定了可用性上限；第三，成本结构（不到 GPT-5.5 1/3）揭示了编程模型的价格竞争正在进入"内卷"阶段——当性能和速度都追上来，价格就成了最后一公里的胜负手。对于中国 AI 编程生态而言，K2.7 Code + DeepSeek + Qwen 正在形成一套"不用看人脸色"的完整替代方案。

范式革新

3Loop Engineering 引爆 AI 编程圈——从"写提示词"到"设计自动循环"，2026 年第四大 AI 工程方向诞生

2026 年 6 月，一条仅 12 个字的推文引爆了整个 AI 编程社区。OpenClaw 创始人 Peter Steinberger（前 OpenAI 核心工程师）写道："你不该再手动给 Agent 写提示词了，你应该设计让 Agent 自己驱动自己的循环系统。"这条推文获得超过 800 万次浏览，随后 Google 工程总监 Addy Osmani 将其正式命名为 Loop Engineering（循环工程），将其定位为 2026 年 AI 领域的第四大工程方向。

传统 Prompt Engineering
  • 人在循环中（Human-in-the-Loop）
  • 每次任务需手动拆分步骤
  • 提示词技巧是核心竞争力
  • Agent 单次执行，出错即停
  • 人工检查结果，调整后再跑
  • 重复性"写 prompt → 看结果 → 改 prompt"
Loop Engineering 新范式
  • Agent 在循环中（Agent-in-the-Loop）
  • 仅定义目标和边界，Agent 自主拆解
  • 设计循环系统替代提示词技巧
  • 自动重试、自我纠错、持续迭代
  • 设定成功标准，Agent 闭环运行
  • "定目标 → 跑循环 → 收成果"

五大模块构成：Loop Engineering 将 AI 自主工作流分解为五个核心模块——目标定义（Goal）→ 计划生成（Plan）→ 执行循环（Execute）→ 验证判断（Verify）→ 反馈调整（Feedback）。关键创新在于，这五个模块形成一个闭环，Agent 在其中自动运转，人类只需定义第 1 步和第 5 步的边界条件。同期，TerminalTraj 入选 ICML 2026——该研究将 GitHub 真实仓库转化为可执行终端轨迹，构建了 32K Docker 镜像和 5 万余条验证轨迹，为 Loop Engineering 提供了训练数据基础。

💡 为什么重要

Loop Engineering 不是又一个 buzzword——它回答了一个结构性问题：当 AI 编程能力已经很强的时候，为什么还需要程序员？答案正在从"写代码"转向"设计系统"。Loop Engineering 的本质是重新定义人与 AI 的分工：人负责定义目标、约束和验收标准，AI 负责在循环中自主探索执行路径。这直接对应了当前 Claude Code Dynamic Workflows、OrcaRouter 多模型路由、Codex 多 Agent 编排等前沿产品正在探索的方向。更深层的意义在于：一旦 Loop Engineering 成为主流，单个开发者的产出将不再受限于个人编码速度，而是受限于定义问题和验收结果的能力——这对整个软件工程行业的人才结构、团队组织和评估体系都将产生深远影响。Prompts Engineering 可能逐步成为"过时技能"，就像今天很少有人再手写汇编一样。

具身智能方向

融资突破

4大晓机器人完成天使+轮融资数亿美元——商汤系，Kairos 世界模型 4B 参数登顶全球四大具身智能榜单

6 月 15 日，上海大晓机器人公司宣布完成天使+轮融资，2026 年上半年累计融资 数亿美元。本轮由吉利资本、达晨财智、深创投、上海科创基金、临港新片区基金等机构参投，老股东商汤国香资本持续增资。投资人阵容覆盖"产业资本+财务基金+国资平台+高校基金"，堪称中国具身智能领域迄今为止最豪华的早期投资阵容。

大晓机器人由商汤科技联合创始人王晓刚创立，澳大利亚科学院院士 陶大程担任首席科学家。公司自主研发的开悟（Kairos）世界模型在具身视频生成、任务指令追随、泛化能力、场景鲁棒性四大维度达到业内领先水平，4B 参数性能超越 28B 参数模型。该模型已向全行业开源，为具身智能机器人提供端到端的感知-决策-执行能力底座。

Kairos 世界模型：四大领先
  • 具身视频生成：高保真物理交互模拟
  • 任务指令追随：复杂指令精准执行
  • 泛化能力：跨场景/跨任务迁移
  • 场景鲁棒性：非结构化环境稳表现
  • 参数规模 4B，性能超越 28B 模型
ACE 研发范式创新
  • 环境式数据采集：类人自然交互数据
  • 世界模型：物理规律内化建模
  • 泛化具身模组：即插即用的硬件适配
  • 从"以任务为中心"到"以人为中心"
  • 获产业界与资本界广泛认可

"世界模型是具身智能的'大脑'——它让机器人不再是预设程序的执行器，而是能在物理世界中理解、预测和适应的智能体。Kairos 的 4B 参数追平甚至超越 28B 竞品的关键，在于我们重新思考了'什么是具身智能真正需要学的东西'。"——大晓机器人 CTO

💡 为什么重要

大晓机器人的本轮融资有四个关键信号。第一，商汤系再出发：王晓刚作为商汤联合创始人二次创业，证明中国 AI 1.0 时代积累的人才和技术正在向具身智能赛道富集。第二，世界模型路线获资本重注：数亿美元天使+轮在中国 AI 领域极为罕见——投资人不是在赌一个产品，而是在赌"世界模型作为具身智能基础设施"的技术路线本身，这与英伟达 Cosmos、智源悟界·Physis 形成三足鼎立的路线竞争。第三，4B 超越 28B 的效率奇迹：小模型反超大模型的做法，与 Rio 3.5（巴西市政级团队也能训练一流模型）异曲同工——AI 能力的民主化正在从语言模型蔓延到世界模型。第四，开源策略的战略意义：全行业开源意味着任何人可以基于 Kairos 开发具身智能应用，这对美国出口管制背景下的中国具身智能生态极为重要。

资本狂飙

5极佳视界 B2 轮再获 10 亿元三个月狂揽 35 亿——估值破百亿，国内首个世界模型独角兽诞生

6 月 15 日，物理 AGI 全球领军企业极佳视界宣布再获 10 亿元 B2 轮融资，由新加坡狮城资本、中国-比利时基金、建投投资、万向钱潮、复星锐正等全球顶级资本阵容共同投资，国中资本、达晨财智、图灵资管等老股东持续超额加注。此前 3 月、4 月，极佳视界已分别完成 10 亿元 Pre-B 轮和 15 亿元 B1 轮融资——三个月内累计融资 35 亿元，估值突破 百亿元，成为国内首个世界模型独角兽。

"双金字塔"技术体系
  • 数据金字塔：从仿真到真机多层级数据
  • 算法金字塔：从感知到决策全栈模型
  • C 端：拾光 S1 家庭机器人已百台部署
  • B 端：工业场景规模化落地
  • 定位"物理世界的 OpenAI"
三个月 35 亿意味着什么
  • Pre-B（3 月）：10 亿
  • B1（4 月）：15 亿
  • B2（6 月）：10 亿
  • 累计 35 亿，估值破 100 亿
  • 国内首个世界模型百亿独角兽

资本为什么在赌世界模型？极佳视界的融资节奏——三个月三轮、合计 35 亿——是整个具身智能赛道资本密度的缩影。2026 年上半年，中国具身智能领域已有极佳视界（35 亿）、大晓机器人（数亿美元）、小鹏 IRON（200 天量产冲刺）、光象科技（头部车企订单）等多条线密集突破。资本押注的核心逻辑是：世界模型是通往物理 AGI 的必经之路——谁能率先训练出一个能理解和预测物理世界的通用模型，谁就掌握了具身智能时代的"操作系统"。极佳视界的"双金字塔"策略（数据+算法并行）区别于纯算法路线，强调从真实物理数据中学习，这可能解释了其估值增长速度。

💡 为什么重要

三个月 35 亿的融资速度，将极佳视界推向了中国具身智能赛道的估值标杆。这背后有三个结构性的行业信号：第一，资本叙事从"人形机器人"升级为"物理 AGI"——前者的想象空间是替代劳动力，后者的想象空间是重新定义物理世界的智能基础设施，估值逻辑完全不同；第二，"双金字塔"策略暗示了一条从数据到算法的完整路径——这与大晓机器人的"环境式数据采集+世界模型+泛化具身模组"形成路线呼应，表明中国具身智能正在形成一套有特色的技术方法论；第三，极佳视界+大晓机器人双百亿估值格局初现——两家公司合计半年内融资超 40 亿元，意味着中国具身智能正在从"散点突破"进入"资本密集型"阶段，技术领先者将拥有充裕的资源壁垒。叠加工信部万台级实景实训政策，中国具身智能在 2026 年上半年已形成"政策+资本+技术+场景"四轮驱动的产业爆发态势。
