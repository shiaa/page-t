6 月 9 日 — Anthropic 正式发布 Claude Fable 5，SWE-Bench Pro 80.3%，被誉"地表最强 AI"

美国：出口管制封禁

💡 为什么重要

这是 AI 史上第一次，一个已经部署给数亿用户的商业大模型被美国政府强制召回。事件标志 AI 正式进入"地缘技术管制"时代——此前出口管制仅针对芯片（如 A100/H100 禁运），如今直接指向模型权重本身。对 AI 编程行业而言，Fable 5 的下架意味着性能最强的编程模型不再可用，企业 AI 基础设施面临供应链断裂风险。而智谱 GLM-5.2 和 Kimi K2.7 Code 等中国编程模型的同步崛起，意味着"美国封、中国开"的格局正在形成——性能差距在缩小，可用性优势在扩大。对开发者而言，依赖单一模型的策略已正式宣告失效。

AI Coding 方向

智谱 · 开源生态

2智谱 GLM-5.2 全量开放 + ZCode 3.0 自研 Agent 内核：中国 AI 编程工具链的"独立宣言"

智谱于 6 月 13 日下午正式宣布：GLM-5.2 面向 GLM Coding Plan 全量用户开放（覆盖 Lite/Pro/Max/团队版），并将于下周以 MIT 协议开源。同步发布的 ZCode 3.0 全面切换自研 Agent 内核，标志着中国 AI 编程工具链首次实现"模型 + Agent 内核"双自研闭环。

GLM-5.2 核心能力：

① 1M 超长上下文：智谱迄今可用上下文最长的模型，在长程编程任务中保持领先

② 最强国产 Coding 模型：多项编程基准评测表现已逼近第一梯队，尤其在长程任务场景表现突出

③ MIT 协议开源：下周正式开源，下一代 API 同步上线，开发者可自由商用、修改、再分发

④ ZCode 3.0 深度集成：ZCode 内 GLM-5.2 配额比直接调 API 高出 150%

ZCode 3.0 自研 Agent 内核升级：

① 全面切换自研 ZCode Agent：针对满血 GLM 深度优化长程推理、工具调用和大型工程执行链路，整体任务完成效果显著优于第三方 Agent

② 全新分组式任务工作区：支持拖拽折叠、跨区迁移、批量管理，高效管控多 Agent 并发任务

③ Zread 智能项目知识库：自动生成结构化项目文档，支持目录浏览、进度监测、一键重生成

④ 可视化 Git 分支图谱：直观呈现分支拓扑，快捷切换 + AI 自动生成标准化提交注释

⑤ 后续版本将不再内置或维护第三方 Agent 适配，全面聚焦自研 Agent 体验

💡 为什么重要

GLM-5.2 + ZCode 3.0 的组合发布，是中国 AI 编程工具链的"独立宣言"时刻。此前 ZCode 底层 Agent 内核依赖第三方框架，模型能力受限于海外闭源体系。此次升级实现了从模型到 Agent 的全链路自研闭环，且时间节点极其精准——在 Claude Fable 5 被美国政府一纸禁令下架的当晚即全面开放。更深层的信号是：智谱选择了MIT 协议全面开源而非"仅开放 API"，意味着所有开发者可以在私有环境中部署和使用，完全不受地缘政治影响。叠加 Kimi K2.7 Code 和 DeepSeek V4-Pro，中国 AI 编程模型正形成"三足鼎立"的开源矩阵。

评测范式变革

3UC 伯克利 ALE 基准：Fable 5 实操不敌 GPT-5.5——Agent 评测从"刷榜"进入"真干活"时代

UC 伯克利发布全新测试集 "Agents' Last Exam"（ALE），让 AI Agent 执行真实电脑任务：Siemens NX 工业建模、Unreal Engine 场景搭建、Adobe After Effects 特效合成等，完全模拟人类工程师的日常工作流。

ALE 头部模型得分
  • GPT-5.5：最高通过率 24%
  • Claude Fable 5：最高通过率 22%
  • 高难度档：绝大多数模型 0%
  • 与 SWE-Bench Pro（Fable 5 80.3%）形成巨大反差
为什么 Fable 5 输了？
  • ALE 测试"多工具协同"而非纯编码
  • Fable 5 擅长单一编程任务但 GUI 操控弱
  • GPT-5.5 多模态 + 工具链调度更均衡
  • SWE-Bench 高 ≠ 真实干活能力强
  • 复杂 UI 场景 Claude 缺乏原生视觉能力

同时值得关注的是硅谷 AI 圈新概念 "Loop Engineering"——Claude Code 负责人 Boris Cherny 公开表示已不再手动输入提示词，转而编写循环逻辑让 Agent 自主发现、分配、检查和记录任务。Codex 也已内置类似功能模块。AI 编程的交互范式正从"人写 prompt → AI 执行"迅速演进为"人写 loop → AI 自主迭代"。

💡 为什么重要

ALE 基准的发布标志着 AI 编程评测从"代码补全/修 Bug"的静态维度，正式进入"Agent 真实干活能力"的动态维度。Fable 5 在 SWE-Bench Pro 上 80.3% 的成绩曾让它被视为编程能力标杆，但 ALE 揭示了一个关键问题：擅长代码 ≠ 擅长用电脑。真正的 Agent 需要跨软件、跨 UI、跨模态的协同操作能力，而这恰恰是当前所有模型的短板（最高仅 24%）。叠加 Loop Engineering 范式的普及——从"写 prompt"到"写 loop"，从"单次编码"到"自主循环"——AI 编程正经历双重范式跃迁：评测从静态到动态，交互从 human-in-the-loop 到 agent-in-the-loop。

具身智能方向

李飞飞 · World Labs

4李飞飞 World Labs 同日三篇论文：用成熟的 2D 生成模型撬动 3D/4D 空间智能

李飞飞联合创立的空间智能公司 World Labs 于 6 月 13 日发布首批三篇学术论文，均由公司实习生主导，核心命题高度统一：借助已在海量数据上训练成熟的 2D 图像/视频生成模型，降低 3D 内容生成的技术门槛。

论文 解决什么问题 核心方法 关键指标
World Tracing 从单张图像恢复被遮挡区域的完整三维几何 像素对齐多层几何表示 + 扩散模型有序深度预测 可见表面严格锚定、遮挡区域约束补全
Modality Forcing 打破深度估计和图像生成任务壁垒，统一多模态感知与生成 RGB/深度各自独立噪声时间步，微调预训练文生图模型 无需独立深度网络，仅需稀疏标注即可训练
Flex4DHuman 手机单目视频重建可合成动态 4D 人体 五轴位置编码 + Wan 2.1 微调 + FreeTimeGS 重建 PSNR 提升约 9.3dB，跨物种泛化

三条技术路线的共同价值：World Tracing 让静态场景建模不再需要多视角相机阵列；Modality Forcing 证明了生成能力和感知能力可以相互增强而非彼此独立；Flex4DHuman 则将 4D 人体重建的数据源从昂贵的多目相机降至普通手机——这是人类日常生产最多的数据形式。三条路线共同指向一个目标：把空间智能（Spatial Intelligence）的门槛从"专业设备 + 大量算力"降到"普通手机 + 预训练 2D 模型"。

💡 为什么重要

World Labs 的三篇论文从不同角度回答了具身智能领域一个核心瓶颈：3D/4D 训练数据的极度稀缺。与 LLM 可以吞噬互联网所有文本不同，具身智能的三维世界理解受限于数据采集成本。李飞飞团队的方法论——"用 2D 的积累撬动 3D 的突破"——提供了可规模化的技术路径。Flex4DHuman 尤其关键：如果手机视频就能重建人物 4D 资产，数据飞轮将彻底转向。这对具身智能在数字内容创作、虚拟制片、AR/VR、机器人仿真训练等领域都有直接推动力。同日 World Labs 联合创始人 Christoph Lassner 因病离职，也为这个明星团队的未来走向增添变数。

资本加速

5清华系千诀科技完成数亿元 A 轮融资：分布式预测世界模型 + 十万级终端落地

具身智能世界模型公司千诀科技完成数亿元 A 轮融资，由京铭资本领投，多家国家队及市场化基金跟投。团队来自清华系，专注分布式预测世界模型研发，与智源悟界·Physis 的"集中式物理隐空间"路线形成差异化互补。截至目前，千诀科技的终端设备落地规模已达十万量级，是具身智能赛道少数从实验室走向规模落地的创业公司。

千诀的分布式架构思路意味着：预测模型不是运行在云端"上帝视角"，而是部署在每个终端设备本地，通过分布式协同完成世界建模与实时决策。这一定位直接对标工信部 6 月 9 日启动的"万台级实景实训"——当机器人需要在工厂、仓库、家庭等真实环境中自主作业时，集中式云端模型面临延迟和带宽瓶颈，而分布式世界模型恰好解决了"最后一米"的实时推理问题。

💡 为什么重要

千诀科技这轮融资是具身智能"世界模型赛道"资本密度持续攀升的缩影。从 6 月初智源悟界·Physis-v0.1（集中式物理隐空间）到千诀科技（分布式终端预测），两条技术路线在"世界模型"这一具身智能的核心基础设施上同时获得资本市场和产业落地的双重验证。十万级终端部署是关键指标——它意味着千诀的范式不是"实验室刷榜"，而是已经在真实场景中跑通了工程闭环。叠加工信部万台级实景实训政策、宇树科技科创板 IPO 过会，中国具身智能的"技术路线→资本市场→政策推动→规模落地"全链路正在 6 月集中打通。
