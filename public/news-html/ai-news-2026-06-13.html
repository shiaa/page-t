行业头条

范式革命

1智源大会重磅发布悟界·Physis-v0.1：全球首个通用世界基座模型，从"预测下一个词"迈向"预测下一个物理状态"

6 月 12 日，第八届北京智源大会在中关村国际创新中心开幕。智源研究院院长王仲远发布全球首个通用世界基座模型——悟界·Physis-v0.1，同步推出多模态神经科学大模型悟界·Brainμ1.0、具身大脑悟界·RoboBrain Orca、统一多模态基座悟界·Emu3.5、药物发现模型悟界·OpenComplex2.5，以及覆盖 18 家芯片厂商 32 款芯片的 FlagOS 2.1 智算软件栈。

核心创新点：

① 范式跃迁：悟界·Physis-v0.1 打破传统世界模型以语言、像素、三维结构、视觉表征为中心的局限，首次以物理隐空间表征替代像素预测，可将视频、深度 RGB、3D 点云、力触反馈等全模态信息统一转化为标准化隐空间物理状态。

② 四大核心能力：物理正确、动作因果可溯、长程一致、通用泛化——已支持 50+ 复杂物理场景的长程推理。

③ 具身大脑 RoboBrain Orca：以"下一个物理状态预测"为核心，实现"想、看、动"三位一体，少样本学习与跨场景泛化能力大幅提升，可支撑机器人在物流、酒店等真实环境长期自主作业。

💡 为什么重要

如果说 GPT 系列开启的 LLM 时代是"预测下一个词元"，悟界·Physis-v0.1 标志的则是"预测下一个物理状态"——AI 范式从数字世界正式跨入物理世界。这与英伟达 Cosmos（像素预测）、DeepMind Genie（视频生成）路线有本质差异，智源选择了物理隐空间这一更接近真实物理本质的路径。具身大脑 RoboBrain Orca 让"机器人通用大脑"有了可工程化的中国底座，叠加工信部 6/9 启动的万台级实景实训，中国具身智能首次具备了"原创底座 + 政策推动 + 量产场景"三位一体的基础。

2Kimi K2.7 Code 编程大模型开源发布：1.1 万亿参数、Token 消耗直降 30%、6/15 上线 6 倍速高速版

与 K2.6 对比（6 项基准）
  • Kimi Code Bench v2：50.9 → 62.0（+21.8%）
  • Program-Bench：48.3 → 53.6（+11%）
  • MLS Bench Lite：26.7 → 35.1（+31.5%）
  • Kimi Claw 24/7 Agent：42.9 → 46.9（约+10%）
  • MCP Atlas（Agent）：69.4 → 76.0（约+9.5%）
  • MCP Mark Verified（Agent）：72.8 → 81.1（+11.4%）
  • 核心：长程任务 Token 消耗平均减少 30%
商业化与高速版
  • 参数规模：1.1 万亿，多模态，256K 上下文
  • 已上线 Kimi API 平台（标准版）
  • 6 月 15 日（周一）上线高速版：常规 180 Token/s、短上下文 260 Token/s，速度约常规 6 倍、价格仅 2 倍
  • 输入 ¥6.5/M tokens、输出 ¥27/M tokens（与 K2.6 一致）
  • 缓存命中输入 ¥1.3/M tokens（行业最低一档）
💡 为什么重要

Kimi K2.7 Code 的发布是中国编程模型在"过度思考"问题上的首次系统性突破。30% 的 Token 降幅直接转化为企业成本下降——这正是当下 AI 编程工具"赢家通吃"的关键变量。在 Anthropic Claude Fable 5 拿下 SWE-Bench Pro 80.3% 榜首、OpenAI 即将放出 GPT-5.6 的当口，月之暗面用 K2.7 Code 把"成本/性能"曲线打到了一个新的甜蜜点：1/30 的缓存输入价 + 6 倍速版本 + 开源策略，让 Kimi 在国内大厂编程模型中具备了清晰的差异化定位。

三巨头混战

3OpenAI 准备放出 GPT-5.6：150 万 token 上下文 + 即将大幅降价，正面迎战 Claude Fable 5

OpenAI 首席科学家 Jakub Pachocki 内部确认 GPT-5.6 相比 GPT-5.5 有"实质性提升"，可能于本月（6 月）内发布。开发者从 Codex 后端日志发现内部代号 kindle-alpha / iris-alpha 模型，上下文窗口约 150 万 token（GPT-5.5 为 100 万，提升 50%）。

价格战一触即发：

① OpenAI 正在考虑大幅降低 Token 定价，目标是抢在 Anthropic 之前出手

② Sam Altman 近期公开表态：算力成本已是用户面临的大问题，会想办法让用户"花更少的钱，获得更大的价值"

③ 同时，Altman 内部讨论"若 AI 实现递归自我改进（RSI），上市计划可暂缓"——技术加速度与商业化节奏的赛跑

④ OpenAI 已秘密提交 S-1 招股书，估值约 8520 亿美元

竞争压力来源
  • Anthropic 估值 9650 亿美元首次反超 OpenAI
  • Claude Fable 5 SWE-Bench Pro 拿 80.3%，碾压 GPT-5.5 的 58.6%
  • Artificial Analysis 综合智能指数 Claude 64.9 分位列第一（10 个单项拿下 5 冠）
  • Claude Code 爆火后，企业客户猛增、AI 预算向 Anthropic 倾斜
OpenAI 应对
  • GPT-5.6（kindle-alpha） 150 万 token 上下文
  • ChatGPT 模型选择器重构为"Intelligence 智力分级"
  • Token 定价大幅下调
  • 走"价格 + 性能"双线反击
💡 为什么重要

这是 AI 编程赛道首次出现"性能 + 价格"双维度同时开战的局面：Anthropic 性能领先（SWE-Bench Pro 80.3%），OpenAI 选择用"价格 + 上下文"反制。叠加 Kimi K2.7 Code 用 1/30 缓存输入价撕开中国市场的口子——6 月正成为 AI 编程模型的"三国杀窗口期"：Anthropic 占性能、OpenAI 守生态、中国厂商用极致性价比突围。开发者短期薅羊毛红利确定，长期看模型能力与生态绑定的比拼将更关键。

具身智能方向

华为 · 操作系统

4华为 HDC 2026 鸿蒙 7 Beta 正式发布：原生 Agent OS 时代开启，盘古 2.0 开源同步登场

6 月 12 日华为开发者大会（HDC 2026）在东莞松山湖启幕，HarmonyOS 7 开发者 Beta 版正式上线，鸿蒙智能体框架 2.0同步发布。余承东宣布鸿蒙正式迈入"Agent OS 时代"。

核心能力：

① Agent 亲和系统架构：深度融合端云大模型，复杂任务成功率提升至 90% 以上，首次向开发者开放 GUI 操控能力 + 20+ 项系统级 AI 能力

② 小艺 AI 私人助理：接入 200+ 项系统级感知数据，具备超强记忆与上下文理解，从语音助手蜕变为 AI 助理

③ 开源盘古 openPangu 2.0 同步发布，端云协同大模型能力首次完整开源

④ 鸿蒙空间计算首发：超沉浸空间美学 + 空间影音 + 空间交互

⑤ HiCar 7.0：6/13 智慧出行峰会发布，重塑智能出行体验

💡 为什么重要

HarmonyOS 7 的意义不只是系统升级，而是全球首个原生支持 Agent 的操作系统。当 6/4 OpenAI 让 Codex 升级为"全行业 Agent 平台"、6/9 智源发布 RoboBrain Orca 具身大脑、6/12 华为将 Agent 内核植入鸿蒙——三家在"Agent 操作系统"赛道同步发力。鸿蒙的优势在于20+ 系统级 AI 能力 + 200+ 感知数据 + 5 亿+ 设备，Agent 从一个 App 升级为 OS 级别的"意图即服务"，这是端侧 AI 真正进入"操作系统级"竞争的标志事件。
