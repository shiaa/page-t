阿里国际站 Accio Work 用户突破千万，AI Agent B 端商业化迎来关键样本

AI Agent B 端商业化 阿里国际站

7 月 23 日，在杭州一场全球跨境电商峰会上，阿里国际站总裁张阔透露，全球已有 1000 万中小企业在使用 Accio Work 做生意，用户数在一年内增长逾 30 倍。过去 12 个月，阿里国际站上的中小企业 Token 消耗量翻了 10 倍，而 Accio Work 单次任务的使用成本下降了 50%。

值得关注的原因：Accio Work 从零到千万用户仅一年，是 AI Agent 在 B 端场景规模化落地的标志性案例。中小企业 Token 消耗翻 10 倍说明它已嵌入真实业务流程，而非停留在“尝鲜”；成本下降 50% 则体现了规模效应与工程优化。对 AI Coding 和 Agent 开发者而言，这是一条可观测的 PMF 路径：垂直场景、工作流嵌入、按任务计费。

PrimalVerse 元昊动力完成数亿元种子轮融资，押注原生 4D 世界模型基模

世界模型 具身智能 4D 重建

近日，4D 世界模型公司 PrimalVerse（元昊动力）宣布完成数亿元种子轮融资，由联想之星、银杏谷资本、啟赋资本、卓源亚洲等财务投资机构联合参与，手术机器人领域头部产业方精锋医疗战略投资。团队由清华背景的世界模型研究者组成，提出以“原生 4D World Token”为核心的第五代多模态大模型，目标覆盖具身智能、游戏影视、自动驾驶、医疗手术等场景。

值得关注的原因：世界模型被普遍视为具身智能和自动驾驶的“底层操作系统”。PrimalVerse 强调从文本/图像/视频 token 走向原生 4D（3D 空间 + 时间）表征，让模型能预测“一次行动之后世界会发生什么”。清华团队贯通 4D 重建、神经渲染、物理仿真与机器人技术链，是少数能完整交付这一技术路径的团队。这笔融资也表明资本仍在向“物理 AI 基础设施”下注。

Claude Code 2.1.205 发布 /checkup 命令，AI 编程环境进入“自我体检”时代

AI Coding Claude Code Agent 工具链

7 月上旬，Anthropic 发布 Claude Code v2.1.205，将 /doctor 升级为完整的 setup checkup，并新增别名 /checkup。Claude Code 创始人 Boris Cherny 介绍，运行 /checkup 可自动清理长期未使用的技能、MCP 和插件，拆分臃肿的 CLAUDE.md，关闭拖慢运行的 hooks，将 Claude Code 更新到最新版，并默认开启自动模式与高频只读命令预批准。该版本共包含 23 项 CLI 升级。

值得关注的原因：AI Coding 工具的竞赛正从“模型能力”延伸到“工程环境治理”。上下文窗口是稀缺资源，未用插件和技能会无声消耗 token；长期项目里 CLAUDE.md 膨胀到数百行后也会拖累效果。/checkup 把这些手动运维动作打包成一键命令，意味着 Agent 开始具备“自我卫生”能力。对 DevOps/SRE 和团队 CI 场景，这能显著降低长期维护摩擦与权限确认噪音。

无界动力 K15 成为全球首个获工业级全域 CE 认证的具身智能机器人，开启全球批量交付

具身智能 工业认证 出海

7 月 9 日，无界动力宣布旗下第二代机器人 K15 通过欧盟合规准入，成为全球首个获得工业级全域 CE 认证的具身智能机器人。K15 全面通过 CE-MD（机械安全）、CE-RED（无线电设备）、CE-EMC（电磁兼容）、EN ISO 13849（功能安全）及 EN 18031（网络安全）认证。目前，无界动力全球近 1 亿美元的国内外订单已全面开启交付，首批 K15 机器人已启程发往欧洲，与远景科技集团法国工厂的合作项目率先落地。

值得关注的原因：CE 认证是欧洲工业市场的强制性准入背书，涉及机械、电磁、功能安全与网络安全，全球公认门槛最高。K15 通过“工业级全域”认证，意味着中国具身智能从“纯硬件输出”升级为“软硬一体的智能基础设施”出海。其批量交付也说明国产具身智能的合规、供应链和量产能力已能支撑跨国项目，对机器人出海和欧洲工业场景落地具有标杆意义。
